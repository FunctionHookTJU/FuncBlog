1　RSA 加密算法

对应 PPT 第 8–13 页。这一节只有 6 页，但它是整讲的心脏：三个算法（密钥产生、加密、解密）+ 一个正确性证明 + 一个完整例子。

建议把这三个算法背下来——后面所有攻击都是在攻击这三个算法里的某一步。

1.1 加密（PPT 第 8–12 页）

算法 1　RSA 公钥加密的密钥产生（PPT 第 8 页）

PPT 原文：

算法 1　RSA 公钥加密的密钥产生 摘要：每一个实体产生 RSA 的公开和对应的秘密密钥。 每个实体 AAA 做如下步骤： （1） 产生两个大随机（不同）的素数 ppp 和 qqq，两个素数的长度基本相等。 （2） 计算 n=p⋅qn = p \cdot qn=p⋅q 和 φ=(p−1)(q−1)\varphi = (p-1)(q-1)φ=(p−1)(q−1)。 （3） 选择一个随机的整数 eee，1<e<φ1 < e < \varphi1<e<φ，满足最大公约数 (e,φ)=1(e, \varphi) = 1(e,φ)=1。 （4） 使用扩展 Euclidean 算法计算唯一的整数 ddd，1<d<φ1 < d < \varphi1<d<φ，满足 e⋅d≡1(modφ)e \cdot d \equiv 1 \pmod \varphie⋅d≡1(modφ)。 （5） AAA 的公开密钥为 (n,e)(n, e)(n,e)；AAA 的秘密密钥为 ddd。

逐步拆解：

第（1）步：找两个大素数 ppp 和 qqq。

要求 为什么
大 小了就能被分解（第 3.2 节讲分解方法，第 4.1 节讲"模至少 1024 比特"）
随机 如果有规律，攻击者可以按规律猜（第 3.7 节"部分密钥泄露攻击"会讲到"用 N+1050kN + 10^{50}kN+1050k 生成素数"这种做法的危险）
不同 如果 p=qp = qp=q，那么 n=p2n = p^2n=p2，开平方就是分解——一击即破
长度基本相等 如果 ppp 远小于 qqq，那么小素数可以靠试除找到（第 3.2 节"简单分解法"）；长度相等让两种极端攻击都失效

补"长度基本相等"这条还能从另一个角度理解（第 3.2 节会讲 Fermat 分解法）：Fermat 分解法在 ppp 和 qqq 非常接近时极其有效，只需要大约 ∣p−q∣/2|p-q|/2∣p−q∣/2 步就能分解。所以反过来，ppp 和 qqq 也不能太近。两头都不能走极端，所以"长度基本相等但数值上随机"就是最佳选择。

第（2）步：算 nnn 和 φ\varphiφ。

n=p⋅q,φ=(p−1)(q−1)n = p \cdot q, \qquad \varphi = (p-1)(q-1)n=p⋅q,φ=(p−1)(q−1)
  • nnn 是公开的（它是模，公钥的一部分）；
  • φ\varphiφ 是保密的（它是 φ(n)\varphi(n)φ(n)，欧拉函数，第 0.4 节讲过 (p−1)(q−1)(p-1)(q-1)(p−1)(q−1) 这个结论）。

补注意这两句话的分量：nnn 公开、φ\varphiφ 保密——所以"从 nnn 算出 φ\varphiφ"就是攻击者的第一个目标。而一旦算出 φ\varphiφ，ppp 和 qqq 就立刻暴露（第 3.1 节的"事实 1"会给出公式）。这是整讲所有攻击的一个共同起点。

第（3）步：选一个加密指数 eee。

条件：1<e<φ1 < e < \varphi1<e<φ 且 gcd⁡(e,φ)=1\gcd(e, \varphi) = 1gcd(e,φ)=1。

补为什么必须 gcd⁡(e,φ)=1\gcd(e, \varphi) = 1gcd(e,φ)=1？ 因为下一步要算 eee 的模 φ\varphiφ 逆元，而模逆存在的充要条件就是 gcd⁡(e,φ)=1\gcd(e, \varphi) = 1gcd(e,φ)=1（第 0.2 节）。如果 eee 和 φ\varphiφ 有公因子，那么不存在满足 ed≡1ed \equiv 1ed≡1 的 ddd，密钥就产生不出来。

这一条也告诉了攻击者一件事：gcd⁡(e,φ)=1\gcd(e, \varphi) = 1gcd(e,φ)=1 意味着 gcd⁡(e,p−1)=1\gcd(e, p-1) = 1gcd(e,p−1)=1 且 gcd⁡(e,q−1)=1\gcd(e, q-1) = 1gcd(e,q−1)=1。所以第 4.3 节会说"如果用 e=3e = 3e=3，就要求 p−1p-1p−1 和 q−1q-1q−1 都不能被 3 整除"——实现时必须检查这一点。

第（4）步：用扩展 Euclidean 算法算出 ddd。

e⋅d≡1(modφ)e \cdot d \equiv 1 \pmod \varphie⋅d≡1(modφ)

这一步就是第 0.3 节讲的"求模逆"——扩展 Euclidean 算法在算出 gcd⁡(e,φ)=1\gcd(e, \varphi) = 1gcd(e,φ)=1 的同时，顺便给出 ddd。

补注意 PPT 说"唯一的整数 ddd"：在 1≤d<φ1 \le d < \varphi1≤d<φ 的范围内，模逆是唯一的。这是因为 ddd 和 d+kφd + k\varphid+kφ 都对（它们模 φ\varphiφ 相同），所以限定范围之后就只有一个是"正经的"钥匙。

第（5）步：公布公钥，藏好私钥。

公钥：(n,e)私钥：d\text{公钥：}(n, e) \qquad \text{私钥：}d公钥：(n,e)私钥：d

补注意私钥只有 ddd，不含 ppp 和 qqq。（这是 PPT 的写法。实现上通常会保留 ppp 和 qqq 以加速解密——这叫 CRT 加速，用中国剩余定理把一次大模幂拆成两次小模幂，速度能快约 4 倍。但从定义上说，私钥就是 ddd。）

补把公钥和私钥画成一张"谁知道什么"的表，这一讲后面要反复回来看：

已知（公开）:  n, e
未知（保密）:  p, q, φ, d
                ↑
          攻击者想拿到其中任何一个

而"拿到 φ\varphiφ"和"拿到 p,qp,qp,q"是等价的（事实 1），"拿到 ddd"也几乎是等价的（事实 2）。这三者构成一个"一破全破"的链条：

分解 n  ⟺  求出 φ  ⟹  求出 d\text{分解 } n \;\Longleftrightarrow\; \text{求出 } \varphi \;\Longrightarrow\; \text{求出 } d分解 n⟺求出 φ⟹求出 d
