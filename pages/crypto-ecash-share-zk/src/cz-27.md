### 从直觉开始：1.1 节要做什么

零知识证明的正式定义（第十二讲 1.2 节的三个定义）非常抽象，直接读会绕晕。课件因此先花四页讲一个**纯物理的故事**（PPT 第 6–9 页），这个故事把「证明我知道一个秘密，但不告诉你这个秘密」这件事变成了一个可以亲眼看见的过程。

【补】**洞穴故事的来历。** 这个故事最早出现在 Quisquater、Guillou 等人 1990 年的一篇科普文章《如何向你的孩子解释零知识协议》（How to Explain Zero-Knowledge Protocols to Your Children）里，原型是《一千零一夜》中「阿里巴巴与四十大盗」的洞穴。它后来成了零知识证明最著名的教学例子，因为它把最抽象的两件事——**「不知道秘密的人无法通过」**和**「看的人学不到任何东西」**——都变成了肉眼可见的物理事实。

故事的主角是两个人：**Peggy**（Prover，证明者）和 **Victor**（Verifier，验证者）。Peggy 声称自己知道洞穴里那道魔法门的咒语；Victor 想知道她是不是在吹牛，但 Peggy 绝不愿意把咒语告诉他。

### 洞穴的布置：把「知识」变成「可检验的行为」

先看洞穴的结构（PPT 第 7 页描述，示意图为讲解方便而画）：

```
                      Victor 站在 A 点（洞口，看得到分叉但看不到通道深处）
                                    │
                            ┌───────┴───────┐
                            │    洞口 A     │
                            └───────┬───────┘
                                    │
                            ┌───────┴───────┐
                            │    分叉 B     │  ← 从这里能同时看到 C、D 两个通道口
                            └───┬───────┬───┘
                ┌───────────────┘       └───────────────┐
                │                                       │
        ┌───────┴───────┐                       ┌───────┴───────┐
        │   C 通道（左） │                       │   D 通道（右） │
        └───────┬───────┘                       └───────┬───────┘
                │                                       │
                └───────────────────┬───────────────────┘
                                    │
                            ┌───────┴───────┐
                            │     密  门    │  ← 只有念对咒语才能打开
                            └───────────────┘
```

洞穴的关键设计只有一句话：**两条通道 C 与 D 在深处被一道魔法门连通，而这扇门只有念对咒语才能打开。**

这条设计带来一个非常干净的性质：

- **知道咒语的人**：从任意一条通道进去，都能通过密门穿到另一条通道，因此**总是**能从 Victor 指定的任何一侧出来。
- **不知道咒语的人**：一旦走进某一条通道，就被**物理地锁死**在那一条里。如果 Victor 要求的正是这一侧，他可以原路退出来蒙混过关；如果要求的是另一侧，他只能干瞪眼。

**翻译成人话**：这个洞穴把「是否掌握咒语」这件看不见的事，翻译成了一个**看得见的、非是即否的行为**——「你能不能从指定的一侧出来」。这就是所有零知识协议的原型：**不去检查秘密本身，而是检查只有掌握秘密的人才能做出的行为。**

### 协议逐步走一遍

课件把协议写成六个步骤（PPT 第 7–8 页），这里逐条抄下来并逐条解释：

> (1) Victor 站在 A 点。
> (2) Peggy 一直走进洞穴，到达点 C 或点 D。
> (3) 在 Peggy 消失在洞穴中之后，Victor 走到点 B。
> (4) Victor 向 Peggy 喊，要她：(4.1) 从左通道出来，或者；(4.2) 从右通道出来。
> (5) Peggy 答应了，如果有必要她就用咒语打开密门。
> (6) Peggy 和 Victor 重复第 (1) 到第 (5) 步 $n$ 次。

逐步翻译：

- **第 (1) 步**把 Victor 放在洞口的 A 点。这时候他还看不见分叉，也看不见 Peggy 会往哪边走。
- **第 (2) 步**是 Peggy 的**承诺（commitment）**：她必须在**还不知道 Victor 会要求哪一侧**的情况下，先选定一条通道走进去。这一步是整件事的命门——它把 Peggy「锁死」在某一条通道里，让她事后无法根据 Victor 的要求临时改变主意。
- **第 (3) 步**让 Victor 走到分叉 B 点。他此时能同时看到 C 和 D 两个通道口，但**已经看不到 Peggy 究竟是从哪一条进去的**（她早就走远了）。物理上的「看不见」在这里扮演了密码学里「隐藏」的角色。
- **第 (4) 步**是 Victor 的**挑战（challenge）**：他随机喊出「从左出来」或「从右出来」。注意「随机」两个字——如果他有偏向（比如每次都喊左边），Peggy 就可以利用这个规律。
- **第 (5) 步**是 Peggy 的**应答（response）**：她知道咒语，所以能穿门，喊哪边就从哪边出来。这里要强调：**诚实的 Peggy 永远能成功**，无论 Victor 喊哪边——这正好是第十二讲 1.2 节「完备性」定义的物理版。
- **第 (6) 步**把一轮变成 $n$ 轮。一轮的说服力有限（下面会算），$n$ 轮才能把冒充者的成功率压到可以忽略。

用 A、B 两列的时序图写出来更清楚：

```
   Peggy（证明者）                              Victor（验证者）
        │                                            │
        │  ── ① Victor 站在 A 点，不看 ──             │
        │                                            │
   ②   │  走进洞穴，随机选 C 或 D 进入               │
        │  （Victor 看不到她选了哪一条）              │
        │                                            │
        │        ③ Peggy 消失后，Victor 走到 B 点 ──▶ │
        │                                            │
        │  ◀── ④ 喊「从 C 出来」或「从 D 出来」 ──    │
        │                                            │
   ⑤   │  若正好在这条通道里，直接走出来             │
        │  否则念咒语打开密门，穿到另一侧再走出来     │
        │                                            │
        │  ── ⑥ 从被要求的通道口出现 ───────────────▶ │
        │                                            │
        │  ── 重复 ①–⑥ 共 n 次 ──                    │
```

**翻译成人话**：每一轮就是「你先躲进一边（承诺）→ 我随机点名一边（挑战）→ 你从被点名的一边出来（应答）」。Peggy 的秘密（咒语）只用在「穿门」这个动作上，从头到尾没有说出任何一个字。

### 为什么一轮挡不住冒充者：$1/2$ 从哪来

现在把 Peggy 换成一个**不知道咒语**的冒充者。她能做什么？

她没有咒语，所以进洞之后就被锁死在某一条通道里。她唯一能做的，是在第 (2) 步随便选一条通道走进去（比如抛硬币选左选右）。于是：

- 如果 Victor 喊的**恰好**是她进去的那一侧，她直接原路走出来，看起来完全正常；
- 如果 Victor 喊的是**另一侧**，她既穿不过密门，也不能凭空出现在另一条通道里，只能认输。

因为 Victor 的挑战是在 $\{C,D\}$ 上均匀随机的，记 $p_{1}$ 为冒充者单轮成功的概率，则

$$p_{1}=\frac{1}{2}.$$

**翻译成人话**：不知道咒语的人，走对一边的机会是一半；只要喊错了边，她就露馅。

【补】**这里有一个非常容易混淆的点：冒充者「选哪边进去」无关紧要。** 无论她怎么选，只要 Victor 的挑战是独立均匀的，她蒙对的概率永远是一半。关键是 **Victor 的挑战必须在她承诺之后才产生，并且与她的选择独立**。如果顺序反过来——Victor 先宣布「我要你从右边出来」，然后 Peggy 再进洞——那么冒充者只要走进右边就行了，成功率是 $100\%$。**「先承诺、后挑战」这个顺序，就是零知识协议的全部安全性来源**，后面第十二讲 1.3 节会把它写成一般结构。

把一轮重复 $n$ 次，且每轮冒充者都独立地赌一次，$n$ 轮全部蒙对的概率是概率的乘积：

$$p_{n}=p_{1}^{\,n}=\left(\frac{1}{2}\right)^{n}=2^{-n}.$$

**翻译成人话**：骗一次有一半机会，骗两次只剩四分之一，骗 $n$ 次就只剩 $2^{-n}$。

把数字代进去感受一下：

| 轮数 $n$ | 冒充成功率 $2^{-n}$ | 直观感觉 |
|---|---|---|
| 1 | $0.5$ | 一半一半，完全不可信 |
| 10 | 约 $9.8\times 10^{-4}$ | 千分之一，仍然太高 |
| 20 | 约 $9.5\times 10^{-7}$ | 百万分之一，勉强可用 |
| 40 | 约 $9.1\times 10^{-13}$ | 万亿分之一，实际可忽略 |

如果按第十二讲 2 节 Fiat-Shamir 协议的做法取 $n=20$ 或 $n=40$（PPT 第 26 页），冒充者成功的概率就落到「实际不可能发生」的量级。**注意这里的「安全」是概率意义上的**：零知识证明从来不说「骗子绝对进不来」，只说「骗子进来的概率小到可以忽略」——这是它与传统数学证明最根本的差别（PPT 第 10 页）。

### 为什么一次成功什么信息都不泄露

到这里 Victor 已经被说服了（$n$ 轮全过，冒充概率 $2^{-n}$）。真正的问题是：**Victor 在这个过程中，除了「Peggy 知道咒语」这件事，还学到了什么别的东西？**

答案是：**什么也没学到。** 论证分两层。

**第一层：Victor 的挑战与 Peggy 的入口相互独立。** 对任意一轮，记 $e\in\{C,D\}$ 为 Victor 喊的那一侧，记事件 $E_{C}$ 为「Peggy 从 C 进入」、$E_{D}$ 为「Peggy 从 D 进入」。因为 Victor 是在**看不到** Peggy 走哪边的情况下随机喊的，所以

$$\Pr[\,e=C\mid E_{C}\,]=\Pr[\,e=C\mid E_{D}\,]=\frac{1}{2}.$$

**翻译成人话**：Peggy 从哪条通道进去，完全不影响 Victor 喊哪一边——他的挑战是一枚独立的硬币。

于是从 Victor 的角度看，每一轮他能观察到的**只有**「我喊了 $e$，她就从 $e$ 出来了」。这件事有两个可能的解释，而且两种解释产生**完全相同的观察记录**：

- 解释一：Peggy 恰好就是从这个通道进去的，直接走了出来；
- 解释二：Peggy 从另一条通道进去，念咒语打开密门穿了过来。

两种情况的概率都是 $1/2$，Victor 没有任何办法区分。**换句话说，「她打开了密门」这个事实从来没有出现在 Victor 的观察里**——他看到的只是「她从被点名的一侧出现了」，而这个现象不知道咒语的人也有 $1/2$ 的机会做出来。

**第二层：Victor 自己就能编出这段录像。** 设想 Victor 想向第三个人吹牛：「我亲眼见过 Peggy 表演零知识证明。」他根本不需要真的找 Peggy，只需要自己**伪造**一段记录：先随机挑一个要喊的方向，比如喊「从 C 出来」，然后假装 Peggy 从 C 出来了。这段编造出来的记录，与他真实观察到的记录**在概率分布上完全一样**。所以真实记录没有携带任何「只有真 Peggy 才能产生」的信息。

这一段正是第十二讲 1.2 节定义 3（零知识属性）的雏形：**如果验证者自己就能造出以假乱真的交互记录，那么真实交互记录里就不可能含有他不知道的东西。** 定义 3 只是把「自己编一段」这件事写成一个算法，称为**模拟器（simulator）**。

【补】**为什么必须强调 Victor 是「随机」喊的？** 因为零知识属性和正确性都建立在挑战的随机性上。假如 Victor 每次都喊「左边」，冒充者只要每次都走进左边就能永远成功——正确性（骗子进不来）当场崩掉；假如 Victor 提前宣布挑战，Peggy 就能在承诺之前把答案安排好——零知识也就无从谈起（虽然那时泄露的其实不是 Peggy 的秘密，而是协议本身的漏洞）。所以后续所有正式协议里，**挑战必须由验证者现场随机生成**，这一条会反复出现。

【补】**一轮的说法要小心。** 严格地说，「一轮全过」这件事本身**确实**说明了一点信息：这个人有 $1/2$ 以上的本事（或者运气好）。但单轮记录不能说明她**知道咒语**——因为 $1/2$ 的运气人人都有。$n$ 轮全过才把「运气」的因素压到 $2^{-n}$。这就是**概率证明（probabilistic proof）**的样式：**单个片段没有说服力，整体统计才有说服力**。它与数学证明的「一步错则全错」逻辑完全不同。

### 评述：分割选择技术（cut and choose）

课件在最后给出一段评述（PPT 第 9 页），把洞穴故事里的技术命名为**分割选择技术（cut and choose）**，并给出它的经典形式：

> 因为它类似如下将任何东西等分的经典协议：
> (1) Peggy 将东西切成两半。
> (2) Victor 给自己选择一半。
> (3) Peggy 拿走剩下的一半。
> Peggy 最关心的是第 (1) 步中的等分，因为 Victor 可以在第 (2) 步选择他想要的那一半。

逐条翻译这个类比，并说明它为什么能保证公平：

- **切的人先动手，但选的人后动手。** 先动手的人（Peggy）不知道自己会拿到哪一半，后动手的人（Victor）可以挑走对自己最有利的一半。这个**信息与选择权的错位**，逼得 Peggy 不敢不切得均匀：**她要是切得一大一小，Victor 一定会拿走大的那份，吃亏的是她自己。**
- **所以「切得均匀」不是靠道德，而是靠激励。** 这个协议不需要任何一方诚实：Peggy 为了自保必须切得公平，Victor 为了自保必须认真挑。
- **代价是要有「东西」可以切，而且切的动作不可逆。** 在洞穴故事里，「切」就是第 (2) 步选一条通道走进去——一旦进去了，就锁死在那条通道里，这就是不可逆的承诺。

把两个协议一一对应起来：

| 分割选择（切东西） | 洞穴故事 | 一般三步行 |
|---|---|---|
| (1) Peggy 把东西切成两半 | Peggy 走进 C 或 D（锁死一侧） | 承诺（commitment） |
| (2) Victor 选走一半 | Victor 随机喊「从 C 或 D 出来」 | 挑战（challenge） |
| (3) Peggy 拿走剩下的一半 | Peggy 从被点名的一侧出来 | 应答（response） |
| Peggy 必须切得均匀 | Peggy 必须真的知道咒语才能两边都应付 | 应答必须依赖秘密 |

**翻译成人话**：**「我先做一件锁死我自己的事，你再出题，我按题作答」**——这个三步套路在密码学里到处都是，第十一讲的电话投币与电话扑克用的也是它。零知识证明的新意不在这个套路本身，而在于课件要证明：**这个套路可以让验证者除了「你知道秘密」之外，什么也学不到**。

【补】**分割选择技术的其它用武之地。** 它不只出现在洞穴里：可验证秘密分享里，分发者把多项式切成两半让对方抽查；电子现金的盲签名里，银行让用户把同一笔钱的若干「候选币」中的一半打开检查；安全多方计算里，参与方互相「切」电路的一半让对方抽查是否被篡改。共同点都是：**一方先做出一批承诺，另一方随机抽查其中一部分**——**重复抽查会把作弊不被抓住的概率压到指数小**。这里的 $\left(1/2\right)^{n}$ 与洞穴故事的 $2^{-n}$ 是同一个数学。

【补】顺带指出课件没有强调的一点：**分割选择的效率并不好。** 因为它靠重复来压低概率，每一轮都要通信、都要重新随机，$n=40$ 就意味着 40 次往返（第十二讲 2 节会看到同样的代价）。所以真实系统里人们更愿意把「1 比特挑战」升级成「$k$ 比特挑战」（第十二讲 3 节 FFS 的做法），用一次通信换 $k$ 位安全性，而不是傻重复 $k$ 次。

### 从直觉到形式化还差什么

洞穴故事讲到这里，直觉已经完全建立：**重复 $n$ 轮 → 冒充概率 $2^{-n}$；Victor 的观察记录他自己都能伪造 → 没有信息泄露。** 但它还不是一个数学定义，因为它依赖三个没有精确化的词：

1. **「压倒的概率」到底是多少？** 洞穴故事里说「$n$ 轮全过」，那 $n$ 取多少、失败概率多小算「可以忽略」，需要定义。这就是第十二讲 1.2 节定义 1（完备性）要处理的事——它要求诚实的 Peggy 「以压倒的概率」成功，并且把「压倒」这个词交给具体应用去定（PPT 第 12 页）。
2. **「骗子几乎不可能通过」怎么保证？** 洞穴故事只给了一个物理直观（不知道咒语就走不出来），数学上需要证明「任何能通过协议的一方，都等价于掌握秘密」。这就是定义 2（正确性，PPT 第 13 页）要做的事。
3. **「什么也没学到」怎么形式化？** 我们说的是「Victor 自己也能编出同样的记录」，这句话必须写成一个**算法**（模拟器）并且证明输出「不可区分」。这就是定义 3（零知识属性，PPT 第 15 页）要做的事。

【补】**还有一个物理故事掩盖掉的现实问题：真实世界里没有「物理上看不见」。** 洞穴故事之所以成立，是因为 Victor 真的看不见 Peggy 走进哪条通道——物理遮蔽提供了「隐藏」。但在网络上，Victor 就是那台接收消息的计算机，Peggy 发出去的每一个比特他都看得一清二楚，没有一道墙能挡住他。所以工程实现里必须用**数学上的隐藏**来替代物理隐藏：把「我选了 C」这件事变成一个**承诺值**（比如一个哈希），让 Victor 看得见这个值但看不出它对应哪一边，等 Victor 出完题之后再**打开**承诺。这就是第十二讲 1.3 节「承诺—挑战—应答」结构里的「承诺」到底承诺的是什么。

**翻译成人话**：洞穴故事是「用墙挡住 Victor 的视线」，真实协议是「用数学挡住 Victor 的计算能力」。两者要达到的效果完全一样：**在 Victor 出题之前，他不能知道我已经选了什么。**

带着这三个待精确化的词，我们进入第十二讲 1.2 节，把直觉逐条变成定义。

### 本节要点

1. 洞穴故事把「是否知道咒语」变成可观察的行为：**能不能从被指定的通道出来**。
2. 协议三步走：Peggy 先随机进入一条通道（**承诺**），Victor 后随机喊一侧（**挑战**），Peggy 从被喊的一侧出来（**应答**）。
3. 冒充者不知道咒语，一轮蒙对的概率是 $1/2$；$n$ 轮独立重复后是 $2^{-n}$。取 $n=20$ 或 $n=40$ 即可实用。
4. **顺序是关键**：先承诺、后挑战。若挑战先于承诺（或挑战可预测），冒充成功率升到 $100\%$。
5. 不泄露信息的理由有两层：挑战与 Peggy 的入口独立；Victor 自己就能编出分布相同的记录（模拟器的雏形）。
6. 这个套路叫**分割选择技术**：先切（承诺）、后选（挑战）、拿剩下的（应答）；公平性来自「谁先动手谁吃亏」。
7. 洞穴故事还差三件事才能变成定义：精确化「压倒的概率」「正确性」「零知识」，分别对应定义 1、2、3。

### 自测题

1. 洞穴故事里，为什么 Victor 必须**先**走到 B 点并喊话，而 Peggy 必须**先**走进通道？把这两步的顺序交换，冒充者的成功率变成多少？
2. 冒充者在第 (2) 步固定「每次只走左边」，她的单轮成功率会变吗？如果 Victor 也固定「每次只喊左边」，又会怎样？
3. 用 $2^{-n}$ 估算：要达到「十亿分之一」（约 $10^{-9}$）的冒充成功率，$n$ 至少取多少？（提示：$2^{10}\approx 10^{3}$）
4. 用「分割选择」的语言复述洞穴故事的三步，并说明 Peggy 为什么「必须真的知道咒语」才敢玩这个游戏。
5. 为什么说「Victor 自己就能编出这段录像」就意味着「交互记录不泄露信息」？请把这句话改写成一句关于「模拟器」的陈述。

<details><summary>答案</summary>

1. 因为 Peggy 必须在不了解挑战的情况下先把自己锁在一条通道里，Victor 才能用一个与她的选择独立的随机挑战去考她。顺序若交换（Victor 先宣布要她从哪边出来），冒充者直接走被要求的那条即可，成功率 $100\%$，协议完全失效。
2. 单轮成功率不变，仍是 $1/2$（她的选择与独立均匀的挑战是否相同，机会都是一半）。但若 Victor 固定喊左边，冒充者只要固定走左边，成功率就是 $100\%$——这正说明**挑战必须不可预测**。
3. $2^{-30}\approx 10^{-9}$，所以 $n\ge 30$（$2^{10}\approx 10^{3}$，故 $2^{-30}\approx 10^{-9}$）。
4. 「切」= 走进一条通道（把自己锁死）；「选」= Victor 选一侧；「拿剩下」= Peggy 从被选的一侧出来。因为密门只有咒语能开，Peggy 若不知道咒语，就只能应付一半的挑战，$n$ 轮下来必然露馅。
5. 改写成：存在一个**不掌握秘密的算法**（模拟器），它能生成与真实交互**不可区分**的记录。既然不掌握秘密也能造出同样的记录，记录里自然没有「只有掌握秘密才能产生」的信息。
