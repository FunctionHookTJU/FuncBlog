课件第 3.2 节（PPT 第 27–32 页）给出与 Shamir 方案并列的第二种门限构造：把秘密藏成高维空间的一个点，把份额做成穿过这个点的超平面。本节先讲几何图景，再落成算法，最后用课件那个 $p=73$ 的例子手算——并且要指出这个例子里的一个真实退化。

### 3.2.1 几何图景：秘密是一个点，份额是一张超平面

（PPT 第 27 页）课件介绍与 Shamir 齐名的另一个门限方案，作者是 George Blakley：

> George Blakley 发明了一个使用平面上的点的门限方案。秘密定义为一个 $t$ 维空间的点。每个分享是一个 $(t-1)$ 维的包括这个点的超平面。任何 $t$ 个超平面的交点则刚好可以决定秘密。

这段话要用「几何 + 线性代数」两种语言各读一遍。

**几何语言**：把秘密藏成高维空间里的一个**点** $Q$，然后给每个用户发一张**穿过 $Q$ 的超平面**（hyperplane）。一张超平面本身包含无穷多个点，所以单看一张不知道 $Q$ 在哪；但若干张凑在一起，它们的**公共交点**就被挤得越来越小，$t$ 张一般位置的超平面恰好把交点挤成唯一一点。

**线性代数语言**：一张超平面就是一个线性方程。$t$ 维空间里的一个点有 $t$ 个坐标，所以要 $t$ 个独立方程才定得住。这正是「$t$ 张超平面」的来历——**门限 $t$ 不是人为规定的，而是空间的维数决定的**。

【补】**什么叫「超平面」？** 在 $t$ 维空间里，由**一个**线性方程确定的 $(t-1)$ 维仿射子空间就叫超平面。具体地：

| 空间维数 $t$ | 超平面是几维 | 日常叫法 |
|---|---|---|
| 2 | 1 维 | 直线 |
| 3 | 2 维 | 平面 |
| 4 | 3 维 | 「三维体」（没有日常名字） |
| $t$ | $t-1$ 维 | 超平面 |

所以「超平面」不是某种神秘对象，只是「直线/平面」在高维的统一称呼。课件说「秘密是一个 $t$ 维空间的点，每个分享是一个 $(t-1)$ 维的超平面」，用的正是这个统一说法。

**维度是怎么被一个个方程「吃掉」的？** 这是理解整个方案的关键计数：

- 起点：$t$ 维空间，维数 $t$。
- 加第 1 个方程（第 1 张超平面）→ 剩下 $t-1$ 维。
- 加第 2 个 → $t-2$ 维。
- ……
- 加第 $t-1$ 个 → 只剩 $1$ 维（一条直线）。
- 加第 $t$ 个 → 只剩 $0$ 维（一个点）。

**翻译成人话**：每多一个「独立」的方程，解空间就被削掉一维。削到 $0$ 维时，解就是一个点——那就是秘密。所以 $t-1$ 个用户只能把秘密限制在一条直线上（还有无穷多种可能），$t$ 个用户才能把它钉成一个点。

```
   三维情形（t = 3）：秘密是空间中的一点 Q
   ┌──────────────────────────────────────────────┐
   │      ╱▔▔▔▔▔▔▔▔▔▔▔╱                            │
   │     ╱  平面 A    ╱│      三张「一般位置」的平面   │
   │    ╱            ╱ │      只有一个公共点 → 交点即 Q │
   │   ┌────────────┐  │                            │
   │   │     Q ●────│──┤ ← 三面公共交点               │
   │   │   ╱        │  │                            │
   │   │ ╱ 平面 B    │ ╱      任意两张平面只交出       │
   │   └────────────┘╱       一条直线                 │
   │    平面 C 也穿过 Q        直线上的点都「说得通」    │
   │                          → 两个分享定不出 Q       │
   └──────────────────────────────────────────────┘
   1 张面：2 维（无穷多点）→ 零信息
   2 张面：1 维（一条直线）→ 秘密在直线上，仍不确定
   3 张面：0 维（唯一交点）→ 秘密被唯一确定
```

### 3.2.2 机制 2：Blakley 的 (t,n) 门限方案

（PPT 第 28 页）课件把几何想法落成算法：

> **摘要**：可信方分配秘密 $S$ 的分享给 $n$ 个用户。
> **结果**：任何 $t$ 个用户的组提交他们的分享就可以恢复秘密 $S$。
> **(1) 建立**：可信方 $T$ 有一个秘密 $S=s_0$ 并希望分给 $n$ 个用户。
> **(1.1)** $T$ 选择一个素数 $p>s_0$。$T$ 选择模 $p$ 的随机数 $s_1,s_2,\dots,s_{t-1}$ 并在模 $p$ 的 $t$ 维空间定义一个点 $Q=(s_0,s_1,s_2,\dots,s_{t-1})$。
> **(1.2)** $T$ 随机选择 $t-1$ 个相互独立模 $p$ 的系数 $a_0^{i},\dots,a_{t-2}^{i}$，$1\le i\le n$，设定

$$y^{i}=s_{t-1}-\sum_{j=0}^{t-2}a_j^{i}\cdot s_j\pmod{p},$$

> 并安全的传输对应超平面

$$x_{t-1}=\sum_{j=0}^{t-2}a_j^{i}\cdot x_j+y^{i}$$

> 给每个 $P_i$ 作为分享。

第一次读这段会被一堆上下标绕晕，把它翻译成「三步走」：

**第一步：造点。** 秘密只占第 $0$ 个坐标，其余 $t-1$ 个坐标全部随机填满：

$$Q=(s_0,\ s_1,\ s_2,\ \dots,\ s_{t-1}),\qquad s_0=S .$$

**翻译成人话**：秘密是 $Q$ 的 $x_0$ 坐标，剩下的坐标都是随机噪声，把点「推」到一个攻击者猜不到的位置。这一步和 Shamir 方案里「随机填系数」是同一个作用：制造不确定性。

**第二步：给每个用户一张过 $Q$ 的超平面。** 第 $i$ 个用户拿到一张超平面，写法是「把最后一个坐标解出来」：

$$x_{t-1}=a_0^{i}x_0+a_1^{i}x_1+\cdots+a_{t-2}^{i}x_{t-2}+y^{i}.$$

**翻译成人话**：这张超平面的形状由前 $t-1$ 个系数 $a_0^i,\dots,a_{t-2}^i$ 决定（随机挑），位置由常数项 $y^i$ 决定。$x_{t-1}$ 的系数固定为 $1$，这样每个方程都能直接写成「$x_{t-1}$ 等于其余坐标的线性组合」，方便后面排矩阵。

**第三步：让这张超平面过 $Q$。** 把 $Q$ 的坐标代进方程，要求成立，于是 $y^i$ 被**反解**出来：

$$y^{i}\equiv s_{t-1}-\sum_{j=0}^{t-2}a_j^{i}s_j\pmod{p}.$$

**翻译成人话**：$y^i$ 不是随机挑的，而是「凑」出来的——凑到让这张超平面恰好穿过 $Q$。这一步保证「所有用户手里的超平面都过同一个点」这一最关键的结构。

**验算一遍「过 $Q$」**：把 $x_j=s_j$ 代进第 $i$ 张超平面的右边，

$$\sum_{j=0}^{t-2}a_j^{i}s_j+y^{i}=\sum_{j=0}^{t-2}a_j^{i}s_j+\Bigl(s_{t-1}-\sum_{j=0}^{t-2}a_j^{i}s_j\Bigr)=s_{t-1},$$

**翻译成人话**：带 $a_j^i$ 的那些项自动抵消，右边只剩 $s_{t-1}$，恰好等于左边 $x_{t-1}$ 的值。所以这 $t$ 个坐标确实满足方程，$Q$ 在该超平面上。

【补】**为什么把最后一个坐标单独解出来，而不是随便选一个？** 有两个好处：（1）保证每个方程里 $x_{t-1}$ 的系数都是 $1$，于是「$t$ 个未知数的 $t$ 个方程」在排列成矩阵时总是**满秩的形式**，不会出现某一行全是零的退化；（2）课件在 3.2.4 节把它写成矩阵时，最后一列整齐地都是 $-1$，行列式条件因此特别容易检查。几何上，这相当于**规定每张超平面都不与 $x_{t-1}$ 轴平行**——这是「一般位置」的一个具体实现方式。

```
   Blakley 机制 2 的信息流向（PPT 第 28 页）
   ┌────────────────────────────────────────────────────────┐
   │  T：S = s_0；掷 s_1, ..., s_{t-1}                        │
   │     → 点 Q = (s_0, s_1, ..., s_{t-1}) ∈ Z_p^t           │
   │     对每个 i = 1..n：                                    │
   │        掷 a_0^i, ..., a_{t-2}^i                          │
   │        y^i = s_{t-1} - Σ a_j^i s_j   ← 让超平面过 Q        │
   │        分享 = 超平面 x_{t-1} = Σ a_j^i x_j + y^i          │
   └───────────┬──────────┬──────────┬──────────┬────────────┘
               ▼          ▼          ▼          ▼
           ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐
           │  P_1  │  │  P_2  │  │  P_3  │  │  P_n  │
           │ 一张面 │  │ 一张面 │  │ 一张面 │  │ 一张面 │
           └───────┘  └───────┘  └───────┘  └───────┘
    每个份额都是「一张面」；面单独无限大，看不出 Q 在哪
    凑够 t 张面 → 唯一交点 Q → S = x_0 = s_0
```

### 3.2.3 恢复秘密：解一个 t 元线性方程组

（PPT 第 29 页）恢复的过程就是「把 $t$ 个方程联立解出来」：

> **(2) 恢复秘密**：任何 $t$ 或更多用户提交他们的分享。他们的分享提供了 $t$ 个不同的超平面来计算点 $Q=(s_0,s_1,s_2,\dots,s_{t-1})$。例如，$t$ 个用户 $P_i$，$1\le i\le t$。他们的超平面可以产生矩阵……

把每张超平面改写成「等号左边是系数的线性组合、右边是常数」的形式：$a_0^ix_0+\cdots+a_{t-2}^ix_{t-2}-x_{t-1}\equiv-y^i$。$t$ 个方程排在一起：

```
     ┌ a_0^1  a_1^1  ...  -1 ┐   ┌ s_0  ┐     ┌ -y^1 ┐
     │ a_0^2  a_1^2  ...  -1 │   │ s_1  │     │ -y^2 │
     │  .      .           . │ · │  .   │  ≡  │  .   │   (mod p)
     │  .      .           . │   │  .   │     │  .   │
     └ a_0^t  a_1^t  ...  -1 ┘   └s_t-1 ┘     └ -y^t ┘
        系数矩阵（由各用户的面拼成）  未知坐标      常数项
```

（PPT 第 29 页）课件给出可解条件：

> 只要矩阵的行列式模 $p$ 不等于 $0$，矩阵模 $p$ 就是可逆矩阵。恢复的秘密就是 $s_0=S$。

**翻译成人话**：把 $t$ 张面的系数拼成一个 $t$ 阶方阵，算它的行列式；只要行列式在模 $p$ 下不为零，这个方阵就可逆，用逆矩阵乘右边的常数向量就把 $(s_0,\dots,s_{t-1})$ 一次解出来，其中 $s_0$ 就是秘密。这与第十一讲 3.1.7 节 Shamir 方案「解线性方程组」的恢复路径形式完全一样，只是那里的矩阵是范德蒙矩阵（必然可逆），这里的矩阵是随机生成的（**未必**可逆）。

【补】**「行列式不为零」这个条件为什么「大概率」成立？** 固定其他系数，行列式是某些系数的多项式（次数至多 $t$）；一个非零多项式在 $\mathbb{Z}_p$ 上的零点至多有 $\deg$ 个，所以随机取值下「行列式恰好为 $0$」的概率不超过 $t/p$。$p$ 取 $10^{12}$ 量级时，这个概率小到可以忽略。但严格地说，**「大概率」不等于「必然」**——如果要求协议在每一组用户上都绝对可用，就必须在分发阶段显式挑选系数，使全部 $\binom{n}{t}$ 个子集的行列式都非零（总能做到，因为可以逐组检查、遇到退化就重掷）。课件的评述 (2) 说的正是这两层意思。

### 3.2.4 例子 2：$p=73$ 的 $(3,5)$ 方案

（PPT 第 30 页）课件给了一个可以完全手算的例子：

> 考虑建立一个 $(3,5)$ 门限方案。令 $p=73$。假定有 5 个人 A，B，C，D，E，他们可以得到如下超平面：
> A：$x_2=4\cdot x_0+19\cdot x_1+68$；B：$x_2=52\cdot x_0+27\cdot x_1+10$；C：$x_2=36\cdot x_0+65\cdot x_1+18$；D：$x_2=57\cdot x_0+12\cdot x_1+16$；E：$x_2=34\cdot x_0+19\cdot x_1+49$。

**先验证「五张面真的都过同一个点」**。课件在第 31 页给出答案是 $Q=(42,29,57)$，即 $S=x_0=42$。把 $Q$ 逐一代入五张面：

| 面 | 右边计算 | 对 $73$ 取余 | 是否等于 $x_2=57$ |
|---|---|---|---|
| A | $4\times42+19\times29+68=787$ | $787-10\times73=57$ | 是 |
| B | $52\times42+27\times29+10=2977$ | $2977-40\times73=57$ | 是 |
| C | $36\times42+65\times29+18=3415$ | $3415-46\times73=57$ | 是 |
| D | $57\times42+12\times29+16=2758$ | $2758-37\times73=57$ | 是 |
| E | $34\times42+19\times29+49=2028$ | $2028-27\times73=57$ | 是 |

**翻译成人话**：五张面确实交于同一点 $(42,29,57)$，所以任何三张面联手都能把它解出来，秘密是 $42$。

**恢复：让 A、B、C 三人联合**（PPT 第 31 页）。把三张面写成方程并移项：

```
     ┌  4  19  -1 ┐   ┌ x_0 ┐     ┌ -68 ┐
     │ 52  27  -1 │ · │ x_1 │  ≡  │ -10 │   (mod 73)
     └ 36  65  -1 ┘   └ x_2 ┘     └ -18 ┘
```

**先算行列式**，确认可解（用第一行展开）：

$$\det=4\,(27\cdot(-1)-(-1)\cdot65)-19\,(52\cdot(-1)-(-1)\cdot36)+(-1)(52\cdot65-27\cdot36).$$

逐项算：$27\cdot(-1)+65=38$，$52\cdot(-1)+36=-16$，$52\cdot65-27\cdot36=3380-972=2408$。于是

$$\det=4\times38-19\times(-16)+(-1)\times2408=152+304-2408=-1952 .$$

对 $73$ 取余：$-1952+27\times73=-1952+1971=19\ne0$。**行列式非零，矩阵可逆，可以解。**

**动手消元。** 第二式减第一式（$x_2$ 项抵消）：

$$(52-4)x_0+(27-19)x_1\equiv-10+68\pmod{73}\ \Longrightarrow\ 48x_0+8x_1\equiv58 .$$

两边乘 $8^{-1}$。先求逆元：$8\times64=512=7\times73+1$，故 $8^{-1}\equiv64$。两边乘 $64$：

$$48\times64\equiv3072-42\times73=6,\qquad 58\times64=3712-50\times73=62,$$

$$6x_0+x_1\equiv62\pmod{73}\ \Longrightarrow\ x_1\equiv62-6x_0 .$$

第三式减第一式：

$$(36-4)x_0+(65-19)x_1\equiv-18+68\pmod{73}\ \Longrightarrow\ 32x_0+46x_1\equiv50 .$$

代入 $x_1\equiv62-6x_0$：

$$32x_0+46(62-6x_0)=32x_0+2852-276x_0=-244x_0+2852\equiv50 .$$

移项：$-244x_0\equiv50-2852=-2802$，即 $244x_0\equiv2802\pmod{73}$。把系数约减：$244-3\times73=25$，$2802-38\times73=28$，于是

$$25x_0\equiv28\pmod{73}.$$

逆元：$25\times38=950=13\times73+1$，故 $25^{-1}\equiv38$，得

$$x_0\equiv28\times38=1064\equiv1064-14\times73=42 .$$

回代：$x_1\equiv62-6\times42=62-252=-190\equiv-190+3\times73=29$；再由 A 式算 $x_2=787\equiv57$。所以

$$(x_0,x_1,x_2)=(42,29,57),\qquad S=x_0=42 .$$

**翻译成人话**：三人一通消元，解出的点与所有面原本的交点完全一致，秘密 $42$ 到手。而且换个组合（比如 B、D、E）会解出同一个点——这就是「任意 $3$ 个都行」。

### 3.2.5 一个必须指出的退化：A 与 E 两个人就能定出秘密

按 $(3,5)$ 门限的定义，任意 $2$ 个人都不该定出 $S$。但在课件这个例子中，**A 和 E 两张面联立就能直接算出 $x_0=42$**。这不是巧合，检查一下它们的系数：

$$A:\ x_2=4x_0+\mathbf{19}x_1+68,\qquad E:\ x_2=34x_0+\mathbf{19}x_1+49 .$$

两张面的 $x_1$ 系数**相同**（都是 $19$）。把两式相减时，$x_1$ 项和 $x_2$ 项**同时**被消掉，只剩一个一元一次方程：

$$4x_0+68\equiv34x_0+49\pmod{73}\ \Longrightarrow\ 19\equiv30x_0\pmod{73}.$$

由于 $30\times56=1680=23\times73+1$，即 $30^{-1}\equiv56$，得

$$x_0\equiv19\times56=1064\equiv42\pmod{73}=S .$$

**翻译成人话**：A 与 E 的两张面在「$x_1$ 方向上是同一张面」，它们相减之后变成「只含 $x_0$ 的方程」，于是 $x_0$ 被直接钉死。**这是对 $(3,5)$ 门限的一次实际破坏**：【勘误】课件把这个例子当作「任意 3 个可恢复、任意 2 个不行」的 (3,5) 门限实例（PPT 第 30–31 页），但 A、E 两个份额已经足以恢复 $S=42$，与门限定义不符。

**这条弯路值得记住，因为它暴露了向量方案的固有弱点**：$t-1$ 个超平面的交是一条**直线**，秘密是这条直线上所有点的 $x_0$ 坐标的集合。要做到「零信息」，必须让这条直线**在 $x_0$ 方向上不固定**（$x_0$ 取遍整个 $\mathbb{Z}_p$）；而一旦两个用户的超平面在「除 $x_0$ 之外的其他方向上完全重合」（本例是 $x_1$ 系数相同），这条直线就会落在「$x_0$ 为常数」的薄片里，秘密立刻暴露。

一般地，把每张面写成行向量 $(a_0^{i},\dots,a_{t-2}^{i},-1)$，则「$(t-1)$ 张面的交线不固定 $x_0$」等价于这些行拼成的 $(t-1)\times t$ 矩阵满足：**删去第 $0$ 列之后剩下的 $(t-1)\times(t-1)$ 子式非零**（子式为零时，交线方向在 $x_0$ 方向上没有分量，$x_0$ 就成了常数）。这个子式是系数的 $t-1$ 次多项式，随机取值下为零的概率不超过 $(t-1)/p$；本例 $t=3$ 时恰为 $1/p$。$p=73$ 时，$\binom{5}{2}=10$ 对超平面里至少出现一对「$x_1$ 系数相同」的概率约 $1-(1-1/73)^{10}\approx13\%$，课件恰好撞上了。**Shamir 方案不存在这类退化**：它用的是范德蒙矩阵，只要编号互不相同，行列式自动非零（见第十一讲 3.1.8 节定理 1）。这个对比是下面表格里最重要的一行。

### 3.2.6 评述：向量方案的代价与 Shamir 的对比

（PPT 第 32 页）课件给了三条评述，逐条读：

> **(1) 注意只有一个坐标分量可以用来存放秘密。** 如果秘密被存放于多个坐标，在得到部分分享的情况下将给攻击者找到秘密以一定的优势。

**为什么？** 假设把秘密拆成两个坐标 $(s_0,s_1)$。拿到 $t-1$ 张面时，解空间是一条直线；这条直线投影到 $(s_0,s_1)$ 平面上一般仍是一条直线，上面有 $p$ 个点。于是攻击者的候选秘密从 $p^{2}$ 个降到约 $p$ 个——**搜索空间开方，安全强度直接减半**。所以「秘密只占一个坐标」不是习惯，而是安全的必要条件。

> **(2) 由于 $p$ 的值通常很大，虽然不能确保矩阵可逆，但有非常大的可能可逆。当然，也有方法可以选择系数 $a_0^{i},\dots,a_{t-2}^{i}$，使得矩阵总是可逆。**

3.2.3 节末尾已经解释过：随机系数的退化概率 $\le t/p$，可以忽略；但「可忽略」不等于「零」，要求绝对可靠就得在分发时逐组检查（或改用结构性构造）。

> **(3) 这个方案需要每个用户相对 Shamir 方案保存更多的信息。** 即这个方案是 $(a_0^{i},\dots,a_{t-2}^{i},y^{i})$ 而 Shamir 方案是 $(x,y)$。

这一条是**存储代价**的对比：Blakley 的份额是 $t$ 个数（$t-1$ 个系数加 $1$ 个常数项），Shamir 的份额是 $2$ 个数（公开编号 $x$ 加一个值 $y$，若要保密其实只有 $1$ 个数）。$t$ 越大差距越明显。

把两个方案完整地摆在一起：

| 对比项 | Shamir 多项式方案 | Blakley 向量方案 |
|---|---|---|
| 几何图景 | $t$ 个点唯一确定一条曲线 | $t$ 张超平面交于一点 |
| 秘密的表示 | 多项式的常数项 $f(0)$ | 空间中点的 $x_0$ 坐标 |
| 份额的形状 | 一个数 $y_i$（外加公开编号） | $t$ 个数 $(a_0^i,\dots,a_{t-2}^i,y^i)$ |
| 恢复算法 | Lagrange 插值 / 解线性方程组 | 解线性方程组（高斯消元） |
| 可解条件 | **自动成立**：编号互不相同即可 | 需行列式非零（「一般位置」） |
| 少于 $t$ 份的安全性 | **完美**（信息论，已证） | 一般位置下完美，但存在退化子集泄露（见 3.2.5） |
| 份额存储量 | 理想：$1$ 个数 | 非理想：$t$ 个数 |
| 计算代价 | 在线 $O(t)$（预计算常数后） | $O(t^{3})$（消元） |
| 加新用户 | 容易：算 $f(n+1)$ | 容易：再给一张过 $Q$ 的面 |
| 主要优势 | 简单、理想、无退化 | 几何直观，便于讲「信息分散」的思想 |

【补】**两个方案的「对偶」关系**值得一提：Shamir 是「**一个方程在 $t$ 个不同点上的取值**」，Blakley 是「**$t$ 个不同方程在同一点上的约束**」。前者的可解性由「点互不相同」保证，后者的可解性由「面互不平行（行列式非零）」保证。插值与解线性方程组在数学上是同一件事的两种写法——这也解释了为什么第十一讲 3.1.7 节 Shamir 的恢复可以写成矩阵求逆，而本节 Blakley 的恢复也可以写成插值。理解了这层对偶，两个方案就不必当作两个孤立的知识点去背。

【补】**实际系统为什么几乎都用 Shamir 而不是 Blakley？** 除了「份额更小」和「无需检查行列式」这两条硬优势，Shamir 还有一个工程上的好处：它的份额天然是「一个 $\mathbb{Z}_p$ 中的元素」，可以直接套用现成的秘密共享库与门限签名协议（如门限 ECDSA、门限 Schnorr 的 Shamir 变体）；而 Blakley 的份额是一整张超平面的系数，向量很长，做多方计算时通信量成倍增加。Blakley 方案今天更多出现在教材与几何直观的讲解中。
