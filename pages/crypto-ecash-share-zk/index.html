如何使用这份讲义

这份讲义把天津大学《密码学》课程最后三讲——第十讲《电子商务与电子现金》（49 页）、第十一讲《秘密分享与游戏》（60 页，另附 3 页 Shamir 证明）、第十二讲《零知识证明技术》（52 页）——重讲了一遍。它不是 PPT 的缩写，而是按课件原有的节次顺序，把每一页的知识点用初学者跟得上的速度重写，并把课件默认你已掌握、其实多数人并没有掌握的前置知识补上。

本册有一个特别之处：三讲几乎不发明新的加密算法，而是把前几册的零件（Hash 函数、RSA、离散对数、数字签名）组装成协议，去做单靠算法做不到的事——让商家看不到卡号、让银行看不到定单、把一把钥匙拆给五个人、隔着电话公平地掷硬币、证明"我知道口令"却一个字都不说。所以第 0 章不是可有可无的复习，而是本册的入口：0.1 给地图，0.2 补数论（二次剩余与模平方根），0.3 补安全观（三类困难问题与可证明安全），0.4 补协议语言（承诺、盲化、交互）。

这份讲义和 PPT 的关系

  • 严格跟着三份 PPT 的目录走（同样的 1、2、3… 小节编号），课件里出现的每个知识点在讲义里都有对应段落，关键处标 （PPT 第 N 页），可以直接翻回原课件核对。
  • 公式与算法框都对照过逐页截图：PPT 导出的 PDF 会把公式抽成散乱字符，凡涉及式子的页，撰写者都是先看逐页位图再落笔的。若你手头的课件版本与讲义对不上，以你的课件为准，并欢迎反馈。
  • 课件只给结论的地方，讲义补"为什么"；课件直接甩出来的式子，讲义拆成一步步推导，并给一个能用手算核验的小例子。
  • 正文里橙色补徽章表示"课件没讲、但初学必需"的内容（术语、类比、易错点、历史背景）；橙红色勘误徽章表示"课件此处确有笔误或不严谨"，本册这种地方很少，出现时一定附订正说明。

三讲之间是怎么串起来的

三讲不是三个孤立的专题，它们共享同一套骨架：

  1. 都用"承诺—挑战—应答"防作弊。第十讲的双重签名把"承诺"落在 Hash 摘要上，第十一讲的投币与扑克把"承诺"落在平方剩余与密钥上，第十二讲的零知识把"承诺"落在随机数 rrr 的平方上。读懂一个，另外两个就有模板可套。
  2. 都靠"随机数把猜中概率压到可忽略"。没有随机挑战，协议就只能靠"对方老实"；有了随机挑战，骗子每轮只有 1/21/21/2、1/41/41/4 或 1/q1/q1/q 的机会。
  3. 都把安全押在同一批困难问题上。第 0.3 节那张分布表值得反复回看：哪一讲踩的是 RSA/分解、哪一讲踩的是离散对数、哪一讲踩的是模平方根。
  4. 都在去掉"可信第三方"。电子现金要摆脱银行实时在线、电话投币要摆脱裁判、零知识鉴别要摆脱"把口令交给对方验证"。去掉裁判的办法，就是让双方互相用协议约束。

关于第 0 章的特殊说明

第 0 章没有对应的 PPT 页，它是为这一册新写的补课，所以：

  • 它不按"课件页码"组织，而按"读后面三讲时会在哪里卡住"组织；
  • 里面的所有手算例子都是本讲义自己选的（p=11p=11p=11 的二次剩余表、n=77n=77n=77 与 n=33n=33n=33 的四个平方根、n=33n=33n=33 的盲签名），目的是让你能拿纸笔复算，而不是背结论；
  • 它标注的「（见第十讲 2.1 节）」这类提示，是回到本册对应小节对照的入口，读到那里时回来核对即可。

正文里的约定

  • 每个公式后面都有一句「翻译成人话」：先看白话再看符号，是本讲义建议的读法。
  • 手算例子的数字都能在纸上核验：全部用小素数、小模数（如 p=11p=11p=11、n=77n=77n=77、n=33n=33n=33），照着算一遍比读十遍有用。
  • 每节末尾有「本节要点」与「自测题」，自测题答案默认折叠，先自己做再看。
  • 附录是复习主力：附录 A 术语中英对照，附录 B 协议与公式速查（每条写"什么时候用"），附录 C 常见疑问 FAQ，附录 D 跨讲综合自测。考前只看附录 B + D 就能覆盖主要考点。
  • 章节编号与课件一致：第 0 章用 0.1～0.4，第十讲用 1/2/3，第十一讲用 1～5，第十二讲用 1～5，附录用 A～D。

一句话概括本册

前三册把密码学的零件一件件造好，这一册用这些零件装出三台"防作弊的机器"：一台让交易只暴露该暴露的部分（第十讲），一台把秘密拆给多人且拆得公平（第十一讲），一台让人能证明自己知道秘密而不泄露秘密（第十二讲）。
