A.1 密码学通用术语

中文 英文 一句话解释
明文 Plaintext 原始消息
密文 Ciphertext 加密后的消息
加密 / 解密 Encryption / Decryption 明密文相互转换
密钥 Key 控制加密解密的那串比特
对称密码 Symmetric Cipher 加解密同一把密钥
非对称密码 / 公钥密码 Asymmetric / Public-key Cipher 公钥加密、私钥解密
分组密码 Block Cipher 按固定长度分块加密
流密码 Stream Cipher 逐比特/逐字节加密
分组长度 Block Size 一个分组多少比特
明文 / 密文攻击 Known / Chosen Plaintext Attack 攻击者掌握信息的强弱等级
强力攻击 / 穷尽搜索 Brute-force / Exhaustive Search 试遍所有密钥
差分分析 Differential Cryptanalysis 追踪"差分"的传播来求密钥
线性分析 Linear Cryptanalysis 用线性逼近描述算法行为
截断攻击 Truncated Differential Attack 只追踪"差分是否非零"
平方攻击 / 积分攻击 Square / Integral Attack 利用整字节取遍所有 256 值的积分性质
侧信道攻击 Side-channel Attack 借助时间、功耗、电磁等泄露信息
定时分析攻击 Timing Attack 靠测量运算耗时反推数据
陷门 Trapdoor 藏在算法里的后门
混淆 / 扩散 Confusion / Diffusion 香农两原则：藏关系 / 铺影响
代换 / 置换 Substitution / Permutation 换值 / 换位置
S-盒 S-box (Substitution box) 实现代换的查表
雪崩效应 Avalanche Effect 输入变 1 位，输出变很多位
弱密钥 / 半弱密钥 Weak / Semi-weak Key 会让算法退化的特殊密钥
中间人攻击 Meet-in-the-Middle Attack 两头夹击，把 2n2^n2n 降到 2(n/2)2^{(n/2)}2(n/2)
认证加密 Authenticated Encryption 同时保证机密性和完整性
盐 Salt 掺进口令的随机串，防批量字典攻击
单向函数 One-way Function 正向易、反向难
哈希 / 散布函数 Hash Function 把任意长度映射成定长摘要
生日攻击 Birthday Attack 找碰撞只需约 √N 次尝试
初始向量 / 初始参数 IV (Initialization Vector) 模式下引入随机性的外部输入

A.2 DES 专用术语

中文 英文 / 缩写 说明
数据加密标准 DES 64 位分组、56 位密钥、16 轮
费斯妥结构 Feistel Network 左右两半交替处理的结构
初始置换 / 逆初始置换 IP/IP−1IP / IP^{-1}IP/IP−1 DES 首尾的固定比特重排
扩张函数 Expansion Function E 32→48 比特
置换函数 Permutation P 32→32 比特
密钥置换选择 PC-1 / PC-2 64→56、56→48
循环左移 LShift / Rotate Left 密钥调度中的移位
三重 DES 3DES / Triple DES EK1(DK2(EK1(m)))E_{K1}(D_{K2}(E_{K1}(m)))EK1​(DK2​(EK1​(m)))
双重 DES Double DES 已被中间人攻击击穿

A.3 AES 专用术语

中文 英文 / 缩写 说明
高级加密标准 AES 128 位分组、128/192/256 位密钥
赖恩达尔 Rijndael AES 的前身，最终胜出的算法
字节转换 ByteSub / BS 逐字节查 S-盒（非线性层）
移动行变换 ShiftRow / SR 各行循环左移 0/1/2/3 位
混合列变换 MixColumn / MC 乘固定循环矩阵，逐列扩散
轮密钥加密变换 AddRoundKey / ARK 异或轮密钥
逆字节转换 / 逆移动行 / 逆混合列 / 逆轮密钥 IBS / ISR / IMC / IARK 对应的四个逆层
轮常量 Rcon (Round Constant) T 变换里首字节异或的常量
字节代换字 SubWord 对 4 字节各查一次 S-盒
循环上移字 RotWord 4 字节循环上移一位
有限域 / 伽罗瓦域 GF / Galois Field AES 的运算地基
既约多项式 / 不可约多项式 Irreducible Polynomial 用来构造 GF(pn)GF(p^{n})GF(pn) 的"素数"
仿射变换 Affine Transformation 线性变换 + 平移
代换-置换网络 SP Network AES 的结构类型
电码本模式 ECB 各分组独立加密
密码分组链接 CBC 前一段密文与当前明文异或后再加密
密码反馈 CFB 把分组密码当流密码用
计数器模式 CTR 现代并行化模式
认证加密模式 GCM / CCM 加密 + 认证一体
