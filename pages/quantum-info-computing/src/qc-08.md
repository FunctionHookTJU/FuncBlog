### 逻辑上，CHSH 左端最大能到多少

课件第 26 页以一个纯逻辑问题开场（PPT 第 26 页）：

> **问题**：逻辑上，CHSH 不等式左端的最大可能值是多少？

**答案：$4$。** 推理只用一句话：$S=C_{A_1B_1}+C_{A_1B_2}+C_{A_2B_1}-C_{A_2B_2}$ 中的每一项都是 $\pm1$ 结果的乘积的平均，因此每个 $C\in[-1,1]$；把三个符号取 $+$、一个取 $-$，最大就是 $|S|=1+1+1+1=4$。

于是我们有了**三个数字**，它们构成第一讲的地图（PPT 第 22–26 页）：

| 世界 | CHSH 左端的最大值 $\lvert S\rvert$ | 数值 | 依据 |
|---|---|---|---|
| 局域隐变量 / 经典概率 | $2$ | $2$ | CHSH 不等式（1.6 节） |
| 量子力学 | $2\sqrt2$ | $\approx2.828$ | Tsirelson 边界（PPT 第 23 页） |
| 一般非信号盒子 | $4$ | $4$ | 逻辑上界（本页） |

**翻译成人话**：经典世界顶到 $2$；量子世界可以多走 $41\%$（$2\sqrt2/2=\sqrt2$）到 $2\sqrt2$；而纯粹从「不许传信 + 结果只有两种」这两条出发，还留着一大段空白（$2\sqrt2$ 到 $4$）——**量子力学为什么恰好停在 $2\sqrt2$，而不是 $4$？** 这就是本节的中心问题。

### PR Box：停在 $4$ 的那个「盒子」

课件第 26 页构造了一个把 CHSH 顶到 $4$ 的装置（PPT 第 26 页）：

> 假定 $A_0,A_1,B_0,B_1$ 四个观测量所对应的测量值均为 $0$ 和 $1$，$a$ 和 $b$ 分别是两端观测量的索引，$x$ 和 $y$ 是两端的测量值，则 $a,b,x,y$ 均取值于 $\{0,1\}$；PR-box 定义为

$$P(x,y\mid a,b)=\tfrac12\,\delta_{a\cdot b,\ x\oplus y}.$$

记号说明（三条都要看清）：

- $a\cdot b$ 是 $a$ 与 $b$ 的**乘积**（对 $0/1$ 而言就是「逻辑与」AND），取值 $0$ 或 $1$；
- $\oplus$ 是**异或**（XOR），即 $x\oplus y=(x+y)\bmod 2$；
- $\delta_{u,v}=1$ 当且仅当 $u=v$，其余情形为 $0$。

**翻译成人话**：两端的输出被要求满足一个**约定**——「$x$ 与 $y$ 的异或」必须等于「两端索引的与」。当 $a\cdot b=0$（至少一个索引是 $0$）时，要求 $x=y$：$(0,0)$ 或 $(1,1)$ 各以 $1/2$ 概率出现。当 $a\cdot b=1$（两个索引都是 $1$）时，要求 $x\neq y$：$(0,1)$ 或 $(1,0)$ 各以 $1/2$ 概率出现。

把四种输入组合列出来（$x,y$ 用 $\pm1$ 记法 $(-1)^x,(-1)^y$ 方便算）：

| $a$ | $b$ | $a\cdot b$ | 允许的 $(x,y)$ | 概率 | $C_{A_aB_b}=E[(-1)^{x+y}]$ |
|---|---|---|---|---|---|
| $0$ | $0$ | $0$ | $(0,0),(1,1)$ | $1/2,1/2$ | $+1$ |
| $0$ | $1$ | $0$ | $(0,0),(1,1)$ | $1/2,1/2$ | $+1$ |
| $1$ | $0$ | $0$ | $(0,0),(1,1)$ | $1/2,1/2$ | $+1$ |
| $1$ | $1$ | $1$ | $(0,1),(1,0)$ | $1/2,1/2$ | $-1$ |

于是课件第 26 页的结论（PPT 第 26 页）：

$$C_{A_0B_0}+C_{A_0B_1}+C_{A_1B_0}-C_{A_1B_1}=1+1+1-(-1)=4 .$$

**翻译成人话**：四项里前三项都是 $+1$，最后一项是 $-1$；按 CHSH 的方式组合（最后一项取负号），四个数全变成 $+1$，加起来正好是逻辑上界 $4$。**它把 CHSH 砸穿了。**

【补】**PR Box 满足非信号原则。** 检验一下边缘分布：

$$P(x\mid a,b)=\sum_y P(x,y\mid a,b)=\tfrac12\sum_y\delta_{a\cdot b,\,x\oplus y}=\tfrac12 .$$

对每一对 $(a,b)$，$x$ 的边缘分布都是均匀的 $(1/2,1/2)$，与 $b$ 无关；$y$ 的边缘同理。**翻译成人话**：PR Box 里的「瞬时影响」也是看不见的——不管另一端把索引拧到哪一档，这一端的统计都不变。所以它**不违反非信号原则**，却把 CHSH 顶到 $4$。

【补】**PR Box 从哪来、为什么重要。** 它以 Popescu 与 Rohrlich 1994 年的文章《量子非局域性作为一条公理》命名。它的意义是**把「非局域性」与「量子力学」剥离开了**：以前人们以为「违背 Bell 不等式的关联」就意味着量子力学，PR Box 表明还存在着**比量子更强的非局域关联**，而且它们同样不违反因果结构（不传信）。于是出现了一个尖锐的问题：**是什么把量子关联限制在 $2\sqrt2$，而不是 $4$？** 这个问题至今没有一个公认的「物理原理」答案。

### 量子关联在非信号盒子集合中的位置

把三类盒子（box，指只由输入输出联合分布 $P(x,y\mid a,b)$ 描述的装置）画成嵌套结构（PPT 第 26 页的问题所要的图）：

```
┌───────────────────────────────────────────────┐
│  所有盒子（概率分布，结果二元）                │
│  ┌─────────────────────────────────────────┐  │
│  │ 非信号盒子（边缘分布与对方设置无关）    │  │
│  │  ┌───────────────────────────────────┐  │  │
│  │  │ 量子关联（可由某量子态实现）      │  │  │
│  │  │  ┌─────────────────────────────┐  │  │  │
│  │  │  │ 经典 / LHV（|S| ≤ 2）        │  │  │  │
│  │  │  └─────────────────────────────┘  │  │  │
│  │  │     |S| ≤ 2√2  ◀── Tsirelson      │  │  │
│  │  └───────────────────────────────────┘  │  │
│  │     PR Box 在量子集合之外：|S| = 4      │  │
│  └─────────────────────────────────────────┘  │
└───────────────────────────────────────────────┘
```

**翻译成人话**：从里到外依次是「经典可达」⊂「量子可达」⊂「非信号」⊂「所有分布」。PR Box 落在**非信号集合之内、量子集合之外**的那一圈里。

【补】**这张图的几个值得记住的性质**：

1. **每个集合都是凸集**：两个可实现分布的概率混合仍然可实现（量子集合的凸性来自密度算子的凸性）。
2. **量子集合严格包含经典集合**：由 CHSH 判决（1.6 节）决定，实验已经确认这件事。
3. **量子集合严格小于非信号集合**：由 Tsirelson 边界 $2\sqrt2<4$ 保证，PR Box 就是那个「出圈」的例子。
4. **PR Box 不可由量子态实现**：这不是技术问题，而是定理。想实现它，必须放弃量子力学。
5. 人们尝试用各种「物理原理」去**导出** $2\sqrt2$：信息因果性（information causality）、宏观定域性（macroscopic locality）、通信复杂度等。它们各自能推出某些界，但都还不是公认的「唯一原理」。**这也是本节的开放问题所在。**

### 课程大作业：在经典设置下设计一个违背 CHSH 的协议

课件第 27 页给出本课程的大作业（PPT 第 27 页）：

> **课程大作业**：在经典设置下，设计一个协议，实现 CHSH 不等式的违背。
> **线索**：考虑在经典设置下实现 CHSH 不等式违背需要何种条件？
> **问题**：说明你设计的在经典设置下的不等式违背机制与量子设置下的不等式违背机制有何区别？

课件这一页的配图很重要，它是提示的全部（PPT 第 27 页）：

```
            A1   A2                        B1   B2
             ▲    ▲                         ▲    ▲
          ┌──┴────┴──┐                  ┌───┴────┴───┐
          │ Free will │                  │ Free will  │   ← 设置选择「自由」是假设
          └────┬─────┘                  └─────┬──────┘
        ┌──────┴──────┐                ┌──────┴──────┐
        │    Alice    │                │     Bob     │
        └──────▲──────┘                └──────▲──────┘
               └───────────┬───────────────────┘
                     源：共享 λ（共享随机性 / 纠缠）
```

**图里那两朵「Free will」云就是答案**：CHSH 不等式的证明不仅用到「局域性」和「结果是 $\lambda$ 的函数」，还用到一个往往被忽略的假设——**两端对测量设置的选取与 $\lambda$ 无关**（1.1 节的**测量独立性**，也叫自由意志假设）。想用纯经典资源违背 CHSH，就必须让证明的某一步失效。

【补】**先看清定理的三条腿。** 1.6 节的推导只用到三件事：

1. **实在论/决定性**：对每个 $\lambda$，四档结果 $A_1,A_2,B_1,B_2$ 都是 $\pm1$ 的确定值；
2. **局域性**：Alice 的结果不依赖 $b$，Bob 的结果不依赖 $a$；
3. **测量独立性**：设置 $(a,b)$ 的分布与 $\lambda$ 的分布**无关**，即 $p(\lambda\mid a,b)=p(\lambda)$。

**只要三条同时成立，就必有 $|S|\le2$。** 因此任何经典协议想越界，必须**明确地**放弃其中至少一条，并且在报告里证明自己确实放弃了它。下面给出两条可行的路线（都只是「思路模板」，具体参数与表述请自己补全）。

#### 路线一：放弃局域性（允许两端通信）

**协议（1 比特经典通信版）**：

1. 裁判给 Alice 设置 $a\in\{0,1\}$，给 Bob 设置 $b\in\{0,1\}$；
2. Alice 把自己的 $a$ 通过一条**经典信道**发给 Bob；
3. Alice 输出 $x=0$；
4. Bob 输出 $y=a\cdot b$（逻辑与）。

**计算 $S$**：由 $x\oplus y=a\cdot b$ 得 $C_{A_aB_b}=E\big[(-1)^{x+y}\big]=(-1)^{a\cdot b}$，于是

$$C_{A_0B_0}=C_{A_0B_1}=C_{A_1B_0}=+1,\qquad C_{A_1B_1}=-1,$$

$$S=1+1+1-(-1)=4 .$$

**翻译成人话**：两端只要串一句话，就能把 CHSH 顶到逻辑上界 $4$。这条路线**放弃的是局域性**：Bob 的输出显式依赖 Alice 的设置（等价地说，$P(y\mid a,b)$ 依赖 $a$，Alice 可以用她的旋钮给 Bob 发信号）。**注意它在实验意义上「违背 CHSH」是平凡的**——没有人会否认通信能破坏不等式；但把它写清楚，能让你确认「局域性」在证明里的确切位置。

#### 路线二：放弃测量独立性（共享计划 → 实现 PR Box）

**协议（超决定论/共享计划版）**：

1. 源在实验开始前抽一个共享随机数 $\lambda=(a^{*},b^{*},x^{*},y^{*})$，要求在 $\{0,1\}^4$ 中满足 $x^{*}\oplus y^{*}=a^{*}\cdot b^{*}$，并在满足条件的 $8$ 个四元组上**等概率**抽取；
2. **两端设置不是自由选取的**，而由同一个源决定：$a=a^{*}$、$b=b^{*}$（这就是被放弃的那条假设）；
3. Alice 的确定性策略：$x=f_A(a,\lambda)=x^{*}$（若 $a\neq a^{*}$，输出任意固定值，例如 $0$）；
4. Bob 的确定性策略：$y=f_B(b,\lambda)=y^{*}$（若 $b\neq b^{*}$，输出任意固定值，例如 $0$）。

**核对联合分布**：给定设置 $(a,b)$ 后，$\lambda$ 被限制在 $8$ 个四元组中满足 $a^{*}=a,b^{*}=b$ 的那 $2$ 个上，各以 $1/2$ 的条件概率出现。于是

$$P(x,y\mid a,b)=\tfrac12\,\delta_{a\cdot b,\ x\oplus y},$$

即**精确实现 PR Box**，从而 $S=4$。

**核对非信号性**：由上式求和得 $P(x\mid a,b)=P(y\mid a,b)=1/2$，与对方设置无关——**这个协议本身不传信**（这是它比路线一「更像量子」的地方）。

**它到底放弃了什么？** 就是测量独立性：$\lambda$ 决定了 $(a,b)$，所以

$$p(\lambda\mid a,b)\neq p(\lambda),$$

条件化到观测到的设置上会**偏置**隐变量的后验分布。1.6 节里把逐 $\lambda$ 不等式升级成 CHSH 的那一步（对 $\lambda$ 求平均时用的是与设置无关的 $p(\lambda)$）因此失效。

【补】**一个极有说服力的自检**：把路线二的装置原封不动，只把第 2 步改成「裁判**自由、随机、与源无关**地选取 $(a,b)$」。此时模型重新满足「$x=f_A(a,\lambda)$、$y=f_B(b,\lambda)$、$\lambda$ 与设置独立」三条，**于是按定理必然 $|S|\le2$**——同一个装置，一改设置来源就再也违背不了。这个对照实验说明：**违背完全来自「设置与 $\lambda$ 的相关性」，而不是来自什么巧妙的输出规则。** 报告里最好把这一步做出来。

#### 路线三（选做）：后选择 / 不公平采样

只保留满足某种条件的实验轮次（例如只保留 $x,y$ 都等于 $1$ 的轮次再统计），可以人为制造出 $S>2$。它放弃的是「实验数据是无偏的公平样本（fair sampling）」。这是历史上真实存在过的实验漏洞（1.6 节的探测效率漏洞），作为选做路线可以尝试，但要在报告里明确说明它**不属于理论推导的三条假设**，而属于实验层面的附加前提。

#### 报告要求与评分要点（建议）

1. **协议描述**：资源（共享随机性？经典信道？），流程（谁在什么时候收到什么），策略（显式的 $f_A,f_B$）。
2. **形式化**：写出 $P(x,y\mid a,b)$ 的表达式，而不是只写文字描述。
3. **数值**：算出四个 $C_{A_aB_b}$ 与 $S$，并交代 $x,y$ 与 $\pm1$ 的对应约定（例如 $A_a=(-1)^x$）。
4. **非信号性检验**：算 $P(x\mid a,b)$、$P(y\mid a,b)$；若协议传信，要说明传了多少比特、经由哪条信道。
5. **假设审计**：明确写出「我放弃的是哪一条假设」，并给出**证明性**的说明（例如路线二里的 $p(\lambda\mid a,b)\neq p(\lambda)$）。
6. **与量子机制对比**：见下表。

| 对比项 | 量子力学的违背机制 | 本作业的经典违背机制 |
|---|---|---|
| $\lvert S\rvert$ 的大小 | $2\sqrt2$（Tsirelson 边界，严格小于 4） | 路线一、二都可以做到 $4$ |
| 设置从哪来 | 自由、随机、与 $\lambda$ 独立 | 路线二：由 $\lambda$ 决定；路线一：设置被用作通信内容 |
| 是否传信 | 不传信（非信号原则） | 路线二不传信；路线一传信 |
| 被放弃的假设 | 不放弃任何假设；结论是 **LHV 不存在** | 放弃局域性（路线一）或测量独立性（路线二） |
| 物理含义 | 关联本身超出经典可达集合 | 「设置选择」被纳入了协议，或两端被允许通信 |
| 实验上能否实现 | 已被 1980 年代以来一系列实验证实 | 逻辑上自洽，但它违背了 Bell 检验的**自由选择前提**，因此不被认为是对量子力学的威胁 |

【补】**几条常见错误，写作业前先避开**：

- ❌ 只说「让 Alice 和 Bob 提前串通好」而不写出联合分布与 $S$ 的计算。**串通本身不违背任何不等式**，必须指出被放弃的是哪条假设。
- ❌ 把「共享随机性」当成违规资源。共享 $\lambda$ 是 LHV 的**标准配置**，不违反任何假设；违规的是 $\lambda$ 与**设置**相关。
- ❌ 用「测量结果不随机」来制造违背。$S$ 是四个相关函数的组合，结果确定并不自动给 $S>2$（1.4 节已经演示了三个 Pauli 方向上的确定性模型，$S$ 反而只有 $0$）。
- ❌ 忘记交代 $0/1$ 与 $\pm1$ 的换算约定，导致符号混乱。
- ✅ 加分项：做出上面那个对照实验（同一装置 + 自由设置 → $S\le2$），或证明 PR Box 的非信号性。

### 小结

**一句话串起第一讲**：EPR 用「定域性 + 不干扰」论证不兼容的物理量可以同时确定，而 Bell 把这个哲学争论翻译成一个可测量的不等式——实验站在量子力学一边，于是我们得到「非局域关联存在、但不违反非信号原则」这一对看似矛盾、实则严格自洽的结论。

### 核心结论清单

1. **EPR 的立场**：定域实在论（局域隐变量模型），认为不兼容性只是测量能力的不足；量子力学因无法建模「同时确定」而不完备（1.1、1.3 节）。
2. **反相关 Bell 态**：$|\Phi^-\rangle=(|01\rangle-|10\rangle)/\sqrt2$ 满足 $\langle\sigma_i\otimes\sigma_j\rangle=-\delta_{ij}$；一般关联为 $E(A\cdot B)=-u\cdot v$；单端约化态 $I/2$（1.2 节）。
3. **LHV 模型的局限**：等概率配对 $(\lambda_s,\lambda_{-s})$ 能精确复现全部 Pauli 关联，但对旋转方向的测量没有「条目」，这为不等式留出了空间（1.4 节）。
4. **非信号原则**：任何一端的边缘统计不受对方测量或局域操作影响；它是量子形式化的定理，因此不能靠「观察瞬时影响」判决世界观（1.5 节）。
5. **CHSH 不等式**：$|S|\le2$，其中 $S=C_{A_1B_1}+C_{A_1B_2}+C_{A_2B_1}-C_{A_2B_2}$；它对所有 LHV 与经典概率模型成立（1.6 节）。
6. **Tsirelson 边界**：量子力学可达 $|S|=2\sqrt2$；1980 年代以来实验一致违背 CHSH，2022 年诺贝尔奖授予 Aspect、Clauser、Zeilinger（1.6 节）。
7. **三条边界**：经典 $2$、量子 $2\sqrt2$、一般非信号 $4$；PR Box 达到 $4$ 且仍满足非信号原则，但不可由量子态实现（1.7 节）。
8. **大作业的要点**：经典协议要违背 CHSH，必须放弃局域性、测量独立性或公平采样中的至少一条；放弃测量独立性即得到 PR Box，是最「像量子」的经典越界方式（1.7 节）。
9. **最重要的区分**：**非局域关联 ≠ 超光速通信。** 前者已被实验确立，后者被非信号原则禁止。

5. 列出 CHSH 推导所依赖的三条假设。课程大作业要求「在经典设置下违背 CHSH」，请指出至少两条可行路线及各自放弃的假设。
6. 在你设计的经典协议里，如果把设置改为「自由随机选取」，$S$ 会怎样变化？为什么？
7. 用自己的话说明：量子机制的违背与经典协议的违背，最本质的区别是什么？
8. 判断：PR Box 既然不违反非信号原则，就应该能用量子态实现。

<details><summary>答案</summary>

1. $4$。$S$ 是四项相关函数的组合，每项 $C\in[-1,1]$，三个取 $+$、一个取 $-$ 时最大为 $1+1+1+1=4$。
2. $P(x,y\mid a,b)=\tfrac12\delta_{a\cdot b,\,x\oplus y}$。当 $a\cdot b=0$ 时 $x=y$，$C=+1$；当 $a\cdot b=1$ 时 $x\neq y$，$C=-1$。于是 $C_{A_0B_0}=C_{A_0B_1}=C_{A_1B_0}=+1$，$C_{A_1B_1}=-1$，$S=1+1+1-(-1)=4$（PPT 第 26 页）。
3. $P(x\mid a,b)=\sum_y\tfrac12\delta_{a\cdot b,x\oplus y}=\tfrac12$（对 $x=0,1$ 都一样），与 $b$ 无关；对 $y$ 同理。所以任何一端都无法通过自己的设置向另一端传信。
4. 从里到外：经典/LHV（$|S|\le2$）⊂ 量子（$|S|\le2\sqrt2$）⊂ 非信号（可达 $|S|=4$）⊂ 所有分布。PR Box 属于**非信号但非量子**的那一层。
5. 三条假设：结果的确定性/实在论（四档结果由 $\lambda$ 确定）、局域性（各自结果不依赖对方设置）、测量独立性（$p(\lambda\mid a,b)=p(\lambda)$）。可行路线：①允许两端经典通信（放弃局域性，例如 Alice 把 $a$ 发给 Bob、$y=a\cdot b$，得 $S=4$）；②让设置与 $\lambda$ 相关（放弃测量独立性，实现 PR Box，得 $S=4$）；③后选择/不公平采样（放弃公平采样，属于实验层面）。
6. 若设置自由随机且与源无关，则协议重新满足 LHV 的三条假设，按定理必有 $|S|\le2$。这说明违背完全来自「设置与 $\lambda$ 的相关性」。
7. 量子力学的违背**不放弃任何一条**假设（它保持局域操作与自由设置），它表明的是**不存在**任何满足这三条假设的隐变量模型；经典协议的违背则必须牺牲其中一条假设，本质上是把「设置的选择」或「通信」纳入了协议本身。
8. 错。Tsirelson 边界 $|S|\le2\sqrt2$ 是量子力学的定理，PR Box 给出的 $|S|=4$ 超出该界限，因此**不可能**由任何量子态+测量的组合实现。
