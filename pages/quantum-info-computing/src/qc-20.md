### 4.2.1 超密编码要解决什么问题

> **超密编码（superdense coding）的目标**：Alice 只向 Bob 发送**一个**量子比特，却让 Bob 得到**两个**经典比特的信息（即 $0$–$3$ 四个值之一）。

直觉上这不可能：一个量子比特测量后只能给出一个比特。超密编码之所以能做，是因为双方**事先共享了一对纠缠比特**（Bell 态）。资源账要这样记：

| 阶段 | 消耗的资源 |
|---|---|
| 准备阶段（可以提前很久做） | 一对处于 Bell 态的纠缠量子比特 + 一个量子通道（双方各持一半） |
| 通信阶段 | **Alice 只发送 1 个量子比特**（她的那一半） |

**翻译成人话**：纠缠是「预付费」的额度，Alice 发送时只花 $1$ 个量子比特就兑现了 $2$ 个经典比特。这也是为什么超密编码**不能用来超光速通信**：第二个比特的「信息」其实早在准备阶段（通过光速以内的信道）就已经被两个粒子共同携带了。

【补】**不共享纠缠行不行？** 不行。Holevo 界（Holevo bound）指出：$n$ 个量子比特在不借助预共享纠缠时最多只能携带 $n$ 个经典比特的可获取信息。超密编码用 $1$ 个量子比特传 $2$ 个比特，靠的正是那对预先建立的纠缠，所以它**不违背** Holevo 界，只是换了一种资源记账方式。

---

### 4.2.2 预备：四个 Bell 态与 Pauli 算子（PPT 第 54 页）

Alice 的四种「编码动作」由三个 Pauli 算子（Pauli operators）和单位算子给出，课件第 54 页记为 $X,Y,Z=\sigma_1,\sigma_2,\sigma_3$：

$$I=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad
X=\sigma_1=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad
Y=\sigma_2=\begin{pmatrix}0&-i\\ i&0\end{pmatrix},\quad
Z=\sigma_3=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.$$

**翻译成人话**：$X$ 就是经典的「非门」（把 $|0\rangle$ 和 $|1\rangle$ 对调）；$Z$ 只给 $|1\rangle$ 加一个负号；$Y$ 相当于「先 $Z$ 再 $X$」（差一个相位）。

双方**预先共享**的初始态是四个 Bell 态（Bell states）中的第一个：

$$\psi_0=\frac{1}{\sqrt2}\big(|00\rangle+|11\rangle\big).$$

**翻译成人话**：这是一个「要么两个都是 $0$、要么两个都是 $1$」的纠缠叠加，单独看任何一个粒子都是随机的 $0/1$ 各一半，但两个粒子的结果**永远一致**。

Alice 按她要发送的 $2$ 比特值（记为 $0$–$3$），只对自己的那个量子比特做作用，得到课件第 54 页的编码表：

| Value | Transformation | New state |
|---|---|---|
| $0$ | $\psi_0=(I\otimes I)\psi_0$ | $\frac{1}{\sqrt2}\big(\lvert 00\rangle+\lvert 11\rangle\big)$ |
| $1$ | $\psi_1=(X\otimes I)\psi_0$ | $\frac{1}{\sqrt2}\big(\lvert 10\rangle+\lvert 01\rangle\big)$ |
| $2$ | $\psi_2=(Y\otimes I)\psi_0$ | $\frac{1}{\sqrt2}\big(-\lvert 10\rangle+\lvert 01\rangle\big)$ |
| $3$ | $\psi_3=(Z\otimes I)\psi_0$ | $\frac{1}{\sqrt2}\big(\lvert 00\rangle-\lvert 11\rangle\big)$ |

**四行都手算一遍**（记住「只动第一个比特」）：

- **Value $0$**：什么都不做，$\psi_0$ 原样。
- **Value $1$**：$X|0\rangle=|1\rangle$、$X|1\rangle=|0\rangle$，逐项作用

$$(X\otimes I)\frac{1}{\sqrt2}\big(|00\rangle+|11\rangle\big)=\frac{1}{\sqrt2}\big(|10\rangle+|01\rangle\big).$$

- **Value $2$**：$Y|0\rangle=i|1\rangle$、$Y|1\rangle=-i|0\rangle$，于是

$$(Y\otimes I)\frac{1}{\sqrt2}\big(|00\rangle+|11\rangle\big)=\frac{1}{\sqrt2}\big(i|10\rangle-i|01\rangle\big)=\frac{i}{\sqrt2}\big(|10\rangle-|01\rangle\big).$$

- **Value $3$**：$Z|0\rangle=|0\rangle$、$Z|1\rangle=-|1\rangle$，于是

$$(Z\otimes I)\frac{1}{\sqrt2}\big(|00\rangle+|11\rangle\big)=\frac{1}{\sqrt2}\big(|00\rangle-|11\rangle\big).$$

【勘误】第 $2$ 行（Value $2$）严格算出来是 $\frac{i}{\sqrt2}\big(|10\rangle-|01\rangle\big)$，而课件表格写的是 $\frac{1}{\sqrt2}\big(-|10\rangle+|01\rangle\big)$，两者相差一个**全局相位** $(-i)$：$\frac{i}{\sqrt2}(|10\rangle-|01\rangle)=-i\cdot\frac{1}{\sqrt2}(-|10\rangle+|01\rangle)$。**全局相位在物理上不可观测**（它不改变任何测量概率），所以课件的写法作为一种「量子态」是等价的，协议不受影响；但如果按「矩阵精确作用」来对答案，需要补上这个 $(-i)$。这一点在后面计算 CNOT 结果时也不影响结论，因为全局相位会原封不动地跟着走。

**四个新态的物理含义**（教材里常按 Bell 基命名）：$\psi_0$ 为 $\Phi^{+}$、$\psi_1$ 为 $\Psi^{+}$、$\psi_2$ 为 $\Psi^{-}$、$\psi_3$ 为 $\Phi^{-}$。它们两两正交，构成两比特空间的一组正交基——这是第 4.3 节要证明的事实。

---

### 4.2.3 步骤 3–4：Bob 执行 CNOT，测量第二个比特（PPT 第 55 页）

Alice 把自己那个量子比特发给 Bob（现在两个比特都在 Bob 手上）。**Bob 先做一次 CNOT**（Alice 送来的比特作控制位，Bob 原来持有的比特作目标位），得到课件第 55 页的完整表格：

| Initial state | Controlled-NOT | First bit | Second bit |
|---|---|---|---|
| $\psi_0=\frac{1}{\sqrt2}(\lvert 00\rangle+\lvert 11\rangle)$ | $\frac{1}{\sqrt2}(\lvert 00\rangle+\lvert 10\rangle)$ | $\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)$ | $\lvert 0\rangle$ |
| $\psi_1=\frac{1}{\sqrt2}(\lvert 10\rangle+\lvert 01\rangle)$ | $\frac{1}{\sqrt2}(\lvert 11\rangle+\lvert 01\rangle)$ | $\frac{1}{\sqrt2}(\lvert 1\rangle+\lvert 0\rangle)$ | $\lvert 1\rangle$ |
| $\psi_2=\frac{1}{\sqrt2}(-\lvert 10\rangle+\lvert 01\rangle)$ | $\frac{1}{\sqrt2}(-\lvert 11\rangle+\lvert 01\rangle)$ | $\frac{1}{\sqrt2}(-\lvert 1\rangle+\lvert 0\rangle)$ | $\lvert 1\rangle$ |
| $\psi_3=\frac{1}{\sqrt2}(\lvert 00\rangle-\lvert 11\rangle)$ | $\frac{1}{\sqrt2}(\lvert 00\rangle-\lvert 10\rangle)$ | $\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)$ | $\lvert 0\rangle$ |

**手算推导**（CNOT 规则：$|a,b\rangle\mapsto|a,a\oplus b\rangle$，只翻目标位）：

- $\psi_0$：$|00\rangle\to|00\rangle$（$a=0$ 不翻），$|11\rangle\to|10\rangle$（$a=1$ 翻目标），故得 $\frac{1}{\sqrt2}(|00\rangle+|10\rangle)$。提公因子后第一个比特是 $|+\rangle$、第二个比特是 $|0\rangle$。
- $\psi_1$：$|10\rangle\to|11\rangle$，$|01\rangle\to|01\rangle$（$a=0$ 不翻），得 $\frac{1}{\sqrt2}(|11\rangle+|01\rangle)$；第一个比特 $|+\rangle$、第二个 $|1\rangle$。
- $\psi_2$：$|10\rangle\to|11\rangle$、$|01\rangle\to|01\rangle$，得 $\frac{1}{\sqrt2}(-|11\rangle+|01\rangle)$；第一个比特 $\frac{1}{\sqrt2}(-|1\rangle+|0\rangle)$、第二个 $|1\rangle$。
- $\psi_3$：$|00\rangle\to|00\rangle$、$|11\rangle\to|10\rangle$，得 $\frac{1}{\sqrt2}(|00\rangle-|10\rangle)$；第一个比特 $\frac{1}{\sqrt2}(|0\rangle-|1\rangle)$、第二个 $|0\rangle$。

**关键观察**：CNOT 之后四个态全部变成了**乘积态**（product state）——「第一个比特是什么」与「第二个比特是什么」不再纠缠，可以写成「(第一个比特的态) $\otimes$ (第二个比特的态)」。**这正是 Bob 可以「测量第二个比特而不扰动第一个比特」的原因**：在乘积态上，对第二个比特的测量是对整个态做局部操作，第一个比特的约化密度算子不受影响。

**步骤 4 的测量判据**（课件第 55 页）：

- 测第二个比特得 $\lvert 0\rangle$ $\Rightarrow$ Alice 发的是 $0$ 或 $3$；对应第一比特为 $|+\rangle$ 或 $|-\rangle$；
- 测第二个比特得 $\lvert 1\rangle$ $\Rightarrow$ Alice 发的是 $1$ 或 $2$；对应第一比特为 $|+\rangle$ 或 $|-\rangle$。

**翻译成人话**：第一个测量只区分出「两个候选值」，把 $4$ 种可能压缩到 $2$ 种。剩下的一位信息藏在第一个比特的**相位**（$|+\rangle$ 还是 $|-\rangle$）里，要靠下一步的 H 门把它「翻译」成 $0/1$。

---

### 4.2.4 步骤 5–6：对第一个比特做 H，再测量（PPT 第 56 页）

Bob 对第一个量子比特执行 H 变换（H 是线性的，作用时第二个比特完全不受影响），得到课件第 56 页的表格：

| Initial state | First bit | $H$(First bit) |
|---|---|---|
| $\psi_0$ | $\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)$ | $\frac{1}{\sqrt2}\big(\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)+\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)\big)=\lvert 0\rangle$ |
| $\psi_1$ | $\frac{1}{\sqrt2}(\lvert 1\rangle+\lvert 0\rangle)$ | $\frac{1}{\sqrt2}\big(\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)+\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)\big)=\lvert 0\rangle$ |
| $\psi_2$ | $\frac{1}{\sqrt2}(-\lvert 1\rangle+\lvert 0\rangle)$ | $\frac{1}{\sqrt2}\big(-\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)+\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)\big)=\lvert 1\rangle$ |
| $\psi_3$ | $\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)$ | $\frac{1}{\sqrt2}\big(\frac{1}{\sqrt2}(\lvert 0\rangle+\lvert 1\rangle)-\frac{1}{\sqrt2}(\lvert 0\rangle-\lvert 1\rangle)\big)=\lvert 1\rangle$ |

**手算验证其中一行**（$\psi_2$）：第一个比特是 $\frac{1}{\sqrt2}(-|1\rangle+|0\rangle)=|-\rangle$。用上一节的规则 $H|-\rangle=|1\rangle$，立刻得到结果 $|1\rangle$。逐项展开也确实如此：

$$H|-\rangle=\frac{1}{\sqrt2}\Big(H|0\rangle-H|1\rangle\Big)=\frac{1}{\sqrt2}\left(\frac{|0\rangle+|1\rangle}{\sqrt2}-\frac{|0\rangle-|1\rangle}{\sqrt2}\right)=\frac{1}{\sqrt2}\cdot\frac{2|1\rangle}{\sqrt2}=|1\rangle .$$

同理 $\psi_0,\psi_1$ 的第一个比特都是 $|+\rangle$，$H|+\rangle=|0\rangle$；$\psi_2,\psi_3$ 的第一个比特都是 $|-\rangle$，$H|-\rangle=|1\rangle$。

**步骤 6**：Bob 测量第一个比特，把两次测量结果合起来查表，就能**确定地**（概率 $1$）读出 Alice 的 $2$ 比特：

| 第二个比特的测量结果 | 第一个比特的测量结果 | 判定 Alice 发送的值 |
|---|---|---|
| $0$ | $0$ | $0$（即 $\psi_0$） |
| $1$ | $0$ | $1$（即 $\psi_1$） |
| $1$ | $1$ | $2$（即 $\psi_2$） |
| $0$ | $1$ | $3$（即 $\psi_3$） |

**翻译成人话**：第一个比特的 $|+\rangle/|-\rangle$ 差别（一个相位差）在 H 门里被「相加相消」放大成了 $|0\rangle/|1\rangle$ 的确定差别，于是第二次测量不再随机。

### 4.2.5 六步流程汇总（PPT 第 54–56 页）

```text
步骤1  预共享纠缠：|ψ0> = (|00>+|11>)/√2
          Alice ──qubit1──┐
                          ├── 纠缠对
          Bob   ──qubit2──┘

步骤2  Alice 按 2 bit 选 I / X / Y / Z，作用在自己的 qubit 上
          value 0 → I      value 1 → X
          value 2 → Y      value 3 → Z
       Alice 把 qubit1 通过量子通道发给 Bob   ← 只发 1 个量子比特

步骤3  Bob 对 (qubit1, qubit2) 执行 CNOT（qubit1 控制，qubit2 目标）
步骤4  Bob 测量 qubit2：|0> → 候选 {0,3}；|1> → 候选 {1,2}
步骤5  Bob 对 qubit1 执行 H
步骤6  Bob 测量 qubit1，与步骤4 结果合起来 → 确定读出 0–3
```

【补】**为什么这套流程一定成功？** 因为 Bob 手上的两次单比特测量加上 CNOT、H 门，合起来**等价于在 Bell 基下做一次联合测量**：四个编码态 $\psi_0,\psi_1,\psi_2,\psi_3$ 两两正交，正交态可以被**概率 $1$** 地区分（一般证明见《量子力学讲义》（P1 讲义）第二章「正交才可区分」；本讲义第 4.3.1 节也已直接用这条结论验收四个 Bell 态）。协议只是把这个「难以直接实现的全局测量」拆成了「CNOT + H + 两次单比特测量」——这正是下一节要说明的问题。

---

### 本节要点

1. 超密编码的前提是**预共享 Bell 态**；通信阶段 Alice 只发 $1$ 个量子比特，Bob 得到 $2$ 个经典比特，因此不违背 Holevo 界。
2. Alice 的编码是对自己那一半做 $I,X,Y,Z$（即 $\sigma_0,\sigma_1,\sigma_2,\sigma_3$），把 $\psi_0$ 映射成四个两两正交的 Bell 态。
3. Bob 的 CNOT 把四个纠缠态全部变成**乘积态**，所以「测第二个比特不扰动第一个比特」。
4. 第一次测量（第二个比特）把候选值压到 $2$ 个；第二次测量（第一个比特经 H 后）再用相位信息区分出最后一位。
5. 判决表：$(\text{第二},\text{第一})=(0,0)\to0$，$(1,0)\to1$，$(1,1)\to2$，$(0,1)\to3$。
6. 【勘误】课件 Value $2$ 行与严格矩阵计算相差一个全局相位 $-i$，物理上等价。

### 自测题

1. 若 Alice 要发送 $2$，她对 $\psi_0$ 施加什么变换？请写出变换后的态（按课件的相位约定）。
2. Bob 做完 CNOT 之后，为什么测量第二个比特不会影响第一个比特的状态？
3. 若 Bob 测第二个比特得到 $|0\rangle$、测第一个比特（H 之后）得到 $|1\rangle$，Alice 发送的值是多少？
4. 如果把协议里的 H 门去掉，直接测量第一个比特，Bob 能确定地读出 Alice 的信息吗？为什么？

<details><summary>答案</summary>

1. 施加 $Y\otimes I$（$Y=\sigma_2$），按课件约定得到 $\psi_2=\frac{1}{\sqrt2}(-|10\rangle+|01\rangle)$；严格计算为 $\frac{i}{\sqrt2}(|10\rangle-|01\rangle)$，两者相差全局相位 $-i$，是可观测上等价的同一个态。
2. 因为 CNOT 之后四个态都变成了乘积态（第一个比特的态 $\otimes$ 第二个比特的态），两个比特之间不再有关联。对乘积态测量其中一个子系统，另一个子系统的约化密度算子不变，所以测量不扰动它。
3. 第二个比特为 $0$ 说明候选是 $\{0,3\}$；第一个比特 H 之后测得 $1$ 说明 H 之前是 $|-\rangle$，对应 $\psi_3$。故 Alice 发送的是 **$3$**。
4. 不能。CNOT 之后第一个比特在 $\psi_0,\psi_1$ 情形下是 $|+\rangle$，在 $\psi_2,\psi_3$ 情形下是 $|-\rangle$。直接在计算基测量 $|+\rangle$ 或 $|-\rangle$，结果都是 $0/1$ 各 $1/2$，读不出相位信息。H 门的作用正是把「$|+\rangle$ 与 $|-\rangle$ 的相位差」变成「$|0\rangle$ 与 $|1\rangle$ 的确定差别」。
