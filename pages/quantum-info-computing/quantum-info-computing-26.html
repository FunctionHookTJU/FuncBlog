5.5 量子计算现状与展望

5.5.1 多项式时间的量子算法：量子傅里叶变换为什么是引擎

课件在最后一页（PPT 第 71 页）给出四条关于量子计算现状的判断，第一条是：

存在可能的 NP 问题，可以用量子算法在多项式时间内求解（这类算法经常基于量子傅里叶变换）。

这句话有两层意思，需要拆开读。

第一层：确实存在「属于 NP」且「量子算法多项式时间可解」的问题。 最著名的例子是整数分解（integer factorization）：给定合数 NNN，求它的一个非平凡因子。它的判定版本「NNN 是否有小于 kkk 的因子」属于 NP——理由是：一旦有人给出因子，验证只需做一次除法，而验证代价是多项式时间。Shor 在 1994 年给出了多项式时间的量子算法来解它，同一算法还顺带解决了离散对数（discrete logarithm）问题。

第二层：这些算法的引擎是量子傅里叶变换（Quantum Fourier Transform, QFT）。 QFT 是经典离散傅里叶变换的量子版本，作用在 nnn 个比特的基态上：

∣x⟩ ⟼ 1N∑y=0N−1e2πi xy/N ∣y⟩,N=2n.|x\rangle\ \longmapsto\ \frac{1}{\sqrt N}\sum_{y=0}^{N-1}e^{2\pi i\,xy/N}\,|y\rangle,\qquad N=2^n .∣x⟩ ⟼ N​1​y=0∑N−1​e2πixy/N∣y⟩,N=2n.

翻译成人话：QFT 把「索引 xxx」变成「所有索引 yyy 的等权叠加，但每个 yyy 前面挂一个相位 e2πixy/Ne^{2\pi ixy/N}e2πixy/N」；这个相位只依赖乘积 xyxyxy，正是傅里叶变换里「频率 ×\times× 位置」的结构。

QFT 的关键性质是它可以在量子电路上高效实现：虽然写出来的矩阵是 N×NN\times NN×N 的，实际却只需 O(n2)=O((log⁡N)2)O(n^2)=O((\log N)^2)O(n2)=O((logN)2) 个基本门（使用 Hadamard 门与受控相位门），而经典快速傅里叶变换要 O(Nlog⁡N)O(N\log N)O(NlogN) 步。指数级的差别就来自这里：量子电路直接在 2n2^n2n 维空间里做变换，代价却只有 nnn 的多项式。

补QFT 怎么被用来解因式分解？ 完整的逻辑链条是：①把「分解 NNN」归约成「求某个函数 f(x)=ax mod Nf(x)=a^x\bmod Nf(x)=axmodN 的周期」——这一步是纯经典数论；②用量子电路制备 ∑x∣x⟩∣f(x)⟩\sum_x|x\rangle|f(x)\rangle∑x​∣x⟩∣f(x)⟩，此时 fff 的周期 rrr 以「相位」的形式编码在寄存器里；③对第一个寄存器做 QFT，把「周期」转成「频率」，于是测量就能以高概率读出 rrr 的倍数；④再用连分数（continued fraction）从测量结果反解出 rrr，最后由 rrr 算出因子。QFT 的作用是「周期 →\rightarrow→ 频率」的转换器，Shor 算法与 Grover 算法的风格差别也在这里：Shor 靠相位干涉，Grover 靠振幅放大。

补为什么因式分解的量子多项式算法没有推翻 RSA 之外的一切？ 因为因式分解并不是 NP 完全问题。它属于 NP∩co-NP\mathrm{NP}\cap\mathrm{co}\text{-}\mathrm{NP}NP∩co-NP，被广泛认为「比 NP 完全问题容易」，甚至可能根本没有经典多项式算法却仍比 NP 完全问题易。因此「Shor 能多项式时间解因式分解」这一事实，不能推出「量子计算机能多项式时间解 NP 完全问题」。

5.5.2 「量子化」能否带来指数加速：一个需要限定条件的主张

课件第二条说（PPT 第 71 页）：

存在多项式复杂性的经典（机器学习）算法，通过量子化可以获得指数加速比。

这句话本身是正确的，而它成立需要同时满足若干结构性前提。「量子化」（quantization）指的是把经典算法改写成量子版本，例如用 HHL 算法解线性方程组、用量子主成分分析（quantum PCA）做降维；在满足下列前提时，这些量子版本确实能相对经典版本取得指数加速。

补这条加速比的适用条件（课件未展开的前提）。 课件只陈述了「存在这样的算法」这一事实，并未承诺普遍适用；为避免读者把它误读成「任意经典算法量子化后都能指数加速」，这里把四条前提补全——缺任何一条，指数加速都会退回到多项式加速甚至毫无优势：

  1. 数据能被高效量子化：经典数据必须用 O(poly(n))O(\mathrm{poly}(n))O(poly(n)) 代价装进量子态（通常依赖 QRAM，即量子随机存取存储器），否则「读数据」这一步就已经吃掉全部加速；
  2. 问题有可利用的结构：矩阵需要稀疏、低秩或低条件数等，例如 HHL 要求条件数 κ\kappaκ 只按多项式增长；
  3. 只要求特定的输出形式：量子算法通常只能高效给出「某个可观测量的期望值」，而不能把解向量完整读出（读出 nnn 个振幅至少要 O(n)O(n)O(n) 次测量）；若下游任务需要完整解，加速立刻消失；
  4. 经典算法没有被同步改进：量子化往往同时暴露了经典算法此前忽略的结构，几年后经典算法也可能被改进，从而把差距抹平——张量网络、随机线性代数等方法已经多次造成这种「去量子化」（dequantization）现象。

翻译成人话：量子化的指数加速不是「免费的午餐」，它更像「当问题恰好具备上述结构时，量子算法能绕开经典算法的瓶颈」；因此在引用这个加速比时，必须逐案确认前提是否成立，而不能由「经典算法是多项式的」直接推出。

补一个有代表性的例子：HHL 解线性方程组。 给定 Ax=bA\mathbf{x}=\mathbf{b}Ax=b，HHL 在有前述前提时以 O(log⁡N)O(\log N)O(logN) 量级的代价给出 x\mathbf{x}x 在某个算子 MMM 下的期望 ⟨x∣M∣x⟩\langle\mathbf{x}|M|\mathbf{x}\rangle⟨x∣M∣x⟩，而经典算法需要 O(N)O(N)O(N) 量级。差别看起来是指数的，但只要「需要读出整个 x\mathbf{x}x」或「AAA 的条件数很大」，优势就消失了。这正说明上面的第 3、2 条前提缺一不可。

5.5.3 BQP 与 NP：仍然是开放问题

课件第三条（PPT 第 71 页）：

直到目前，不能确知任何 NP 问题是否存在多项式时间的量子算法。因此，BQP 与 NP 的关系依然是开放问题。

这里出现了本节最重要的一个复杂度类，先把定义写清楚。

补BQP（Bounded-error Quantum Polynomial time，有界误差量子多项式时间）：存在量子算法在多项式时间内以至少 2/32/32/3 的成功概率判定答案的语言类。它是经典类 BPP（有界误差经典多项式时间）的量子对应物。

已知的包含与分离关系可以排成一条链：

P⊆BPP⊆BQP⊆PSPACE.\mathrm{P}\subseteq\mathrm{BPP}\subseteq\mathrm{BQP}\subseteq\mathrm{PSPACE}.P⊆BPP⊆BQP⊆PSPACE.

翻译成人话：经典能高效解决的问题，量子计算机也都能高效解决（把经典电路当量子电路跑）；量子能高效解决的问题都在多项式空间之内，所以量子计算机不可能解决所有可计算问题，也不可能凭空超越 PSPACE\mathrm{PSPACE}PSPACE 的天花板。

那么 BQP\mathrm{BQP}BQP 和 NP\mathrm{NP}NP 谁大谁小？两个方向都是开放的：

关系 状态 说明
NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}NP⊆BQP？ 未知 若成立，则 NP 完全问题有多项式时间量子算法
BQP⊆NP\mathrm{BQP}\subseteq\mathrm{NP}BQP⊆NP？ 未知 若成立，则量子算法的能力上限仍在 NP 之内

翻译成人话：我们现在既不知道量子计算机能否高效解 NP 完全问题，也不知道量子计算机的能力是否被 NP 封顶。课件把它称为「开放问题」（open problem），是一个非常准确的表述。

补已经知道的两件事，可以排除一些想象。 ①Grover 只能给 NP 完全问题二次加速：把量子搜索套在 NP 完全问题的穷举上，代价是 O(2n/2)=O(2n)O(2^{n/2})=O(\sqrt{2^n})O(2n/2)=O(2n​)，相对经典的 O(2n)O(2^n)O(2n) 只是平方根级改进，仍然是指数的，因此这不足以证明 NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}NP⊆BQP。②存在 oracle 分离：Bennett、Bernstein、Brassard 与 Vazirani 在 1997 年构造了一个 oracle，相对于它 NP⊈BQP\mathrm{NP}\not\subseteq\mathrm{BQP}NP⊆BQP。这类分离结果说明「用通用技巧证明 NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}NP⊆BQP」是走不通的——任何这样的证明都必须在某处用到问题的具体结构，而不能只依赖查询模型。

勘误课件第三条写「不能确知任何 NP 问题是否存在多项式时间的量子算法」，字面读来与第一条冲突（因式分解就是 NP 问题且已有多项式量子算法）。按上下文，这里要表达的是「不能确知任何 NP 完全问题是否存在多项式时间的量子算法」；课件第一条讲的则是「存在某些属于 NP 的问题有多项式量子算法」。两句话只有在补上「完全」二字后才自洽。

5.5.4 物理实现：纠错开销与器件成本

课件第四条（PPT 第 71 页）：

通用量子算法的物理实现仍存在较大困难，并需付出较高综合代价：纠错开销、量子器件的制造和使用成本开销等。

这一条最容易被当成「工程上的抱怨」而略过，但它其实是量子计算最大的现实障碍。要理解它，必须先理解为什么量子计算天然需要纠错。

补量子比特是连续量、量子测量是破坏性的，这让「纠错」变得非常反直觉。

  • 经典比特的错误只有「翻转」一种，用三份拷贝投票即可纠正；
  • 量子态不能拷贝（不可克隆定理，见第 3.2 节），所以「复制三份投票」的思路直接失效；
  • 更麻烦的是：测量会塌缩态，而连续振幅上的小误差无法通过「看它一眼」发现。

翻译成人话：既要纠正错误，又不能用「抄三份对比」的办法，也不能随便测量，只能用多个物理量子比特编码一个逻辑量子比特，并且只测量「错误症状」（syndrome）而不测量编码态本身。这就是量子纠错码（quantum error-correcting code）的思路。

补阈值定理（threshold theorem）与开销。 阈值定理指出：只要每个物理门的错误率低于某个阈值（对表面码一类方案，阈值在 10−210^{-2}10−2 量级），就能用「级联编码」把逻辑错误率压到任意低，代价是逻辑比特数按 O(poly(log⁡(1/ϵ)))O(\mathrm{poly}(\log(1/\epsilon)))O(poly(log(1/ϵ))) 增长。但常数因子极大：在当前的器件参数（相干时间约 10210^{2}102 微秒、双比特门错误率约 10−310^{-3}10−3 量级）下，一个逻辑量子比特大致需要 10310^{3}103 到 10410^{4}104 个物理量子比特；若还要执行非 Clifford 门，通常需要额外的「魔术态蒸馏」（magic state distillation），开销再上一个量级。因此「几百个物理量子比特」和「几百个逻辑量子比特」是两个相差三四个数量级的概念。

补三个常被混淆的数字。 宣传中的「量子比特数」通常指物理量子比特；能跑通用量子算法需要的是逻辑量子比特；而算法的电路深度决定了需要多低的逻辑错误率。判断一条量子计算新闻是否可信，先问三个问题：物理还是逻辑？错误率多少？电路深度多少？

翻译成人话：量子计算的瓶颈不在「原理上做不到」，而在「代价高得惊人」：为了把一个逻辑比特的错误率压到可用水平，要付出成千上万个物理比特和大量额外的纠错电路；工程上又要求极高保真度的门、极长的相干时间、以及接近绝对零度的运行环境。所以课件说「仍需付出较高综合代价」，这个措辞是克制的。

补「量子优越性」与「通用量子计算」是两件事。 量子优越性（quantum advantage / supremacy）实验通常针对精心构造的采样问题——它们能证明「量子设备做成了经典模拟很困难的事」，但不等于能跑 Shor 或 Grover 这类有实用价值的算法。前者是「硬件里程碑」，后者才对应「通用量子算法」。课件的第四条针对的正是后者。

小结

一句话串起本讲：通用计算模型告诉我们「什么能被计算」（5.1），量子电路与通用门集告诉我们「用什么搭出量子计算机」（5.2），Grover 算法告诉我们「如何用振幅放大把无结构搜索从 O(N)O(N)O(N) 降到 O(N)O(\sqrt N)O(N​)」（5.3–5.4），而本节的四条现状判断提醒我们「哪些加速已经兑现、哪些仍是开放问题、代价又有多大」（5.5）——量子计算的价值不在于「量子比经典快」，而在于对特定结构的问题，它能突破经典算法的下界。

核心结论清单

  1. QFT 是多项式时间量子算法的主力引擎：∣x⟩↦1N∑ye2πixy/N∣y⟩|x\rangle\mapsto\frac{1}{\sqrt N}\sum_y e^{2\pi ixy/N}|y\rangle∣x⟩↦N​1​∑y​e2πixy/N∣y⟩，可在 O(n2)O(n^2)O(n2) 个门内实现（n=log⁡Nn=\log Nn=logN），Shor 的因式分解与离散对数算法都建立在它之上。（PPT 第 71 页）
  2. 因式分解不是 NP 完全问题：所以「Shor 能多项式时间解因式分解」不能推出「量子计算机能高效解 NP 完全问题」。
  3. 「量子化带来指数加速」有适用条件：高效数据装载、问题结构（稀疏/低秩/低条件数）、只要求期望值型输出、经典算法未被同步改进——四条缺一不可。（PPT 第 71 页，见 §5.5.2 的补）
  4. BQP 与 NP 的关系是开放问题：已知 P⊆BPP⊆BQP⊆PSPACE\mathrm{P}\subseteq\mathrm{BPP}\subseteq\mathrm{BQP}\subseteq\mathrm{PSPACE}P⊆BPP⊆BQP⊆PSPACE；NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}NP⊆BQP 与 BQP⊆NP\mathrm{BQP}\subseteq\mathrm{NP}BQP⊆NP 两个方向都未知。
  5. Grover 对 NP 完全问题只有二次加速：O(2n/2)O(2^{n/2})O(2n/2) 仍是指数的，不能用来证明 NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}NP⊆BQP；且存在相对某个 oracle 的 NP⊈BQP\mathrm{NP}\not\subseteq\mathrm{BQP}NP⊆BQP 分离结果。
  6. 物理实现的瓶颈是纠错开销与器件成本：一个逻辑量子比特在现阶段的典型代价是 10310^{3}103–10410^{4}104 个物理量子比特，加上魔术态蒸馏等额外开销。（PPT 第 71 页）
  7. 「量子优越性实验」不等于「通用量子算法」：前者多是采样问题上的硬件里程碑，后者才对应 Shor、Grover 这类有明确实用目标的算法。

  2. 因为因式分解不是 NP 完全问题：它属于 NP∩co-NP\mathrm{NP}\cap\mathrm{co}\text{-}\mathrm{NP}NP∩co-NP，被普遍认为比 NP 完全问题简单，甚至可能不存在经典多项式算法。NP 完全问题是 NP 中「最难」的一类，若某类问题有多项式算法，则整个 NP 有多项式算法。Shor 算法只覆盖了因式分解与离散对数这两个具体问题，对 NP 完全问题没有给出任何多项式算法。

  3. 任答两条即可。①高效数据装载：经典数据必须能以 O(poly(n))O(\mathrm{poly}(n))O(poly(n)) 代价装进量子态；若假设不成立，读数据本身就耗掉全部加速。②问题结构（稀疏/低秩/低条件数）：例如 HHL 要求条件数 κ\kappaκ 只按多项式增长；若 AAA 条件数极大，解的精度需要极高的相位估计精度，加速消失。③输出形式：量子算法通常只能给出期望值；若必须读出完整解向量，需 O(N)O(N)O(N) 次测量，加速消失。④经典算法未被同步改进：若经典算法随后被改进到同等复杂度，差距被抹平。

  6. 经典纠错的核心是「复制多份经典比特，用多数表决定位被翻转的那一份」。量子情形有两个障碍：①不可克隆定理（第 3.2 节）禁止复制任意未知量子态，无法做出三份拷贝；②测量会塌缩态，直接「读出来比对」会破坏待保护的叠加态。量子纠错因此改为「把 1 个逻辑比特编码进多个物理比特的纠缠态」，只测量错误症状（syndrome）而不测量编码态本身，从而既纠正错误又不破坏信息。
