4.2 超密编码协议

4.2.1 超密编码要解决什么问题

超密编码（superdense coding）的目标：Alice 只向 Bob 发送一个量子比特，却让 Bob 得到两个经典比特的信息（即 000–333 四个值之一）。

直觉上这不可能：一个量子比特测量后只能给出一个比特。超密编码之所以能做，是因为双方事先共享了一对纠缠比特（Bell 态）。资源账要这样记：

阶段 消耗的资源
准备阶段（可以提前很久做） 一对处于 Bell 态的纠缠量子比特 + 一个量子通道（双方各持一半）
通信阶段 Alice 只发送 1 个量子比特（她的那一半）

翻译成人话：纠缠是「预付费」的额度，Alice 发送时只花 111 个量子比特就兑现了 222 个经典比特。这也是为什么超密编码不能用来超光速通信：第二个比特的「信息」其实早在准备阶段（通过光速以内的信道）就已经被两个粒子共同携带了。

补不共享纠缠行不行？ 不行。Holevo 界（Holevo bound）指出：nnn 个量子比特在不借助预共享纠缠时最多只能携带 nnn 个经典比特的可获取信息。超密编码用 111 个量子比特传 222 个比特，靠的正是那对预先建立的纠缠，所以它不违背 Holevo 界，只是换了一种资源记账方式。

关键观察：CNOT 之后四个态全部变成了乘积态（product state）——「第一个比特是什么」与「第二个比特是什么」不再纠缠，可以写成「(第一个比特的态) ⊗\otimes⊗ (第二个比特的态)」。这正是 Bob 可以「测量第二个比特而不扰动第一个比特」的原因：在乘积态上，对第二个比特的测量是对整个态做局部操作，第一个比特的约化密度算子不受影响。

步骤 4 的测量判据（课件第 55 页）：

  • 测第二个比特得 ∣0⟩\lvert 0\rangle∣0⟩ ⇒\Rightarrow⇒ Alice 发的是 000 或 333；对应第一比特为 ∣+⟩|+\rangle∣+⟩ 或 ∣−⟩|-\rangle∣−⟩；
  • 测第二个比特得 ∣1⟩\lvert 1\rangle∣1⟩ ⇒\Rightarrow⇒ Alice 发的是 111 或 222；对应第一比特为 ∣+⟩|+\rangle∣+⟩ 或 ∣−⟩|-\rangle∣−⟩。

翻译成人话：第一个测量只区分出「两个候选值」，把 444 种可能压缩到 222 种。剩下的一位信息藏在第一个比特的相位（∣+⟩|+\rangle∣+⟩ 还是 ∣−⟩|-\rangle∣−⟩）里，要靠下一步的 H 门把它「翻译」成 0/10/10/1。

                          ├── 纠缠对
          Bob   ──qubit2──┘

步骤2  Alice 按 2 bit 选 I / X / Y / Z，作用在自己的 qubit 上
          value 0 → I      value 1 → X
          value 2 → Y      value 3 → Z
       Alice 把 qubit1 通过量子通道发给 Bob   ← 只发 1 个量子比特

步骤3  Bob 对 (qubit1, qubit2) 执行 CNOT（qubit1 控制，qubit2 目标）
步骤4  Bob 测量 qubit2：|0> → 候选 {0,3}；|1> → 候选 {1,2}
步骤5  Bob 对 qubit1 执行 H
步骤6  Bob 测量 qubit1，与步骤4 结果合起来 → 确定读出 0–3

补为什么这套流程一定成功？ 因为 Bob 手上的两次单比特测量加上 CNOT、H 门，合起来等价于在 Bell 基下做一次联合测量：四个编码态 ψ0,ψ1,ψ2,ψ3\psi_0,\psi_1,\psi_2,\psi_3ψ0​,ψ1​,ψ2​,ψ3​ 两两正交，正交态可以被概率 111 地区分（一般证明见《量子力学讲义》（P1 讲义）第二章「正交才可区分」；本讲义第 4.3.1 节也已直接用这条结论验收四个 Bell 态）。协议只是把这个「难以直接实现的全局测量」拆成了「CNOT + H + 两次单比特测量」——这正是下一节要说明的问题。

本节要点

  1. 超密编码的前提是预共享 Bell 态；通信阶段 Alice 只发 111 个量子比特，Bob 得到 222 个经典比特，因此不违背 Holevo 界。
  2. Alice 的编码是对自己那一半做 I,X,Y,ZI,X,Y,ZI,X,Y,Z（即 σ0,σ1,σ2,σ3\sigma_0,\sigma_1,\sigma_2,\sigma_3σ0​,σ1​,σ2​,σ3​），把 ψ0\psi_0ψ0​ 映射成四个两两正交的 Bell 态。
  3. Bob 的 CNOT 把四个纠缠态全部变成乘积态，所以「测第二个比特不扰动第一个比特」。
  4. 第一次测量（第二个比特）把候选值压到 222 个；第二次测量（第一个比特经 H 后）再用相位信息区分出最后一位。
  5. 判决表：(第二,第一)=(0,0)→0(\text{第二},\text{第一})=(0,0)\to0(第二,第一)=(0,0)→0，(1,0)→1(1,0)\to1(1,0)→1，(1,1)→2(1,1)\to2(1,1)→2，(0,1)→3(0,1)\to3(0,1)→3。
  6. 勘误课件 Value 222 行与严格矩阵计算相差一个全局相位 −i-i−i，物理上等价。

自测题

  1. 若 Alice 要发送 222，她对 ψ0\psi_0ψ0​ 施加什么变换？请写出变换后的态（按课件的相位约定）。
  2. Bob 做完 CNOT 之后，为什么测量第二个比特不会影响第一个比特的状态？
  3. 若 Bob 测第二个比特得到 ∣0⟩|0\rangle∣0⟩、测第一个比特（H 之后）得到 ∣1⟩|1\rangle∣1⟩，Alice 发送的值是多少？
  4. 如果把协议里的 H 门去掉，直接测量第一个比特，Bob 能确定地读出 Alice 的信息吗？为什么？
答案
  1. 施加 Y⊗IY\otimes IY⊗I（Y=σ2Y=\sigma_2Y=σ2​），按课件约定得到 ψ2=12(−∣10⟩+∣01⟩)\psi_2=\frac{1}{\sqrt2}(-|10\rangle+|01\rangle)ψ2​=2​1​(−∣10⟩+∣01⟩)；严格计算为 i2(∣10⟩−∣01⟩)\frac{i}{\sqrt2}(|10\rangle-|01\rangle)2​i​(∣10⟩−∣01⟩)，两者相差全局相位 −i-i−i，是可观测上等价的同一个态。
  2. 因为 CNOT 之后四个态都变成了乘积态（第一个比特的态 ⊗\otimes⊗ 第二个比特的态），两个比特之间不再有关联。对乘积态测量其中一个子系统，另一个子系统的约化密度算子不变，所以测量不扰动它。
  3. 第二个比特为 000 说明候选是 {0,3}\{0,3\}{0,3}；第一个比特 H 之后测得 111 说明 H 之前是 ∣−⟩|-\rangle∣−⟩，对应 ψ3\psi_3ψ3​。故 Alice 发送的是 333。
  4. 不能。CNOT 之后第一个比特在 ψ0,ψ1\psi_0,\psi_1ψ0​,ψ1​ 情形下是 ∣+⟩|+\rangle∣+⟩，在 ψ2,ψ3\psi_2,\psi_3ψ2​,ψ3​ 情形下是 ∣−⟩|-\rangle∣−⟩。直接在计算基测量 ∣+⟩|+\rangle∣+⟩ 或 ∣−⟩|-\rangle∣−⟩，结果都是 0/10/10/1 各 1/21/21/2，读不出相位信息。H 门的作用正是把「∣+⟩|+\rangle∣+⟩ 与 ∣−⟩|-\rangle∣−⟩ 的相位差」变成「∣0⟩|0\rangle∣0⟩ 与 ∣1⟩|1\rangle∣1⟩ 的确定差别」。
