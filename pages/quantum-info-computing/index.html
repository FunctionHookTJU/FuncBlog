如何使用这份讲义

这份讲义把天津大学《量子信息与量子人工智能》P2 课件（《量子信息和量子计算导论》，共 71 页 PPT）重讲了一遍。它不是课件的摘要，而是按课件原有的节次顺序，把每一页的知识点用初学者能跟上的速度重写，并补上课件默认你已掌握、其实很多人没有掌握的前置知识（前置内容见配套的 P1 讲义《导论与量子力学基础》）。

这份讲义怎么用

  1. 先读导论，再看第一讲。导论（PPT 第 1–2 页）给出两条研究动机与全篇地图；第一讲是后面所有内容的地基——纠缠、EPR、Bell、CHSH、PR Box。
  2. 对照课件看。每节都标了 （PPT 第 N 页），可以直接翻到对应 PPT 核对。课件的节次编号被完整保留（1.1 / 1.2 / … / 5.5），所以你能用课件的目录来定位。
  3. 看到橙色「补」徽章要格外认真。那是我补充的、课件里没写但初学必需的内容（术语定义、历史背景、类比、易错点、补充数据）。看到橙色「勘误」徽章，说明课件该处有笔误或不严谨，已给出订正（例如 1.6 节 CHSH 左端最后一项的符号、1.7 节 Tsirelson 取值的符号组合）。
  4. 公式不是装饰。每个公式后面都有一句「翻译成人话」。遇到看不懂的推导，先看那句白话，再回头抠符号。
  5. 每讲结尾有小结与自测题，答案默认折叠，先自己做再看；附录提供跨讲综合自测与公式速查。

阅读建议（按你的基础选路线）

你的情况 建议路线
完全没学过量子力学 先读 P1 讲义（第 0 章 + 第二讲）→ 再回来读导论与第一讲
学过量子力学，但没接触过纠缠判据 导论 → 1.1–1.3 精读 → 1.4–1.7 逐节精读（本讲的判决都在这里）
只想搞懂「为什么纠缠不能传信」 1.2（反相关 Bell 态）→ 1.5（非信号原则）
只想搞懂「Bell 不等式到底怎么被违背」 1.4（LHV 模型）→ 1.6（CHSH 与实验）→ 1.7（三条边界）
要交课程大作业 1.6（CHSH 的三条假设）→ 1.7（课程大作业一节：两条可行路线与报告要求）
关心应用与算法 导论 → 第三讲（QKD）→ 第四讲（超密编码）→ 第五讲（量子计算）

关于正文里的这些约定

  • （PPT 第 N 页）：该段落对应课件页码。
  • 蓝色等宽代码块：用来放 ASCII 结构图（时序图、嵌套集合图、协议流程图）。若你看到这些框线错位，是本机缺少覆盖 ⊂ ─ │ ┌ └ 的等宽字体，页面左下角会自己提示你安装 Consolas 或 DejaVu Sans Mono。
  • 表格：表格 用于概念对比；灰色无表头的对齐表用于纯数值排列表（如矩阵、隐变量取值表）。
  • 数学公式在构建时已离线渲染成矢量/HTML 混排，断网也能正常显示（不依赖任何 CDN）。
  • 每节底部的「上一节 / 下一节」和右侧「大章节」目录条可以连续翻页；右侧目录可用「收起」按钮隐藏，状态会记住。

从课件到讲义的取舍

  • 课件里的思考题、课堂讨论、练习题被保留在对应位置，并给出「该怎么想」的提示与折叠答案（例如 1.2 节的关联函数练习、1.7 节的大作业思路）。
  • 课件口播性的重复表述被合并；同一知识点在多页反复出现的，合并到首次出现处以保持线索清晰。
  • 涉及公式、矩阵、隐变量表的页面（PPT 第 7–9、15、19–24、26 页）已逐页对照课件原图核对，凡与课件不一致处均用「勘误」标出。
