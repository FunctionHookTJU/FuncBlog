3.3 BB84 方案全流程

3.3.1 承接上文：从「不可克隆」到「可检测的窃听」

量子密钥分发（quantum key distribution, QKD）要的不是「用量子态把信件送过去」，而是让 Alice 与 Bob 共享一串只有他们两人知道的随机比特（密钥），再用这串密钥去加密真正要传的经典消息。换句话说，量子力学在这里只负责「配钥匙」这一件事。

上一节的不可克隆定理（no-cloning theorem）堵死了 Eve 最省事的一条路：她无法把量子通道上飞过的未知态「复制一份留底、原件照传」。但「不能克隆」并不自动等于「一定能发现窃听」。Eve 完全可以换个思路：把 Alice 发来的量子比特先测一下，再按测量结果伪造一个同样的态发给 Bob——这叫拦截—重发（intercept–resend）攻击。测量塌缩（measurement collapse）保证了她这一手必然在两端的比对数据里留下痕迹：只要她测了，她伪造出来的态就不一定还是 Alice 原来那个态。

BB84 方案（Bennett–Brassard 1984）的全部精妙之处，就是把「必然留下痕迹」这句定性的话，变成一套双方可执行、且能把痕迹量化成置信度的流程。（PPT 第 48 页）

补一个高频误读：非克隆定理禁止的是克隆未知量子态，并不禁止克隆已知量子态。课件第 48 页顶部特意强调这一点——如果 Eve 已经知道这个态是什么（例如她偷听到了制备方案或制备基），她当然可以照样子制备任意多份，定理管不着。

3.3.2 两组互补基与四个量子态

BB84 只动用四个单量子比特态，按「两组基、每组两个态」的方式组织。课件第 48 页用偏振箭头画出来是：

直角基（Z 基，计算基）          对角基（X 基，哈达玛基）
   0  →  ↑  （竖直偏振）            0  →  ↖  （−45° 偏振，对应 |−⟩）
   1  →  →  （水平偏振）            1  →  ↗  （+45° 偏振，对应 |+⟩）

写成狄拉克记号，直角基就是计算基的两个基矢，对角基就是它们的等权实叠加：

∣0⟩=∣↑⟩,∣1⟩=∣→⟩;∣+⟩=12(∣0⟩+∣1⟩),∣−⟩=12(∣0⟩−∣1⟩).|0\rangle=\lvert\uparrow\rangle,\qquad |1\rangle=\lvert\rightarrow\rangle;\qquad |+\rangle=\frac{1}{\sqrt2}\big(|0\rangle+|1\rangle\big),\qquad |-\rangle=\frac{1}{\sqrt2}\big(|0\rangle-|1\rangle\big).∣0⟩=∣↑⟩,∣1⟩=∣→⟩;∣+⟩=2​1​(∣0⟩+∣1⟩),∣−⟩=2​1​(∣0⟩−∣1⟩).

翻译成人话：竖直/水平是一个「坐标系」，+45°/−45° 是另一个「坐标系」；同一个比特值 000 在这两个坐标系里对应两个不同的量子态。

互补基（mutually unbiased bases，也称共轭基）指的是这样两组基：任何一组基里的基矢，在另一组基下测量时，两个结果的概率都是 1/21/21/2。用式子写就是

∣⟨0∣+⟩∣2=∣⟨0∣−⟩∣2=∣⟨1∣+⟩∣2=∣⟨1∣−⟩∣2=12.\big|\langle 0|+\rangle\big|^2=\big|\langle 0|-\rangle\big|^2=\big|\langle 1|+\rangle\big|^2=\big|\langle 1|-\rangle\big|^2=\frac12 .​⟨0∣+⟩​2=​⟨0∣−⟩​2=​⟨1∣+⟩​2=​⟨1∣−⟩​2=21​.

这只把 ∣+⟩=12(∣0⟩+∣1⟩)|+\rangle=\tfrac{1}{\sqrt2}(|0\rangle+|1\rangle)∣+⟩=2​1​(∣0⟩+∣1⟩) 的系数取模平方：∣12∣2=12\left|\tfrac{1}{\sqrt2}\right|^2=\tfrac12​2​1​​2=21​。这条式子就是 BB84 安全性的全部数学根源——如果你用错了基去测，你得到的信息量是零。

把四个态排成一张表（这也是后面所有概率计算用的字母表）：

比特值 Z 基（直角基）制备的态 X 基（对角基）制备的态
000 ∣↑⟩=∣0⟩\lvert\uparrow\rangle=|0\rangle∣↑⟩=∣0⟩ ∣↖⟩=∣−⟩\lvert\nwarrow\rangle=|-\rangle∣↖⟩=∣−⟩
111 ∣→⟩=∣1⟩\lvert\rightarrow\rangle=|1\rangle∣→⟩=∣1⟩ ∣↗⟩=∣+⟩\lvert\nearrow\rangle=|+\rangle∣↗⟩=∣+⟩

补关于箭头方向：课件第 48 页把 X 基的 000 画成左上箭头 ∣↖⟩\lvert\nwarrow\rangle∣↖⟩、111 画成右上箭头 ∣↗⟩\lvert\nearrow\rangle∣↗⟩，即「0→∣−⟩0\to|-\rangle0→∣−⟩、1→∣+⟩1\to|+\rangle1→∣+⟩」；不少教材采用相反的约定「0→∣+⟩0\to|+\rangle0→∣+⟩、1→∣−⟩1\to|-\rangle1→∣−⟩」。两种写法都只是标签约定：协议只要求 Alice 与 Bob 对「哪支箭头代表 000」有共识。换标签不改变任何结论——筛选、1/41/41/4 与 3/83/83/8 这些误码率数字完全不变。本讲义全篇（含第 3.2 节）统一遵循课件第 48 页的约定。

3.3.3 BB84 的四步流程（PPT 第 48 页）

课件把协议写成四条，我们逐条拆开：

1 Alice 随机利用两组互补基制备并发送 qubit 序列。 对每一个比特，Alice 独立地做两个随机选择：先随机选一个比特值（000 或 111），再随机选一组基（Z 或 X），然后按上表制备对应的态，通过量子通道（quantum channel）发给 Bob。她用两个随机数决定四个态中的一个，四个态等概率，各 1/41/41/4。

2 Bob 随机利用同样两组互补基测量 qubit 序列。 Bob 不知道 Alice 选了什么基，他只能独立地随机选 Z 或 X 去测。测完他手里有 0/1 结果，但此时这些结果还不能当密钥用：因为他选错基时结果是完全随机的。

3 Alice 以经典通道告知 Bob 她每次所用的制备基。 「经典通道」（classical channel）指双方可以公开喊话、Eve 全都能听，但不能篡改（要认证）。Alice 只公布「我第 iii 个比特用的是哪组基」，绝不公布比特值。

于是 Bob 可以逐位对照：两边基相同的比特被留下（这叫筛选，sifting），基不同的比特直接丢弃——因为那些位 Bob 的结果跟 Alice 的比特值无关。

4 Alice 和 Bob 通过经典通道随机抽取一部分「两端基相同」的量子比特作验证量子比特，以确定是否存在窃听者；若不存在，则双方接受密钥。 注意被抽去验证的比特必须从密钥里删掉（它们已经在经典通道上被公开讨论，不再是秘密）。

        ┌───────────┐   量子通道：qubit 序列        ┌───────────┐
        │   Alice   │ ───────────────────────────→ │    Bob    │
        │ 随机选基  │                              │ 随机选基  │
        │ 随机选比特│ ←─────────────────────────── │   测量    │
        └───────────┘   经典通道：公布基 / 抽样比对  └───────────┘
                              ▲
                              │ 拦截—重发
                        ┌───────────┐
                        │    Eve    │
                        └───────────┘

补筛掉一半比特为什么不可惜？ 因为「选错基」这个事件本身是随机的独立事件，淘汰它不会泄漏任何关于比特值的信息——Bob 丢弃的是他自己测错的位，而 Alice 的比特值在这些位上对他本来就是未知的。筛选后剩下的比特数期望是 n/2n/2n/2。

3.3.4 无窃听时，两端结果不一致的概率是 0（题干见 PPT 第 49 页；数值为讲义推导）

课件第 49 页的第一个问题：若不存在侦听，Alice 和 Bob 在任一验证量子比特上获得不同测量值的概率是多少？

因为验证比特的定义就是「两端基相同」的那些位。基相同时，Bob 用的测量算符与 Alice 制备的态属于同一组基：若 Alice 制备 ∣0⟩|0\rangle∣0⟩，Bob 在 Z 基下测得 000 的概率是 ∣⟨0∣0⟩∣2=1|\langle 0|0\rangle|^2=1∣⟨0∣0⟩∣2=1；若 Alice 制备 ∣+⟩|+\rangle∣+⟩，Bob 在 X 基下测得 000 的概率是 ∣⟨+∣+⟩∣2=1|\langle +|+\rangle|^2=1∣⟨+∣+⟩∣2=1。于是

P(不一致∣无窃听，理想信道)=0.P(\text{不一致}\mid \text{无窃听，理想信道})=0 .P(不一致∣无窃听，理想信道)=0.

翻译成人话：理想情况下，只要没人捣乱，两端结果必须逐位相同，一个错都不该有。

3.3.5 有窃听时，不一致的概率是 1/41/41/4（筛选后）/ 3/83/83/8（全部）（题干见 PPT 第 49 页；数值为讲义推导）

页码归属说明：本小节与上一小节的 000、1/41/41/4、3/83/83/8 都是讲义按课件第 49 页的提问自行推导出来的；课件该页只给出两个提问与 Chernoff–Hoeffding 不等式的简化版，并没有写出这些数值。

第二个问题：若存在侦听，不一致的概率是多少？ 这里必须把 Eve 的策略说清楚——BB84 的教科书标准分析假设她做拦截—重发：每个比特都拦下来，自己随机选一组基测量，然后按结果重新制备、发给 Bob。Eve 也是独立随机选基，所以她与 Alice 同基的概率是 1/21/21/2。

对筛选后的验证比特（已保证 Alice 与 Bob 同基），分两种情况：

Eve 拦截—重发（每个比特独立随机选基）
├─ Eve 与 Alice 同基（概率 1/2）
│    Eve 测得的态 = Alice 的态，她重发的态也就是 Alice 的态
│    └─ Bob 在同一组基下测量 → 结果与 Alice 必然相同（贡献 1/2 × 1）
└─ Eve 与 Alice 异基（概率 1/2）
     Eve 重发的是另一组基里的态；Bob 用 Alice 的基去测它
     └─ 互补基的性质 → Bob 的结果与 Alice 相同的概率只有 1/2（贡献 1/2 × 1/2）

把两条加起来：

P(相同∣有窃听，筛选后)=12⋅1+12⋅12=34,P(不一致∣有窃听，筛选后)=14.P(\text{相同}\mid \text{有窃听，筛选后})=\frac12\cdot 1+\frac12\cdot\frac12=\frac34, \qquad P(\text{不一致}\mid \text{有窃听，筛选后})=\frac14 .P(相同∣有窃听，筛选后)=21​⋅1+21​⋅21​=43​,P(不一致∣有窃听，筛选后)=41​.

这就是量子密钥分发里最著名的数字：有拦截—重发窃听时，筛选比特的误码率是 25%25\%25%（quantum bit error rate, QBER，量子误码率）。

如果连基不同的比特也一起算（不筛选，直接问「任一位上两端结果不同的概率」），还要再分一层：基不同时 Bob 的结果与 Alice 的比特值完全无关，相同概率只有 1/21/21/2。于是

P(不一致)=12⋅14+12⋅12=18+14=38.P(\text{不一致})=\frac12\cdot\frac14+\frac12\cdot\frac12=\frac18+\frac14=\frac38 .P(不一致)=21​⋅41​+21​⋅21​=81​+41​=83​.

翻译成人话：有窃听时，888 个比特里大约有 333 个会对不上；没窃听时，一个都不该对不上。这个巨大的差距，就是第 3.4 节要用统计不等式去量化的东西。

补Eve 有没有更「隐蔽」的策略？ 有。她可以对一部分比特窃听、或者用非正交态做更精细的攻击（如集体攻击、相干攻击），把误码率压到 ≤25%\le 25\%≤25% 以下。但只要她的攻击给了她关于密钥的任何信息，误码率就必然大于零——这背后的定量关系（安全性的误码率判据）属于 QKD 安全证明的内容。本节只需要抓住「零 vs 非零」这个可检测的差别。

3.3.6 为什么公布制备基不会泄漏比特值

这是初学者最容易被卡住的地方：Alice 都在经典通道上把基喊出来了，Eve 不就知道了吗？

关键在于「基」和「值」是两个独立的随机变量。基相同的那些比特，Alice 公布的信息是「我用 Z 基」——这句话对「我发的是 000 还是 111」没有任何约束，因为她在 Z 基下发 000（∣0⟩|0\rangle∣0⟩）和发 111（∣1⟩|1\rangle∣1⟩）的概率各是 1/21/21/2。也就是说

P(比特=0∣公布基=Z)=P(比特=1∣公布基=Z)=12.P(\text{比特}=0\mid \text{公布基}=Z)=P(\text{比特}=1\mid \text{公布基}=Z)=\frac12 .P(比特=0∣公布基=Z)=P(比特=1∣公布基=Z)=21​.

翻译成人话：知道基，等价于知道「谜面用的是哪套坐标」，但谜底仍然是均匀随机的。

真正泄漏信息的时刻是测量：Eve 若要获得比特值，就必须对量子比特做测量（或伪造），而互补基的性质使她的测量必然在筛选比特上引入约 25%25\%25% 的误码——获得信息必然留下痕迹。这正是第 3.1 节那句话的具体兑现：量子框架下，泄漏必然破坏信息本身。

本节要点

  1. BB84 用四个态：Z 基的 ∣0⟩,∣1⟩|0\rangle,|1\rangle∣0⟩,∣1⟩ 与 X 基的 ∣+⟩,∣−⟩|+\rangle,|-\rangle∣+⟩,∣−⟩；两组基互补（互相测量时结果各 1/21/21/2）。
  2. 流程四步：Alice 随机制备 → Bob 随机测量 → 公布基并筛选 → 抽验证比特比对。
  3. 无窃听（理想通道）时，验证比特不一致概率为 000。
  4. 拦截—重发窃听下，筛选比特误码率为 1/41/41/4；不筛选时为 3/83/83/8。
  5. 公布基不泄漏比特值；泄漏信息必然引入误码，因此窃听可被统计检测。

自测题

  1. Alice 用 Z 基制备 ∣1⟩|1\rangle∣1⟩，Bob 用 X 基测量。他测得 000 与测得 111 的概率各是多少？
  2. 为什么 BB84 中 Bob 选错基的那些比特必须全部丢掉，而不能靠后续纠错「救回来」？
  3. Eve 对每个比特都做拦截—重发。Alice 与 Bob 在一段原始（未筛选）比特上，结果不一致的概率是多少？请写出推导。
  4. 若 Eve 只测量、不重发（即截断信道），Alice 和 Bob 会发现什么异常？
答案
  1. ∣1⟩|1\rangle∣1⟩ 在 X 基下展开为 ∣1⟩=12(∣+⟩−∣−⟩)|1\rangle=\tfrac{1}{\sqrt2}(|+\rangle-|-\rangle)∣1⟩=2​1​(∣+⟩−∣−⟩)，故 P(0)=∣⟨+∣1⟩∣2=12P(0)=|\langle+|1\rangle|^2=\tfrac12P(0)=∣⟨+∣1⟩∣2=21​，P(1)=∣⟨−∣1⟩∣2=12P(1)=|\langle-|1\rangle|^2=\tfrac12P(1)=∣⟨−∣1⟩∣2=21​。用错基测量，结果与比特值无关，信息量为零。
  2. 因为基不同时 Bob 的结果与他自己的测量基是绑定的，与 Alice 的比特值统计独立（各 1/21/21/2）。这些位不携带任何关于 Alice 比特值的信息，属于「纯噪声」，留下来只会污染密钥，无法靠纠错恢复（纠错不能凭空创造信息）。
  3. 分两种情形：两基相同（概率 1/21/21/2）时，Eve 同基概率 1/21/21/2 则必相同，异基时相同概率 1/21/21/2，故相同概率为 34\tfrac3443​、不一致 14\tfrac1441​；两基不同（概率 1/21/21/2）时，Bob 结果与 Alice 比特值无关，不一致概率 12\tfrac1221​。合计 P=12⋅14+12⋅12=38P=\tfrac12\cdot\tfrac14+\tfrac12\cdot\tfrac12=\tfrac38P=21​⋅41​+21​⋅21​=83​。
  4. Bob 收不到任何量子比特（或只有噪声），「筛选后比特数」会远低于预期的 n/2n/2n/2，或者他测得的结果与 Alice 完全不相关（不一致率趋近 1/21/21/2）。信道损耗与窃听都会表现为「计数率异常 + 误码」，所以实际系统要把两者联合起来监控。
