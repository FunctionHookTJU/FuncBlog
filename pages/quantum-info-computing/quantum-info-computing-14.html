2.6 隐变量模型的总结与逻辑谱系

逻辑谱系：箭头就是「蕴含」

课件用一张图收束前五节，标题是主要非经典统计特征的逻辑谱系，并注明箭头表示蕴含关系。（PPT 第 42 页）

                        ┌──────────────────────────────┐
                        │ 非局域性                      │
                        │ 例如 (λ+-, λ-+) 的隐变量序偶    │
                        │ 一般不存在                    │
                        └──────────────▲───────────────┘
                                       │
   ┌──────────────────┐   Spekkens   ┌─┴────────────────────────┐
   │ 负性              │◀────2008────▶│ 上下文性                  │
   │ （伪概率表示的负性）│              │ 例如 λ+- 的隐变量一般不存在 │
   └────────▲─────────┘              └────────────▲─────────────┘
            │                                     │
            └──────────────┬──────────────────────┘
                    ┌──────┴───────────────────────────┐
                    │ （概率）不兼容性                  │

四个特征的含义（PPT 第 42 页）：

特征 一句话含义 课件给的例子
（概率）不兼容性（incompatibility） 存在不能同时被精确测量的观测量组合；概率层面就已经冲突 最根本的非经典统计特征
上下文性（contextuality） 无法给投影算子分配与上下文无关的确定值 「λ+−\lambda_{+-}λ+−​ 的隐变量一般不存在」
负性（negativity） 用伪概率（quasiprobability）表示量子态时必然出现负值 伪概率表示的负性
非局域性（nonlocality） 无法给两个分离系统同时分配局域确定值 「(λ+−,λ−+)(\lambda_{+-},\lambda_{-+})(λ+−​,λ−+​) 的隐变量序偶一般不存在」

逐条读懂这张图：

  • 不兼容性在最底层：课件称它「最根本」。它是源头，另外三个特征都由它派生；这与第 1.1 节讲的「测量不兼容性是 EPR 争议的核心」呼应。
  • 不兼容性 ⇒\Rightarrow⇒ 上下文性：不兼容的观测量无法同时拥有确定值，于是「给每个投影算子预先贴好 0/1 标签」这件事在多组基之间必然撞车。这正是 KS 定理的机制。
  • 不兼容性 ⇒\Rightarrow⇒ 负性：不兼容意味着不存在联合概率分布，于是任何试图用「经典概率分布」写量子统计的表示都会出现负值。
  • 负性 ⇔\Leftrightarrow⇔ 上下文性（Spekkens 2008）：双向箭头表示等价。Spekkens 在 2008 年证明：在一个给定的伪概率表示框架里，「存在负性」与「存在上下文性」是同一件事的两种说法——负性是上下文性在「准概率语言」里的翻译。
  • 上下文性 ⇒\Rightarrow⇒ 非局域性：非局域性是上下文性的特殊形态。Bell 场景（两方、各自选测量）就是一种特殊的「测量上下文场景」，所以非局域关联可以用上下文性的语言统一描述。

补关于这张图箭头的读法。文献里更常见的读法是「非局域性是上下文性的一个特例」（即在 Bell 场景下，非局域性 ⇒\Rightarrow⇒ 上下文性）。课件把箭头画成由上下文性指向非局域性，应当理解为「更普遍的、下层的特征涵盖并生出上层的特殊特征」：不兼容性是最普遍的语言，上下文性/负性居中，非局域性是其特例。无论采用哪种箭头读法，这张图的结论都一致：四个非经典特征不是彼此孤立的清单，而是同一件事在不同层次上的表现，而不兼容性处在最底层。

勘误课件图上的箭头方向（上下文性 →\to→ 非局域性）与文献中通常的蕴含方向（非局域性 ⇒\Rightarrow⇒ 上下文性）相反。若按字面把它当作「上下文性蕴含非局域性」来引用，会在「单系统上下文性能否直接推出两体非局域关联」这个技术问题上被追问；考试或报告里建议把这张图读作「四个特征的层次结构图」，或明确写出你采用的蕴含方向。

两种不可能性定理的分工

课件把整讲的结论压成三行（PPT 第 43 页）：

  • 局域隐变量（LHV）模型的不可能性：Bell 不等式族；
  • 非上下文隐变量（NCV）模型的不可能性：KS 定理和 KCBS 不等式等；
  • 结论：任何解释 QM 的隐变量模型，必须是全局的、上下文的。

把两个定理的「分工」列成表更清楚：

隐变量模型 额外假设 被谁否掉 留下的活路
LHV（局域隐变量） 决定性 + 非上下文 + 局域 Bell/CHSH 不等式族的实验违背 放弃局域性
NCV（非上下文隐变量） 决定性 + 非上下文 KS 定理（态无关）、KCBS 不等式（态相关） 放弃非上下文性
DC（全局 + 上下文） 决定性 没有被否掉（第 2.4 节的平凡构造） 代价：模型失去解释力

翻译成人话：Bell 砍掉「局域」，KS/KCBS 砍掉「非上下文」，两条腿都被砍完之后，隐变量论只剩下一种姿势能站着——全局的、上下文的。但第 2.4 节已经说明，这种模型可以平凡地造出来，代价是 λ\lambdaλ 必须携带「这次用哪个基」的信息，因此它不再给出任何独立预言。

补这正是「量子上下文性」在物理上的分量：它并不是说「量子力学很玄」，而是说「值先于测量而存在」这个朴素直觉与量子力学的统计不能兼得——你必须放弃非上下文性（于是值依赖语境），或者放弃决定性（于是接受内禀随机），或者放弃局域性（于是接受超距影响）。三者必舍其一。

思考题：客观性是实在的特性，还是认知过程的特性？

课件最后留下一道开放思考题（PPT 第 43 页）：

朴素的客观性观念受到 QM 实验结果的挑战，一种有非定域（瞬时）超距作用的、上下文的「客观性」，是客观实在的特性，还是认知过程的特性？

两种读法都值得写清楚：

  • 读法一（客观实在的特性）：DC 模型告诉我们，即使允许超距耦合，隐变量的取值也必须依赖测量上下文。于是「上下文性」就不是「我们知识不够」的产物，而是世界本身的结构——连上帝视角的 λ\lambdaλ 也得看基说话。
  • 读法二（认知过程的特性）：另一种观点认为，上下文性恰恰暴露了「可观测量有预先确定的值」这个提问方式不适合量子世界。上下文性不是世界的性质，而是「我们把测量结果硬塞进『预先存在的值』这个认知框架」时产生的张力（这与 QBism、关系性量子力学等「认知/关系」解读相呼应）。

翻译成人话：这道题没有标准答案，它把整讲的物理结论推向一个解释学问题。本讲能确定的是物理约束：你不可能同时拥有「局域 + 非上下文 + 决定性」的隐变量模型；至于剩下的那种「全局 + 上下文」的客观性该算实在还是算认知，取决于你选择哪一种量子力学诠释。

补如何写这道思考题：好的答法不是选边站，而是先复述约束（Bell + KS/KCBS 的判决），再给出两种读法各自需要承担的代价：读法一需要解释「为什么世界的属性要依赖我们怎么问」；读法二需要解释「为什么测量结果表现出如此稳定的、可重复的统计规律」。两边都不轻松，这才是这道题的意义。

小结

一句话串起本讲：把 O3 这条最弱的客观性写成 D-NC 隐变量模型后，单量子比特能被两个基本实体精确复现（二维每个投影算子只有唯一上下文），但 KS 定理用「9 组基 × 18 个投影算子各出现两次」的奇偶性矛盾证明非上下文赋值在四维必然失败，KCBS 不等式又把这一失败变成可实验判决的定量门槛 β=∑i=04⟨Pi⟩≤2\beta=\sum_{i=0}^{4}\langle P_i\rangle\le2β=∑i=04​⟨Pi​⟩≤2 被量子力学的 5\sqrt55​ 违背——于是任何解释量子力学的隐变量模型都只能是全局的、上下文的。

核心结论清单

  1. 客观性三重含义：O1 朴素、O2 局域、O3 上下文，满足 O1 ⇒\Rightarrow⇒ O2 ⇒\Rightarrow⇒ O3；三者都要求「值先于测量」，因此都是隐变量模型。
  2. D-NC 模型：决定性 + 非上下文，是最弱的隐变量理论；合法性要求「λ\lambdaλ 在每组基上恰好取一次 1」。
  3. 二维必然成功：d=2d=2d=2 时每个投影算子只有唯一一组基，故不存在「换上下文」；∣0⟩=12λ+−+12λ++|0\rangle=\tfrac12\lambda_{+-}+\tfrac12\lambda_{++}∣0⟩=21​λ+−​+21​λ++​ 即可精确复现 ZZZ 基与 XXX 基统计。
  4. KS 定理：d≥3d\ge3d≥3 时不存在满足「每组正交基恰好一个 1」的非上下文赋值。课件反例是 9 组基、18 个投影算子各出现 2 次；按列求和得奇数 9，按算子合并得偶数 2k2k2k，矛盾。
  5. 上下文性 ≠ 概率依赖上下文：tr(Mρ)\mathrm{tr}(M\rho)tr(Mρ) 恒与测量基无关；上下文性发生在隐变量层，即 λ(M/B1)≠λ(M/B2)\lambda(M/B_1)\neq\lambda(M/B_2)λ(M/B1​)=λ(M/B2​)。
  6. 强上下文性：概率本身随上下文改变；它严格强于标准上下文性（KS 型上下文性就是「标准但不强」）。
  7. KCBS 不等式：5-cycle 上相邻事件互斥，NCHV 要求 β≤2\beta\le2β≤2（因 α(C5)=2\alpha(C_5)=2α(C5​)=2），量子力学给出 βQM=5≈2.236\beta_{\mathrm{QM}}=\sqrt5\approx2.236βQM​=5​≈2.236；手算例 β=20/9≈2.2222\beta=20/9\approx2.2222β=20/9≈2.2222。
  8. 逻辑谱系：不兼容性最根本，它推出上下文性与负性；负性与上下文性等价（Spekkens 2008）；非局域性是其特殊形态。
  9. 最终结论：LHV 被 Bell 不等式族否掉，NCV 被 KS 定理与 KCBS 不等式否掉，所以任何解释量子力学的隐变量模型必须全局且上下文——而这样的模型可以平凡构造，代价是失去解释力与预言力。
