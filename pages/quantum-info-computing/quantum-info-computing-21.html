4.3.1 练习：四个 Bell 态的投影算子构成一个投影测量基（PPT 第 57 页）

练习（课件第 57 页）：证明 {∣ψ0⟩⟨ψ0∣, ∣ψ1⟩⟨ψ1∣, ∣ψ2⟩⟨ψ2∣, ∣ψ3⟩⟨ψ3∣}\big\{|\psi_0\rangle\langle\psi_0|,\ |\psi_1\rangle\langle\psi_1|,\ |\psi_2\rangle\langle\psi_2|,\ |\psi_3\rangle\langle\psi_3|\big\}{∣ψ0​⟩⟨ψ0​∣, ∣ψ1​⟩⟨ψ1​∣, ∣ψ2​⟩⟨ψ2​∣, ∣ψ3​⟩⟨ψ3​∣} 构成了一个投影测量基，其中 ∣ψ0⟩,∣ψ1⟩,∣ψ2⟩,∣ψ3⟩|\psi_0\rangle,|\psi_1\rangle,|\psi_2\rangle,|\psi_3\rangle∣ψ0​⟩,∣ψ1​⟩,∣ψ2​⟩,∣ψ3​⟩ 是四个贝尔态。

4.3.2 问题：Bob 为何不直接用 Bell 基测量？（PPT 第 57 页）

既然刚才证明了「四个 Bell 态可以被完美区分」，那 Bob 直接对两个比特做 Bell 基测量、一步读出 000–333 不就完了？

课件第 57 页的解释：全局测量难以直接实现。

翻译成人话：∣ψi⟩⟨ψi∣|\psi_i\rangle\langle\psi_i|∣ψi​⟩⟨ψi​∣ 这种算符是两比特联合测量，它不是「对第一个比特测一下、再对第二个比特测一下」——它要求两个量子比特在测量装置里发生可控的相互作用，并且要在纠缠基下做投影。在实验中，让两个量子比特在保持相干的前提下做联合投影，比单比特测量难得多。

补这正是超密编码协议的实际价值。 第 4.2 节的六步流程做的事情是：把「一次难实现的两比特 Bell 基测量」分解成

CNOT⏟两比特门 + H⏟单比特门 + 两次单比特测量⏟最容易做的操作.\underbrace{\text{CNOT}}_{\text{两比特门}}\ +\ \underbrace{H}_{\text{单比特门}}\ +\ \underbrace{\text{两次单比特测量}}_{\text{最容易做的操作}} .两比特门CNOT​​ + 单比特门H​​ + 最容易做的操作两次单比特测量​​.

也就是说，六步流程不是数学上「必须这么走」，而是实验上「这样才做得出来」。「把全局测量分解为局域操作 + 经典后处理」是量子信息里反复出现的手法（量子隐形传态、纠缠交换、量子纠错都靠它）。

补一般情形不能这么省。 并非任何联合测量都能用「局域门 + 单比特测量」实现；能这样分解的测量叫可局域实现（LOCC 可实现）的测量。Bell 基测量之所以幸运，是因为四个 Bell 态构成一个可由 CnotC_{not}Cnot​ 与 HHH 变换到计算基的正交基（下一段给出理由）：先做 CnotC_{not}Cnot​ 再做 H1H_1H1​，恰好把四个 Bell 态映射成四个计算基态，之后的测量就是普通的单比特测量。

手算验证这个映射（与 4.2.3–4.2.4 节同一套计算，只是写成「正向」形式）：

(H⊗I) Cnot ∣ψ0⟩=∣00⟩,(H⊗I) Cnot ∣ψ1⟩=∣01⟩,(H⊗I) Cnot ∣ψ2⟩=∣11⟩,(H⊗I) Cnot ∣ψ3⟩=∣10⟩.(H\otimes I)\,C_{not}\,|\psi_0\rangle=|00\rangle,\qquad (H\otimes I)\,C_{not}\,|\psi_1\rangle=|01\rangle,\qquad (H\otimes I)\,C_{not}\,|\psi_2\rangle=|11\rangle,\qquad (H\otimes I)\,C_{not}\,|\psi_3\rangle=|10\rangle .(H⊗I)Cnot​∣ψ0​⟩=∣00⟩,(H⊗I)Cnot​∣ψ1​⟩=∣01⟩,(H⊗I)Cnot​∣ψ2​⟩=∣11⟩,(H⊗I)Cnot​∣ψ3​⟩=∣10⟩.

以 ψ2\psi_2ψ2​ 为例：CnotC_{not}Cnot​ 后第一个比特为 12(−∣1⟩+∣0⟩)=∣−⟩\frac{1}{\sqrt2}(-|1\rangle+|0\rangle)=|-\rangle2​1​(−∣1⟩+∣0⟩)=∣−⟩、第二个比特为 ∣1⟩|1\rangle∣1⟩；再对第一个比特做 HHH，H∣−⟩=∣1⟩H|-\rangle=|1\rangleH∣−⟩=∣1⟩，得到 ∣11⟩|11\rangle∣11⟩ ✓。以 ψ3\psi_3ψ3​ 为例：CnotC_{not}Cnot​ 后第一个比特为 12(∣0⟩−∣1⟩)=∣−⟩\frac{1}{\sqrt2}(|0\rangle-|1\rangle)=|-\rangle2​1​(∣0⟩−∣1⟩)=∣−⟩、第二个比特为 ∣0⟩|0\rangle∣0⟩；HHH 之后第一个比特变成 ∣1⟩|1\rangle∣1⟩，得到 ∣10⟩|10\rangle∣10⟩。由于四个 Bell 态被送到四个不同的计算基态，一次计算基测量就把它们完全分开——这就是「Bell 基测量可以拆成 CNOT + H + 单比特测量」的全部道理。

4.3.3 纠缠粒子可以空间分离，但这不违反相对论（PPT 第 57 页）

注（课件第 57 页）：两个彼此纠缠的粒子可以空间分离地存在。

超密编码里，Alice 与 Bob 各持纠缠对的一半，两人可以相距任意远。这会引出初学者最常见的疑问：这是不是一种超光速通信？

不是。 逐条核对超密编码的三个阶段：

阶段 发生了什么 是否受光速限制
准备 生成 ψ0\psi_0ψ0​ 并把两个粒子分别送到 Alice、Bob 手上 要送粒子就要走物理信道，速度 ≤c\le c≤c
通信 Alice 把她那一半物理发送给 Bob（量子通道） 是，v≤cv\le cv≤c
解码 Bob 做 CNOT、H 与两次测量 局域操作，不传信息

翻译成人话：Bob 在没收到 Alice 的量子比特之前，手上什么都没有——他甚至不知道 Alice 有没有做编码。信息是通过「把量子比特送过去」这一步传递的，而它老老实实受光速限制。 纠缠只是让这 111 个量子比特「装得下」222 个比特，并没有让信号跑得更快。

补与量子隐形传态（quantum teleportation）的对偶。两者都用一对预共享的 Bell 态，但资源分配正好相反：

超密编码 量子隐形传态
预共享 Bell 态 Bell 态
通信阶段发送的量子比特 111 个（Alice 的那一半） 000 个（只做 Bell 基测量）
通信阶段发送的经典比特 000 个 222 个
效果 传输 222 比特经典信息 传输 111 个量子态

一句话记忆：超密编码是「111 qubit 换 222 cbit」，隐形传态是「222 cbit 换 111 qubit」，两者都靠同一对纠缠做「汇率」。

4.3.4 协议的信息论意义：111 个量子比特真的能载 222 比特吗？

课件本节的核心结论是：协议的信息论意义在于「111 qubit 载 222 bit 经典信息」。

这句话必须带上限定语才严谨，否则会与 Holevo 界冲突（Holevo 界的引入见第 4.2.1 节的补，附录 C.15 也有专门的问答）：

场景 单个量子比特最多能携带的经典信息
无预共享纠缠，Alice 直接把 111 个量子比特发给 Bob ≤1\le 1≤1 比特（Holevo 界）
预共享一对 Bell 态，Alice 只发她那 111 个量子比特 222 比特（超密编码）

翻译成人话：多出来的那 111 个比特不是「凭空塞进量子比特」的，而是早就存在那对纠缠里了。要做一次超密编码，就必须先建立一对 Bell 态；而建立纠缠本身要消耗量子通道（例如产生纠缠光子对并把两个光子分别送出去）。所以正确的说法是：

预共享纠缠+1 qubit ⟶ 2 cbit.\text{预共享纠缠}+1\ \text{qubit}\ \longrightarrow\ 2\ \text{cbit} .预共享纠缠+1 qubit ⟶ 2 cbit.

补纠缠是一种可量化的资源。 正因为纠缠能被「换算」成通信容量，它才值得被当作独立的研究对象（纠缠熵、纠缠蒸馏、纠缠交换等）。超密编码是这个观念最干净的第一个例子：它不是「量子力学推翻了信息论」，而是「信息论在资源清单里多了一项纠缠」。

小结

一句话串起本讲（第四讲　量子超密编码）：本讲先用两个最基本的门把工具备齐——CNOT 能把叠加变成纠缠、H 能把相位差翻成比特差；再让一对预先共享的 Bell 态充当「预付的资源」，Alice 用四个 Pauli 局域操作把自己的 222 比特编进那一半纠缠里，Bob 用 CNOT 把纠缠拆成乘积态、用一次 H 把相位差翻成 0/10/10/1，两次单比特测量就确定地读出信息；其实质是把一次难以实现的 Bell 基全局测量分解为「单比特门 + 单比特测量」，而全部代价早已预付在那对纠缠上——所以 111 个量子比特载 222 个经典比特既不违背 Holevo 界，也不违背相对论。

核心结论清单

  1. {Pi=∣ψi⟩⟨ψi∣}i=03\{P_i=|\psi_i\rangle\langle\psi_i|\}_{i=0}^{3}{Pi​=∣ψi​⟩⟨ψi​∣}i=03​ 满足 Pi†=PiP_i^{\dagger}=P_iPi†​=Pi​、Pi2=PiP_i^{2}=P_iPi2​=Pi​、PiPj=δijPiP_iP_j=\delta_{ij}P_iPi​Pj​=δij​Pi​、∑iPi=I\sum_iP_i=I∑i​Pi​=I，是一个合法的投影测量基；据此四个 Bell 态能以概率 111 被完全区分。
  2. 完备性的关键在于把两比特空间分成 {∣00⟩,∣11⟩}\{|00\rangle,|11\rangle\}{∣00⟩,∣11⟩} 与 {∣01⟩,∣10⟩}\{|01\rangle,|10\rangle\}{∣01⟩,∣10⟩} 两块，每块里的两个投影算子相加恰好给出该块的计算基投影之和。
  3. Bob 不直接用 Bell 基测量的原因是全局（联合）测量难以直接实现；六步流程把 Cnot+H+C_{not}+H+Cnot​+H+ 两次单比特测量拼成等效的 Bell 基测量。
  4. 映射关系：∣ψ0⟩→∣00⟩|\psi_0\rangle\to|00\rangle∣ψ0​⟩→∣00⟩、∣ψ1⟩→∣01⟩|\psi_1\rangle\to|01\rangle∣ψ1​⟩→∣01⟩、∣ψ2⟩→∣11⟩|\psi_2\rangle\to|11\rangle∣ψ2​⟩→∣11⟩、∣ψ3⟩→∣10⟩|\psi_3\rangle\to|10\rangle∣ψ3​⟩→∣10⟩（在 CnotC_{not}Cnot​ 后接 H1H_1H1​ 的作用下，下标 111 表示只对第一个比特做 HHH）。
  5. 纠缠粒子可以空间分离，但超密编码不违背相对论：信息靠「物理发送那 111 个量子比特」传递，v≤cv\le cv≤c。
  6. 信息论意义：111 qubit 载 222 bit 只在预共享纠缠的前提下成立，与 Holevo 界（无纠缠时 ≤1\le1≤1 bit）并不矛盾；纠缠是可量化、可换算成通信容量的资源。
  7. 超密编码（1 qubit + 纠缠 →\to→ 2 cbit）与量子隐形传态（2 cbit + 纠缠 →\to→ 1 qubit）互为对偶。

  2. 因为 {∣00⟩,∣11⟩}\{|00\rangle,|11\rangle\}{∣00⟩,∣11⟩} 与 {∣01⟩,∣10⟩}\{|01\rangle,|10\rangle\}{∣01⟩,∣10⟩} 是两比特空间里两个互相正交的子空间，任何跨子空间的外积项在求和时都会因为「跨子空间内积为零」而消失。于是只需在每个子空间内部做一次「两个 Bell 态投影相加」的二维小计算：P0+P3=∣00⟩⟨00∣+∣11⟩⟨11∣P_0+P_3=|00\rangle\langle00|+|11\rangle\langle11|P0​+P3​=∣00⟩⟨00∣+∣11⟩⟨11∣、P1+P2=∣01⟩⟨01∣+∣10⟩⟨10∣P_1+P_2=|01\rangle\langle01|+|10\rangle\langle10|P1​+P2​=∣01⟩⟨01∣+∣10⟩⟨10∣，两者相加立即得到 III。

  4. 能。协议只要求预共享的是一对最大纠缠态，四个 Pauli 编码把 ∣ψ3⟩|\psi_3\rangle∣ψ3​⟩ 同样映射成四个彼此正交的态，之后的 CNOT + H + 两次测量是固定的解码电路，判决表会相应地整体移位，但每个 222 比特值仍对应唯一一组测量结果。实际使用中一般约定用 ∣ψ0⟩=Φ+|\psi_0\rangle=\Phi^{+}∣ψ0​⟩=Φ+ 只是为了记账方便。
  5. 错误。超密编码成立的前提是预先共享一对纠缠比特；建立纠缠本身要消耗量子通道资源（要把两个粒子分别送达双方）。不带纠缠时 Holevo 界给出「nnn 个量子比特最多 nnn 个经典比特」，所以这是「纠缠 + 1 qubit →\to→ 2 cbit」的资源换算，而不是「量子比特本身就值两个经典比特」。
  6. 超密编码：通信阶段 Alice 发送 111 个量子比特、不发经典比特，效果是把 222 比特经典信息传给 Bob。量子隐形传态：通信阶段双方做 Bell 基测量后要发送 222 个经典比特、不发量子比特，效果是把 111 个量子态传给 Bob。两者都消耗一对预共享的 Bell 态。
