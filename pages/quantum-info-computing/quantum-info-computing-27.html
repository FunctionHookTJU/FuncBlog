附录 A 使用说明

本附录把全书（P1 与 P2）出现的核心术语按主题汇成一张中英对照表，共 97 条。每条的格式是「中文（含英文缩写）｜英文原名｜一句话解释」。

三点使用建议：

  1. 首次读到某个术语时先查这里，再到对应小节看推导——本表只给「一句话定义」，不替代推导。
  2. 英文名是查文献的钥匙。中文译名在同一批文献里常有多种（例如 contextuality 译作「上下文性」「互文性」「文脉性」），只有英文名唯一。
  3. P1 与 P2 的术语都在表内（含量子密钥分发与量子计算两讲），可作为考前快速回查的索引。

补表中带「（P1）」的条目属于上一讲《量子力学讲义：导论与量子力学基础》的内容，本讲义沿用其定义，不重复推导。

A.1 纠缠、EPR 与 Bell 不等式

中文术语 英文原名 一句话解释
量子纠缠 quantum entanglement 复合态无法写成各子系统态的直积，测量结果之间存在非经典关联。
直积态 product state 可写成两个子系统态张量积的复合态，不纠缠。
贝尔态 Bell state 两量子比特的最大纠缠态，共四个，构成一组正交基。
反相关贝尔态 anti-correlated Bell state ∣Φ−⟩=(∣01⟩−∣10⟩)/2\lvert\Phi^-\rangle=(\lvert 01\rangle-\lvert 10\rangle)/\sqrt2∣Φ−⟩=(∣01⟩−∣10⟩)/2​，两端同向测量必得相反结果。
局域测量 local measurement 只作用在纠缠态某一个子系统上的测量。
相关函数 correlation function 两端测量结果乘积的平均值，常记 E(A⋅B)E(A\cdot B)E(A⋅B) 或 CABC_{AB}CAB​。
隐变量 hidden variable 量子态描述之外补充的未知参数，用来把随机性归结为无知。
局域隐变量模型 local hidden variable (LHV) model 测量结果由粒子自带的值决定，且远端测量不能瞬时影响本端。
定域实在论 local realism 「实在论」加「局域性」的世界观，LHV 的哲学表述。
定域决定论 local determinism 结果由内蕴属性完全决定，且影响不能超光速传播。
EPR 佯谬 EPR paradox Einstein、Podolsky、Rosen 论证量子力学对物理实在的描述不完备。
完备性 completeness 一个理论体系能建模物理世界的所有实际状态。
测量不兼容性 measurement incompatibility 两个可观测量不对易，不能同时具有确定值。
超距（EPR）关联 EPR correlation / action at a distance 课件用语：纠缠粒子之间存在的瞬时相互影响。
共轭可观测量 conjugate (complementary) observables 彼此不兼容的一对可观测量，如 σ1\sigma_1σ1​ 与 σ3\sigma_3σ3​。
概率混合 probabilistic mixture 按隐变量取值的概率加权得到的统计描述。
隐变量序偶 pair of hidden variables 描述两端各自隐变量的组合 (λA,λB)(\lambda_A,\lambda_B)(λA​,λB​)。
局域性漏洞 locality loophole 实验中两端距离或时序不足，使信号可能偷偷传递的缺陷。
检测效率漏洞 detection loophole 被探测到的子样本不具代表性而导致的结论缺陷。
自由意志假设 free will assumption 测量设置的选择独立于隐变量，是 Bell 实验的前提（PPT 第 27 页）。

A.2 非信号原则与关联的边界

中文术语 英文原名 一句话解释
非信号原则 no-signaling principle 一端的局域操作不改变另一端测量结果的边缘统计。
边缘概率 marginal probability 对不关心的变量求和后留下的概率分布。
显著可辨识影响 statistically detectable influence 能改变边缘统计、从而被统计检验发现的效应。
非局域性 nonlocality 量子关联无法被任何 LHV 模型复现的性质。
CHSH 不等式 CHSH inequality LHV 与经典概率模型必须满足的相关组合上界 222。
CHSH Clauser–Horne–Shimony–Holt 提出该不等式的四位物理学家的姓氏词头（PPT 第 23 页）。
Tsirelson 界 Tsirelson bound 量子力学允许的相关组合最大值 222\sqrt222​。
PR 箱 Popescu–Rohrlich box 满足非信号原则但把相关组合推到 444 的假想装置。
异或 exclusive OR (⊕\oplus⊕) 模 2 加法，1⊕1=01\oplus1=01⊕1=0。
经典设置下的违背 classical violation of CHSH 用共享随机数等经典资源伪造关联的协议（PPT 第 27 页大作业）。

A.3 上下文性与隐变量的逻辑谱系

中文术语 英文原名 一句话解释
量子上下文性 quantum contextuality 测量结果依赖于该观测量所处的测量基（上下文），又称互文性、文脉性。
上下文 context 包含目标可观测量的一组兼容测量，即一个测量基。
客观性 objectivity 物理量的值独立于测量过程而存在。
朴素客观性 naive objectivity (O1O1O1) 值先于测量存在，不受不兼容量测量影响，且与上下文无关。
局域客观性 local objectivity (O2O2O2) 把 O1O1O1 中的「不兼容量测量」限制为充分远处发生的测量。
上下文客观性 contextuality objectivity (O3O3O3) 值先于测量且与上下文无关，但放弃局域性（允许全局隐变量）。
决定性 determinism (D) 测量结果由隐变量完全决定，先于测量而存在。
非上下文性 non-contextuality (NC) 隐变量的值与测量该属性所处的测量基无关。
D-NC 模型 deterministic non-contextual model 同时满足 D 与 NC 的最弱隐变量模型，单比特时可任意精度逼近。
强上下文性 strong contextuality 允许 tr(Mρ)\mathrm{tr}(M\rho)tr(Mρ) 本身依赖 MMM 所在测量基的更强主张。
测量结果合法性 validity of measurement outcomes 同一测量基内隐变量恰好取一次 111，满足互斥事件的穷尽性。
KS 定理 Kochen–Specker theorem 不存在对所有投影算子一致赋值的非上下文隐变量模型。
NCHV non-contextual hidden variable 非上下文隐变量（模型）。
KCBS 不等式 KCBS inequality 5 环图上的非上下文不等式 β≤2\beta\le 2β≤2，量子可达 5\sqrt55​。
互斥事件 mutually exclusive events 不能同时为真的事件，量子情形对应正交投影。
逻辑谱系 logical hierarchy 不兼容性 ⇒\Rightarrow⇒ 上下文性 ⇒\Rightarrow⇒ 非局域性 ⇒\Rightarrow⇒ 负性。
负性 negativity 伪概率表示中出现负值，被视为最根本的非经典统计特征（Spekkens 2008）。
全局隐变量 global hidden variable 不要求局域性、允许两个隐变量超距耦合的隐变量框架。

A.4 量子密钥分发

中文术语 英文原名 一句话解释
量子密钥分发 quantum key distribution (QKD) 用测量塌缩保证「窃听必留痕迹」的密钥协商方案。
测量塌缩 measurement collapse 测量把态投影到测量基上，原始叠加信息被破坏。
不可克隆定理 no-cloning theorem 不存在能复制任意未知量子态的酉算子。
BB84 方案 BB84 protocol 两组互补基制备与测量、经典通道筛选与验证的四步协议。
互补基 mutually complementary (unbiased) bases 一个基中的任一态在另一个基下测量结果等概率，如 ZZZ 基与 XXX 基。
窃听者 eavesdropper (Eve) 试图截获密钥的第三方。
截获—重发攻击 intercept–resend attack 窃听者测量后照结果重发，会在验证比特留下误码。
验证比特 test bits (check bits) 用于估计误码率、随后丢弃的那部分比特。
误码率 quantum bit error rate (QBER) 验证比特中两端结果不一致的比例。
Chernoff–Hoeffding 不等式 Chernoff–Hoeffding inequality 给出样本均值偏离期望的概率上界，用于窃听检测的显著性估计。
统计假设检验 statistical hypothesis testing 在零假设下计算样本（或更极端样本）的概率，小于阈值则拒绝零假设。
零假设 null hypothesis (H0H_0H0​) 假设检验中先假定成立的那个命题（此处为「未被侦听」）。

A.5 超密编码与基本门

中文术语 英文原名 一句话解释
超密编码 superdense coding 借助预共享纠缠，用 1 个量子比特传送 2 个经典比特。
CNOT 门 controlled-NOT gate 以第一个比特为控制、翻转第二个比特的两比特门。
Walsh–Hadamard 变换 Walsh–Hadamard transform (H) 生成等权实叠加的单比特酉变换。
Pauli 算子 Pauli operators σ1,σ2,σ3\sigma_1,\sigma_2,\sigma_3σ1​,σ2​,σ3​（即 X,Y,ZX,Y,ZX,Y,Z），描述单比特旋转与翻转。
投影测量基 projective measurement basis 一组正交投影算子之和为单位算子的测量集合。
全局测量 global (joint) measurement 同时作用在两个比特上的测量，工程上难以直接实现。

A.6 量子计算与复杂度

中文术语 英文原名 一句话解释
可计算 computable 可由物理（现实的）计算设备实现的过程。
通用计算模型 universal computation model 能实现所有可计算过程的形式模型。
图灵机 Turing machine 最经典的通用计算模型，含潜在无限的读写带。
图灵公设 Turing's thesis 所有可由算法计算的函数均可由图灵机计算。
逻辑电路模型 logic circuit model 输入输出均为有限比特串的计算模型。
充分联结词集合 functionally complete set 能组合出任意逻辑函数的门集合，如 {¬,∧}\{\neg,\wedge\}{¬,∧}。
Toffoli 门 Toffoli gate (CCNOT) 双控制比特的三比特门，与 NOT 一起构成通用经典门集。
量子电路模型 quantum circuit model 由量子门组合实现的通用量子计算模型。
量子门 quantum gate 作用在量子比特上的酉变换，是量子电路的基本元件。
酉变换 unitary transformation 保持内积的线性变换 U†U=IU^{\dagger}U=IU†U=I，保证概率守恒。
量子并行性 quantum parallelism 一次酉变换同时作用在叠加态的全部分支上。
实等权叠加 real equal-weight superposition 全部计算基态系数均为 1/N1/\sqrt N1/N​ 的叠加态。
Grover 算法 Grover's algorithm 用振幅放大把无结构搜索的复杂度从 O(N)O(N)O(N) 降到 O(N)O(\sqrt N)O(N​)。
振幅放大 amplitude amplification Grover 迭代的物理含义：逐步放大目标分支的振幅。
符号反转 sign flip (phase oracle) 把满足 P(x)=1P(x)=1P(x)=1 的分支振幅乘 −1-1−1。
相对平均反转 inversion about the mean 振幅变换 ai↦2μ−aia_i\mapsto 2\mu-a_iai​↦2μ−ai​，即关于平均值做镜像。
扩散算子 diffusion operator 相对平均反转的电路实现，常记 DDD。
相位回踢 phase kickback 辅助比特的本征相位反弹回控制寄存器。
辅助比特 ancilla qubit 为完成计算临时引入、最后不参与测量的额外量子比特。
查询复杂度 query complexity 以调用判定函数（oracle）次数计的复杂度。
uncompute uncompute 用逆运算把临时工作寄存器清回原状，避免破坏相位干涉。
量子傅里叶变换 quantum Fourier transform (QFT) 把周期信息转成频率信息的酉变换，Shor 算法的引擎。
BQP bounded-error quantum polynomial time 有界误差量子多项式时间类，量子可高效判定问题的集合。
NP nondeterministic polynomial time 解可在多项式时间内被验证的问题类。
NP 完全 NP-complete NP 中「最难」的一类问题，若其一有多项式算法则 NP 亦然。
量子优越性 quantum advantage (supremacy) 量子设备完成经典设备难以模拟的任务，属硬件里程碑。
量子纠错 quantum error correction 用多个物理比特编码一个逻辑比特，只测量错误症状。
逻辑量子比特 logical qubit 经纠错编码后可靠运行的量子比特。
物理量子比特 physical qubit 实际器件中的量子比特，一个逻辑比特通常需要成千上万个。
阈值定理 threshold theorem 单门错误率低于阈值即可用级联编码把逻辑错误率压到任意低。
魔术态蒸馏 magic state distillation 用大量有噪声的态「蒸馏」出高保真非 Clifford 资源态的过程。
