第四讲　小结与自测

一句话串起整讲

定义（第1节）
    │  Hash 函数 = 压缩 + 容易算 + 三条"做不到"
    │  MDC（不带密钥）  vs  MAC（带密钥）
    │  三条性质的强弱：抗碰撞 ⇒ 抗第二原像；抗原像独立
    ↓
骨架（第2节）
    │  所有 Hash 函数都是同一套：预处理 → 迭代压缩 → 可选输出变换
    │  H₀=IV，H_i=f(H_{i-1}, x_i)，h(x)=g(H_t)
    │  强度标尺：原像 2ⁿ，碰撞 2^{n/2}  → 参数要求 n≥80 / n≥160
    ↓
MDC（第3节）
    │  ├─ 基于分组密码：MDC-2（双链 + 交叉交换，用 DES 当零件）
    │  └─ 定制：SHA-1（160比特，4轮×20步）  /  MD5（128比特，4轮×16步）
    │     两者的 IV 是同一串字节的正读与倒读
    │     SHA-1 静态移位，MD5 每步都变 → 两种设计风格
    ↓
MAC（第4节）
    │  ├─ 基于分组密码：CBC-MAC（= CBC 加密去掉 IV、只留最后一块）
    │  │   弱点：可拼接 → 用"解密再加密"的可选处理封堵
    │  ├─ 由 MDC 构造：密钥必须放两头（前一后一都不行）
    │  │   h(k‖x) 死于长度扩展；h(x‖k) 死于碰撞
    │  └─ 定制：MD5-MAC（密钥注入 IV + 常量 + 消息末三处）
    ↓
现状：MD5 已可实际碰撞（2004），SHA-1 已被实际碰撞（2017）

核心结论清单（考前必背）

# 结论
1 Hash 函数的最弱定义只有两条：压缩（任意长度 → 固定 nnn 比特）+ 容易计算
2 密码用两类：MDC（不带密钥，完整性检查）与 MAC（带密钥，认证来源 + 完整性）
3 MDC 的三条性质：抗原像（2n2^{n}2n）、抗第二原像（2n2^{n}2n）、抗碰撞（2n/22^{n/2}2n/2）
4 抗碰撞 ⇒ 抗第二原像（唯一成立的蕴含）；抗原像与抗第二原像互不保证
5 OWHF = 定义 1 + 抗原像 + 抗第二原像；CRHF = 定义 1 + 抗第二原像 + 抗碰撞（不要求抗原像）
6 输入由不可信方控制 → 要 CRHF（数字签名）；可信方单方应用 → OWHF 够（口令表）
7 MAC 的安全目标是计算抵抗：给定 0 个或多个 (xi,hk(xi))(x_i, h_k(x_i))(xi​,hk​(xi​))，造不出新消息的合法 MAC
8 攻击 MAC 的三种能力：已知消息 < 选择消息 < 适应性选择消息
9 伪造分两类：选择性伪造（能控内容，致命）与存在性伪造（不能控内容，通常无害）
10 迭代压缩一般模型：H0=IVH_0 = IVH0​=IV，Hi=f(Hi−1,xi)H_i = f(H_{i-1}, x_i)Hi​=f(Hi−1​,xi​)，h(x)=g(Ht)h(x) = g(H_t)h(x)=g(Ht​)，通常 g(Ht)=Htg(H_t) = H_tg(Ht​)=Ht​
11 理想强度（事实 5）：原像/第二原像 ≈2n\approx 2^{n}≈2n，碰撞 ≈2n/2\approx 2^{n/2}≈2n/2；这就是生日悖论
12 参数要求（事实 6，以 2802^{80}280 为门槛）：OWHF 需 n≥80n \geq 80n≥80；CRHF 需 n≥160n \geq 160n≥160；MAC 需 n≥64n \geq 64n≥64（密钥 64–80）
13 CRHF 的输出长度必须是 OWHF 的两倍——因为找碰撞只要 2n/22^{n/2}2n/2
14 MDC-2：两条链各跑一次 DES，密钥由 g(H)g(H)g(H)、g′(H′)g'(H')g′(H′) 从 64 比特链变量导出；四个半块交叉交换是抗碰撞的关键
15 MDC-2 的输出 = 128 比特，抗碰撞强度约 2642^{64}264，与 DES 的密钥强度同量级（无短板）
16 SHA-1：输入 <264< 2^{64}<264 比特，分组 512 比特、输出 160 比特，4 轮 × 20 步 = 80 步，5 个 32 比特寄存器
17 SHA-1 的四个逻辑函数：f1f_1f1​ 选择、f2=f4=X⊕Y⊕Zf_2 = f_4 = X \oplus Y \oplus Zf2​=f4​=X⊕Y⊕Z、f3f_3f3​ 多数
18 SHA-1 的常量 K1∼K4K_1 \sim K_4K1​∼K4​ 来自 2,3,5,10\sqrt{2}, \sqrt{3}, \sqrt{5}, \sqrt{10}2​,3​,5​,10​ 的前 30 位——"没有埋后门"的证明
19 SHA-1 每步：A,B,C,D,E←(E+fi(B,C,D)+CLS5(A)+Wt+Ki), A, CLS30(B), C, DA, B, C, D, E \leftarrow (E + f_i(B,C,D) + CLS_5(A) + W_t + K_i),\ A,\ CLS_{30}(B),\ C,\ DA,B,C,D,E←(E+fi​(B,C,D)+CLS5​(A)+Wt​+Ki​), A, CLS30​(B), C, D
20 SHA-1 的字扩展：Wt=CLS1(Wt−3⊕Wt−8⊕Wt−14⊕Wt−16)W_t = CLS_1(W_{t-3} \oplus W_{t-8} \oplus W_{t-14} \oplus W_{t-16})Wt​=CLS1​(Wt−3​⊕Wt−8​⊕Wt−14​⊕Wt−16​)，16≤t≤7916 \le t \le 7916≤t≤79
21 SHA-0 → SHA-1 的唯一改动就是字扩展里加了 CLS1CLS_1CLS1​——一步移位定生死
22 MD5：分组 512 比特、输出 128 比特，4 轮 × 16 步 = 64 步，4 个 32 比特寄存器
23 MD5 的四个逻辑函数 F,G,H,IF, G, H, IF,G,H,I 各不相同；H=X⊕Y⊕ZH = X\oplus Y\oplus ZH=X⊕Y⊕Z 是唯一线性的那个（放在第 3 轮）
24 MD5 的常量 T[i]=⌊232∥sin⁡(i)∥⌋T[i] = \lfloor 2^{32}\|\sin(i)\| \rfloorT[i]=⌊232∥sin(i)∥⌋（iii 为弧度），共 64 个，每步不同
25 MD5 的消息字置换：p2(i)=(1+5i) mod 16p_2(i)=(1+5i)\bmod 16p2​(i)=(1+5i)mod16，p3(i)=(5+3i) mod 16p_3(i)=(5+3i)\bmod 16p3​(i)=(5+3i)mod16，p4(i)=7i mod 16p_4(i)=7i\bmod 16p4​(i)=7imod16（系数必须与 16 互素）
26 MD5 每步的循环左移量按 4 步一循环：轮 1 是 7,12,17,227,12,17,227,12,17,22；轮 2 是 5,9,14,205,9,14,205,9,14,20；轮 3 是 4,11,16,234,11,16,234,11,16,23；轮 4 是 6,10,15,216,10,15,216,10,15,21
27 MD5 和 SHA-1 的 IV 是同一串字节（01 23 45 67），只是小端/大端读法相反
28 MD5 的填充规则：512 的倍数减 64，最少填 1 比特最多填 512 比特，先 1 后 0，末尾 64 比特放原始长度
29 "即使已满足要求仍要填充"——否则"恰好整除"会与"填充后"产生歧义
30 为什么填充要先补 "1"：避免"消息"与"消息后跟若干 0"撞成同一个结构（可逆填充）
31 CBC-MAC：H1=Ek(M1)H_1 = E_k(M_1)H1​=Ek​(M1​)，Hi=Ek(Hi−1⊕Mi)H_i = E_k(H_{i-1} \oplus M_i)Hi​=Ek​(Hi−1​⊕Mi​)，MAC = HtH_tHt​（IV 固定为 0，只要最后一块）
32 CBC-MAC 的经典弱点：可拼接——知道 (x1,H1)(x_1, H_1)(x1​,H1​)、(x2,H2)(x_2, H_2)(x2​,H2​)、(x1∥z,M)(x_1\|z, M)(x1​∥z,M) 即可伪造 x2∥(H1⊕z⊕H2)x_2\|(H_1\oplus z\oplus H_2)x2​∥(H1​⊕z⊕H2​) 的 MAC 也是 MMM
33 可选处理 Ht′=Dk′(Ht)H'_t = D_{k'}(H_t)Ht′​=Dk′​(Ht​)、Ht=Ek(Ht′)H_t = E_k(H'_t)Ht​=Ek​(Ht′​)：用第二个密钥 + 一次解密封住拼接，代价极低
34 由 MDC 构造 MAC：h(k∥x)h(k\|x)h(k∥x) 死于长度扩展、h(x∥k)h(x\|k)h(x∥k) 死于碰撞，两者都不可用
35 正确构造：hk(x)=h(k∥p∥x∥k)h_k(x) = h(k\|p\|x\|k)hk​(x)=h(k∥p∥x∥k) 或 hk(x)=h(k∥p1∥h(k∥p2∥x))h_k(x) = h(k\|p_1\|h(k\|p_2\|x))hk​(x)=h(k∥p1​∥h(k∥p2​∥x))；ppp 用来把 kkk 填满一个完整分组
36 为什么 ppp 必须存在：保证内部至少两次分组计算，避免"密钥位移攻击"
37 MD5-MAC：密钥 ≤128 比特、输出 64 比特；密钥注入三个位置：IV（K0K_0K0​）、常量 T[j]T[j]T[j]（K1K_1K1​）、消息末尾附加块（K2K_2K2​）
38 MD5-MAC 的附加 512 比特块 = K2∥K2⊕T0∥K2⊕T1∥K2⊕T2K_2 \| K_2\oplus T_0 \| K_2\oplus T_1 \| K_2\oplus T_2K2​∥K2​⊕T0​∥K2​⊕T1​∥K2​⊕T2​
39 现状：MD5 于 2004 年被王小云等实际碰撞（约 2402^{40}240），SHA-1 于 2017 年被 SHAttered 实际碰撞（约 2632^{63}263）——两者都不能用于数字签名

自测题（答案见附录 D）
