A.2 第五讲（RSA 与 Rabin）术语

中文 英文 / 缩写 说明
RSA 算法 RSA 1977 年由 Rivest、Shamir、Adleman 提出
Rabin 算法 Rabin 基于模合数开平方困难
公钥 / 公开密钥 Public Key RSA 里是 (n,e)(n, e)(n,e)；Rabin 里是 nnn
私钥 / 秘密密钥 Private Key RSA 里是 ddd；Rabin 里是 (p,q)(p, q)(p,q)
加密指数 Encryption Exponent eee 公钥的一部分，推荐 65537
解密指数 Decryption Exponent ddd 满足 ed≡1(modφ)ed \equiv 1 \pmod \varphied≡1(modφ)
模 Modulus nnn n=pqn = pqn=pq
欧拉函数 Euler's Totient φ(n)\varphi(n)φ(n) φ(pq)=(p−1)(q−1)\varphi(pq) = (p-1)(q-1)φ(pq)=(p−1)(q−1)
通用指数 Universal Exponent λ\lambdaλ λ=lcm⁡(p−1,q−1)\lambda = \operatorname{lcm}(p-1, q-1)λ=lcm(p−1,q−1)
费马小定理 Fermat's Little Theorem ppp 素数、gcd⁡(a,p)=1\gcd(a,p)=1gcd(a,p)=1 ⟹ ap−1≡1(modp)a^{p-1} \equiv 1 \pmod pap−1≡1(modp)
欧拉定理 Euler's Theorem gcd⁡(a,n)=1\gcd(a,n)=1gcd(a,n)=1 ⟹ aφ(n)≡1(modn)a^{\varphi(n)} \equiv 1 \pmod naφ(n)≡1(modn)
中国剩余定理 CRT (Chinese Remainder Theorem) 多个同余式的联立求解
扩展 Euclidean 算法 Extended Euclidean Algorithm / EEA 求 sa+tb=gcd⁡sa+tb=\gcdsa+tb=gcd，顺便求模逆
素性测试 Primality Test Fermat / Miller–Rabin / Solovay–Strassen / AKS
伪素数 Pseudoprime 骗过某个基的合数
卡迈克尔数 Carmichael Number 骗过所有基的合数（如 561、1105、1729）
见证 Witness 形如"这个 aaa 使 an−1≠1a^{n-1}\ne1an−1=1"的证据
模幂 Modular Exponentiation gb mod ng^b \bmod ngbmodn
从左向右二进制算法 Left-to-Right Binary Algorithm 即"平方-乘法"算法
平方-乘法 Square-and-Multiply 上述算法的别名
盲化 Blinding 解密前乘随机数，让耗时与真实数据无关
大整数分解 IFP (Integer Factorization Problem) RSA 的安全性所依赖
光滑 / 平滑 Smooth / BBB-smooth 所有素因子 ≤B\le B≤B
平滑界 Smoothness Bound BBB Pollard p−1p-1p−1 算法的参数
指数分解方法 Index Calculus / Exponential Factoring 用通用指数造 x2≡y2x^2\equiv y^2x2≡y2
Pollard 的 p−1p-1p−1 算法 Pollard's p−1p-1p−1 Algorithm 利用 p−1p-1p−1 的平滑性
二次筛法 Quadratic Sieve / QS 大规模筛光滑关系 + 解线性方程组
数域筛法 NFS (Number Field Sieve) 目前最快的通用分解算法
Fermat 分解法 Fermat's Factorization 用于 ppp 与 qqq 非常接近的情形
丢番图关系 / 平方关系 Congruence of Squares x2≡y2(modn)x^2 \equiv y^2 \pmod nx2≡y2(modn)
因子基 Factor Base 二次筛法里用的小素数集合
亚指数 Sub-exponential 比多项式慢、比指数快的复杂度
平方根问题 SQROOT 给定 ccc 求 mmm 使 m2≡c(modn)m^2 \equiv c \pmod nm2≡c(modn)
Rabin 冗余 Rabin Redundancy 复制消息尾部，用于唯一确定明文
前项搜索攻击 Forward Search Attack 枚举消息空间建字典
共模攻击 Common Modulus Attack 同一个 nnn 配不同 eee
小指数攻击 Small Exponent Attack 针对小 eee 或小 ddd 的攻击
乘法特性 / 同态特性 Multiplicative / Homomorphic Property (m1m2)e≡m1em2e(m_1m_2)^e \equiv m_1^e m_2^e(m1​m2​)e≡m1e​m2e​
广播攻击 Broadcast Attack 同一消息发给多人，用 CRT 合并
选择密文攻击 Chosen-Ciphertext Attack / CCA 攻击者能问解密结果
适应性选择密文攻击 Adaptive CCA / CCA2 能根据回答调整询问
解密预言机 Decryption Oracle 能回答解密询问的"黑盒"
循环攻击 Cycling Attack 反复加密直到绕回起点
部分密钥泄露攻击 Partial Key Exposure Attack 知道 l/4l/4l/4 位即可恢复

定时攻击 Timing Attack 靠测量运算耗时
边信道攻击 Side-channel Attack 利用时间、功耗、电磁等无意泄露
电耗分析攻击 Power Analysis Attack 利用功耗曲线
出错攻击 Fault Attack 故意制造计算错误再观察
电磁辐射攻击 Electromagnetic Attack 接收设备辐射的电磁波
RSA-OAEP Optimal Asymmetric Encryption Padding 最优非对称加密填充，可证明安全
BKSP 填充 PKCS#1 v1.5 OAEP 之前的标准填充（有 Bleichenbacher 攻击）
