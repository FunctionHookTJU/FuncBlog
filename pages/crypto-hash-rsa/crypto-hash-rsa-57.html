3.8 循环攻击（PPT 第 40–42 页）

基本循环攻击（PPT 第 40 页）

PPT 原文：

令 c≡me(modn)c \equiv m^{e} \pmod nc≡me(modn) 为一条密文消息。令 kkk 为一个正整数满足 cek≡c(modn)c^{e^{k}} \equiv c \pmod ncek≡c(modn)。由于加密是在消息空间 {0,1,…,n−1}\{0, 1, \ldots, n-1\}{0,1,…,n−1} 上的一个计算，这样的整数 kkk 一定存在。由此，我们得到

cek−1≡(cek)e−1≡m(modn)。c^{e^{k-1}} \equiv \left(c^{e^{k}}\right)^{e^{-1}} \equiv m \pmod n。cek−1≡(cek)e−1≡m(modn)。
这一事实就导致了如下的循环攻击。攻击者计算 ce(modn)c^{e} \pmod nce(modn)，ce2(modn)c^{e^{2}} \pmod nce2(modn)，ce3(modn)c^{e^{3}} \pmod nce3(modn)，直到结果等于 ccc。如果 cek≡c(modn)c^{e^{k}} \equiv c \pmod ncek≡c(modn)，则它的前一次计算结果 cek−1(modn)c^{e^{k-1}} \pmod ncek−1(modn) 就应该等于明文消息 mmm。

补这个攻击的思想简单得有点好笑，但确实成立。先建立直觉：

RSA 加密是一个"在有限集合上的映射"：

m⟼me mod nm \longmapsto m^{e} \bmod nm⟼memodn

定义域和值域都是 {0,1,…,n−1}\{0, 1, \ldots, n-1\}{0,1,…,n−1} 这 nnn 个元素的有限集合。

补有限集合上的映射有一个必然性质：

如果反复施加同一个映射，一定会"绕回原点"（进入一个循环）。

画个图看：

把"加密"这个动作记作 E：

    c ──E──→ c^e ──E──→ c^{e²} ──E──→ c^{e³} ──E──→ …
    
  这个序列在 {0,…,n−1} 这个"只有 n 个格子"的集合里跑
  所以它一定在某个时刻"重复"→ 之后就永远循环下去

PPT 定义的那个 kkk 就是"绕回起点"所需的步数：

cek≡c(modn)c^{e^{k}} \equiv c \pmod ncek≡c(modn)

（这里 cekc^{e^k}cek 的意思是"对 ccc 连续施加 kkk 次加密"，也就是 ((ce)e)⋯((c^e)^e)^{\cdots}((ce)e)⋯ 一共 kkk 重。）

补为什么"前一次结果就是明文"？用一个"可逆映射"的论证最干净。

把加密记作一个映射 EEE：

E(x)=xe mod nE(x) = x^{e} \bmod nE(x)=xemodn

于是 cekc^{e^{k}}cek 表示"对 ccc 连续施加 kkk 次 EEE"，记作 Ek(c)E^{k}(c)Ek(c)。

起始点是 c=me=E(m)c = m^{e} = E(m)c=me=E(m)，也就是**"ccc 是 mmm 加密 1 次的结果"**。

现在把 PPT 的条件 cek≡cc^{e^{k}} \equiv ccek≡c 用 EEE 重写：

Ek(c)=cE^{k}(c) = cEk(c)=c

而 c=E(m)c = E(m)c=E(m)，代进去：

Ek(E(m))=E(m)⟹Ek+1(m)=E(m)E^{k}\big(E(m)\big) = E(m) \quad \Longrightarrow \quad E^{k+1}(m) = E(m)Ek(E(m))=E(m)⟹Ek+1(m)=E(m)

两边同时"消掉"最外面一层 EEE（这里用到 EEE 在合法消息空间上是双射——RSA 加密是可逆的，所以可以"两边同时解密"）：

Ek(m)=mE^{k}(m) = mEk(m)=m

也就是说：从 mmm 出发加密 kkk 次，会回到 mmm 自己。 ✓（这很自然：mmm 和 ccc 在同一个循环里，只是相差 1 步。）

那么"从 ccc 出发加密 k−1k-1k−1 次"得到什么？

Ek−1(c)=Ek−1(E(m))=Ek(m)=mE^{k-1}(c) = E^{k-1}\big(E(m)\big) = E^{k}(m) = mEk−1(c)=Ek−1(E(m))=Ek(m)=m

——正好是 mmm！

cek−1=Ek−1(c)=Ek(m)=m\boxed{c^{e^{k-1}} = E^{k-1}(c) = E^{k}(m) = m}cek−1=Ek−1(c)=Ek(m)=m​

大白话总结：

从 c 出发：加密 k 次回到 c        （这是 k 的定义）
          ↓
   所以从 c 出发加密 k−1 次，就到了"回到 c 的前一步"
          ↓
   而"回到 c 的前一步"就是 m
       （因为 m 加密 1 次就已经是 c 了，两者在循环里相差 1 步）

换句话说：RSA 加密在合法消息空间里形成一个"环"。攻击者沿着环往前跑，跑到"刚好回到起点 ccc"的那一刻，它的上一步就是明文 mmm。

补所以基本循环攻击的做法是：

① 从 c 出发，反复加密：
      c^e, c^{e²}, c^{e³}, …, 每次都不停地加密
        ↓
② 每一步都检查"是不是等于 c 了"
        ↓
③ 一旦发现 c^{e^k} ≡ c (mod n)  ← 绕回来了！
        ↓
④ 那么上一步的 c^{e^{k−1}} 就是明文 m

补这个攻击的致命局限：需要绕一圈，而这一圈可能长得离谱。

kkk 有多大？ 理论上是"从 ccc 出发的那个循环的长度"，平均量级大约是 n\sqrt{n}n​ 到 nnn 之间——对 1024 比特的 nnn，这是天文数字。

所以基本循环攻击"理论成立，实际不可行"——和事实 2 那个"通用指数分解方法"一样，是"理论上重要的观察"，不是实用的攻击。

一般形式的循环攻击（PPT 第 41–42 页）

PPT 第 41 页原文：

一般形式的循环攻击是发现一个最小的正整数 uuu 满足

fu=(ceu−c, n)>1。f_u = \left(c^{e^{u}} - c,\ n\right) > 1。fu​=(ceu−c, n)>1。
如果
ceu≡c(modp)和ceu≢c(modq)，c^{e^{u}} \equiv c \pmod p \quad \text{和} \quad c^{e^{u}} \not\equiv c \pmod q，ceu≡c(modp)和ceu≡c(modq)，
则 fu=pf_u = pfu​=p。同样地，如果
ceu≢c(modp)和ceu≡c(modq)，c^{e^{u}} \not\equiv c \pmod p \quad \text{和} \quad c^{e^{u}} \equiv c \pmod q，ceu≡c(modp)和ceu≡c(modq)，
则 fu=qf_u = qfu​=q。在任何一种情况下，都将导致 nnn 的分解，攻击者可以得到 ddd 并进一步得到明文消息 mmm。另一方面，如果
ceu≡c(modp)和ceu≡c(modq)，c^{e^{u}} \equiv c \pmod p \quad \text{和} \quad c^{e^{u}} \equiv c \pmod q，ceu≡c(modp)和ceu≡c(modq)，
则 fu=nf_u = nfu​=n 并且 ceu≡c(modn)c^{e^{u}} \equiv c \pmod nceu≡c(modn)。

补这一段和 3.2.2 节 Pollard p−1p-1p−1 的思路是"同一个套路"——

不要等到"完全绕回来"，而是在路上随时算 gcd⁡\gcdgcd，一旦 gcd⁡>1\gcd > 1gcd>1 就抓到一个因子。

看这三种情形：

情形 ①：c^{e^u} ≡ c (mod p)  但  c^{e^u} ≢ c (mod q)
        → p 整除 (c^{e^u} − c)，而 q 不整除
        → f_u = gcd(c^{e^u} − c, n) = p      ← 拿到因子 p！

情形 ②：c^{e^u} ≢ c (mod p)  但  c^{e^u} ≡ c (mod q)
        → 对称地，f_u = q                    ← 拿到因子 q！

情形 ③：两个都成立
        → p 和 q 都整除 (c^{e^u} − c)
        → f_u = n（"打得太开"，没分开）

补情形①为什么会发生？ 因为"绕回起点"这件事在模 ppp 和模 qqq 下的周期不同：

模 p 下的周期≠模 q 下的周期\text{模 } p \text{ 下的周期} \ne \text{模 } q \text{ 下的周期}模 p 下的周期=模 q 下的周期

所以"在模 ppp 下已经回到 ccc、但在模 qqq 下还没回来"这个时刻一定存在（反之亦然）。

这和 3.2.2 节"一个因子被打开、另一个没被打开"的结构完全一样——gcd⁡\gcdgcd 就是靠这种"不对称"来分离因子的。

补而且这个方法比基本循环攻击有优势：它不需要走完整个周期——只要走到"两个模的周期第一次不一致"的位置就够了，而这个位置通常远小于完整周期。

PPT 第 42 页的评述把事情说完了：

评述. 事实上，按算法的执行过程，uuu 必定是满足 ceu≡c(modn)c^{e^{u}} \equiv c \pmod nceu≡c(modn) 的最小正整数。在这种情况下，基本循环攻击成功并且可以有效计算 ceu−1≡m(modn)c^{e^{u-1}} \equiv m \pmod nceu−1≡m(modn)。由于第三个条件发生的概率要小于第一个和第二个条件，因此，一般形式的循环攻击要先于循环攻击结束。显然，一般形式的循环攻击可以看作是一种分解整数的方法。由于分解整数 nnn 通常情况下是困难的，所以这些循环攻击并不能给 RSA 加密的安全带来威胁。

补逐句解释：

"uuu 必定是满足 ceu≡c(modn)c^{e^u} \equiv c \pmod nceu≡c(modn) 的最小正整数"——也就是说，如果走到了情形③（fu=nf_u = nfu​=n），那 uuu 就是完整的循环长度。

"由于第三个条件发生的概率要小于第一个和第二个条件"——为什么？

因为情形③要求"同时在模 ppp 和模 qqq 下都绕回来"。如果两个模下的周期分别是 TpT_pTp​ 和 TqT_qTq​，那么情形③发生在 lcm⁡(Tp,Tq)\operatorname{lcm}(T_p, T_q)lcm(Tp​,Tq​) 处，而情形①②发生在二者"第一次不一致"处——后者早得多。

"一般形式的循环攻击要先于循环攻击结束"——所以实际跑的时候，还没等到完整循环，一般形式就已经抓到因子了。

"一般形式的循环攻击可以看作是一种分解整数的方法。由于分解整数 nnn 通常情况下是困难的..."——最后的结论：这个攻击的难度不超过"分解 nnn"的难度。

补这个结论很关键，它说明循环攻击"不构成额外的威胁"：

攻击 难度
一般形式的循环攻击 ≤ 分解 nnn 的难度
而 RSA 的安全性假设 分解 nnn 是困难的
所以 循环攻击不构成比"分解 nnn"更强的威胁

补这是一类重要的论证方式，值得单独记住：

要说明"某个攻击不构成威胁"，最经济的方式是证明"这个攻击的难度不低于已知的困难问题"。

PPT 在 3.12 节（定时攻击）的结尾也会用同样的论证。这类推理的价值是：它把"评估一个新攻击"变成了"比较两个已知问题的难度"——不用重新证明 RSA 安全，只要证明"新攻击不比分解更容易"就够了。
