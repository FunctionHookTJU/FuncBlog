第五讲　小结与自测

一句话串起整讲

两个方案，一条主线（第1、5节）
    │  RSA    = 大整数分解困难（"被认为"）
    │  Rabin  = 模合数平方根困难（"可证明"等价于分解）
    │  共同点：都是"陷门单向函数"的应用
    ↓
RSA 的三个算法（第1节）
    │  密钥产生：找 p,q → n=pq, φ=(p−1)(q−1) → 选 e → 求 d = e⁻¹ mod φ
    │  加密：c = m^e mod n          解密：m = c^d mod n
    │  正确性证明：ed = 1+k(p−1)(q−1) → 费马小定理 → 模 p、模 q、合成模 pq
    ↓
怎么真的算出来（第2节）
    │  素性测试（Fermat；工程用 Miller–Rabin）
    │  模幂：从左向右二进制算法（k 次平方 + 1 的个数次模乘）
    │  ★ 这里埋下了定时攻击的伏笔：那个"如果 b_i = 1"的条件分支
    ↓
RSA 的攻击全景（第3节 —— 本讲重点）
    │  3.1  知道 φ 就能分解 n；知道 d 就能分解 n（一破全破）
    │  3.2  分解方法：试除 → Fermat → 指数分解 → Pollard p−1 → 二次筛法 → NFS
    │         ★ 灵魂是"基本原理 1"：x²≡y² 且 x≢±y ⟹ gcd(x−y,n) 给因子
    │  3.3  小 e：群发（CRT）+ 小消息 ⟸ 要害是"取模失效"
    │  3.4  小 d：Wiener（d < n^0.25/3）、Boneh–Durfee（d < n^0.292）⟹ d 不能小
    │  3.5  乘法特性：同态 → 适应性选择密文攻击 ⟹ 靠"格式校验"防
    │  3.6  共模攻击：同一个 n 配不同 e ⟹ 扩展 Euclidean 线性组合直接还原 m
    │  3.7  部分密钥泄露：知道 p 或 d 的 l/4 位就够了（Coppersmith）
    │  3.8  循环攻击：难度 ≤ 分解 n ⟹ 不构成额外威胁
    │  3.9  消息隐藏：不动点至少 9 个，占比 2⁻¹⁰²⁰ ⟹ 无害
    │  3.10 前项搜索：确定性加密 + 小消息空间 ⟹ 加盐
    │  3.11 RSA-OAEP：G/H 双掩码 + k₁ 个 0 校验 ⟹ 一次挡住一整类攻击
    │  3.12 定时攻击：条件模乘泄露 d 的比特 → 方差统计 → 常数时间/盲化
    ↓
参数规范（第4节）
    │  n ≥ 1024（长期 2048+）；p、q 各半长度、独立随机、|p−q| 不太小
    │  强素数（可选）；e = 65537（推荐）；d > n^0.292（天然满足）
    │  ★ 必做：加 OAEP
    ↓
Rabin（第5、6、7节）
    │  公钥只有 n，私钥是 (p,q)；加密 c = m² mod n
    │  解密：4 个平方根 → 靠"冗余规则"筛出唯一明文
    │  计算平方根：p ≡ q ≡ 3 (mod 4) 时 r = c^{(p+1)/4}，再 CRT 组合出 ±x, ±y
    │  安全：被动攻击 ⟺ 分解 n（可证明）；主动攻击有选择密文问题 → 冗余规则解决
    ↓
总结（第8节）
    公钥加密的四条要求 + 密钥真实性（需要可信第三方）
    认证与不可否认靠"用私钥做解密运算"（即数字签名）
    内核：陷门单向函数（RSA 与 Rabin 都是"候选函数"）

# 结论
1 RSA（1977，Rivest–Shamir–Adleman）依赖大整数分解困难；Rabin 依赖模合数平方根困难
2 RSA 的安全性只在一个方向成立（分解 ⇒ 攻破）；Rabin 双向等价，所以可证明
3 RSA 密钥产生：n=pqn = pqn=pq，φ=(p−1)(q−1)\varphi = (p-1)(q-1)φ=(p−1)(q−1)，选 eee 使 gcd⁡(e,φ)=1\gcd(e,\varphi)=1gcd(e,φ)=1，用扩展 Euclidean 算法求 d=e−1 mod φd = e^{-1} \bmod \varphid=e−1modφ
4 公钥 (n,e)(n, e)(n,e)，私钥 ddd；加密 c=me mod nc = m^e \bmod nc=memodn，解密 m=cd mod nm = c^d \bmod nm=cdmodn
5 正确性证明三步：ed=1+k(p−1)(q−1)ed = 1 + k(p-1)(q-1)ed=1+k(p−1)(q−1) → 模 ppp 用费马小定理（分 gcd⁡(m,p)=1\gcd(m,p)=1gcd(m,p)=1 和 =p=p=p 两种情形）→ 模 qqq 同理 → 合成模 pqpqpq
6 λ=lcm⁡(p−1,q−1)\lambda = \operatorname{lcm}(p-1, q-1)λ=lcm(p−1,q−1) 是最小通用指数，可替代 φ\varphiφ 以得到更小的 ddd；但 λ\lambdaλ 与 φ\varphiφ 同量级
7 一破全破：分解 nnn ⟺ 求 φ\varphiφ（事实 1）；知道 (e,d)(e,d)(e,d) ⇒ 能分解 nnn（事实 2，因为 ed−1ed-1ed−1 是通用指数）
8 事实 1 的核心代数式：p+q=n−φ+1p + q = n - \varphi + 1p+q=n−φ+1，再用韦达定理和求根公式解出 p,qp, qp,q
9 素性测试容易、分解困难——这是 RSA 可行的技术前提（NP 问题的"短证书"特征）
10 Fermat 素性测试：an−1≢1(modn)⇒na^{n-1} \not\equiv 1 \pmod n \Rightarrow nan−1≡1(modn)⇒n 是合数；伪素数能骗过它，Carmichael 数能骗过所有基（工程上用 Miller–Rabin）
11 模幂：从左向右二进制算法——每位一次平方，位为 1 时再一次模乘；总代价 kkk 次平方 + ∥e∥\|e\|∥e∥ 中 1 的个数次模乘
12 基本原理 1（整讲的灵魂）：x2≡y2(modn)x^2 \equiv y^2 \pmod nx2≡y2(modn) 且 x≢±y(modn)x \not\equiv \pm y \pmod nx≡±y(modn) ⟹ gcd⁡(x−y,n)\gcd(x-y, n)gcd(x−y,n) 给出非平凡因子
13 z2≡1(modpq)z^2 \equiv 1 \pmod{pq}z2≡1(modpq) 恰好有 4 个根，其中 2 个平凡、2 个非平凡——分解攻击（3.2.1）、Rabin 解密（5.1）、Rabin 安全证明（第 7 节）都靠它
14 Pollard 的 p−1p-1p−1 算法：Q=∏q≤Bq⌊ln⁡n/ln⁡q⌋Q = \prod_{q \le B} q^{\lfloor \ln n/\ln q\rfloor}Q=∏q≤B​q⌊lnn/lnq⌋；若 p−1p-1p−1 是 BBB-平滑的则 p∣(aQ−1)p \mid (a^Q - 1)p∣(aQ−1)；d=nd=nd=n 时改用指数分解方法
15 二次筛法/数域筛法：筛出"x2 mod nx^2 \bmod nx2modn 是 BBB-平滑的"关系 → 在 F2\mathbb{F}_2F2​ 上解线性方程组求"全偶"行子集 → 凑 x2≡y2x^2 \equiv y^2x2≡y2 → gcd⁡\gcdgcd
16 NFS 的复杂度是亚指数：L[n]=e1.9229(1+o(1))ln⁡1/3(n)(ln⁡ln⁡n)2/3L[n] = e^{1.9229(1+o(1))\ln^{1/3}(n)(\ln\ln n)^{2/3}}L[n]=e1.9229(1+o(1))ln1/3(n)(lnlnn)2/3；这就是"nnn 至少 1024 比特"的依据
17 小 eee 攻击要害是"取模失效"：群发（eee 个同余式 + CRT）与加密小消息（me<nm^e < nme<n）；加填充即可防
18 小 ddd 不能用：Wiener d<n0.25/3d < n^{0.25}/3d<n0.25/3、Boneh–Durfee d<n0.292d < n^{0.292}d<n0.292；eee 可以小、ddd 不可以，因为 eee 公开、ddd 保密
19 RSA 是乘法同态的：(m1m2)e≡m1em2e(modn)(m_1m_2)^e \equiv m_1^e m_2^e \pmod n(m1​m2​)e≡m1e​m2e​(modn)；配合"解密预言机"就是完整的明文恢复攻击；防法是规定明文格式并拒绝不合法密文
20 共模攻击：同一个 nnn、gcd⁡(e1,e2)=1\gcd(e_1,e_2)=1gcd(e1​,e2​)=1、同一条消息 → c1ac2b≡mc_1^{a}c_2^{b} \equiv mc1a​c2b​≡m（其中 ae1+be2=1ae_1+be_2=1ae1​+be2​=1）
21 部分密钥泄露：知道 ppp 或 ddd 的 l/4l/4l/4 位就足以恢复（Coppersmith）；教训是"随机 ≠ 不可预测"
22 循环攻击的难度不超过分解 nnn，所以不带来额外威胁（"证明不构成威胁"的范式）
23 不可隐藏明文的数量为 [1+gcd⁡(e−1,p−1)][1+gcd⁡(e−1,q−1)]≥9[1+\gcd(e-1,p-1)][1+\gcd(e-1,q-1)] \ge 9[1+gcd(e−1,p−1)][1+gcd(e−1,q−1)]≥9；占比约 2−10202^{-1020}2−1020，无害
24 RSA-OAEP：GGG、HHH 为 Hash 函数，双重掩码，明文含 k1k_1k1​ 个 0 用于校验；k=1024k=1024k=1024 时有用消息占 75%
25 定时攻击：算法 4 里"A←A⋅gA \leftarrow A\cdot gA←A⋅g 仅当 bi=1b_i=1bi​=1"泄露 ddd；用方差比较判断该步是否执行；防法是常数时间实现 + 盲化
26 RSA 参数规范：n≥1024n \ge 1024n≥1024（长期 2048+）；p,qp,qp,q 独立随机且长度相等；∥p−q∥\|p-q\|∥p−q∥ 不能太小；推荐 e=65537e = 65537e=65537；d>n0.292d > n^{0.292}d>n0.292
27 强素数三条件：p−1p-1p−1 有大素因子（防 Pollard p−1p-1p−1）、p+1p+1p+1 有大素因子（防 p+1p+1p+1 算法）、r−1r-1r−1 有大素因子（防循环攻击）
28 Rabin 密钥产生：只需 n=pqn=pqn=pq；公钥 nnn，私钥 (p,q)(p,q)(p,q)；加密 c=m2 mod nc = m^2 \bmod nc=m2modn
29 Rabin 解密有 4 个候选根（CRT 下 (±r,±s)(\pm r, \pm s)(±r,±s) 的 4 种组合），必须用冗余规则（复制最后 64 比特）筛出唯一解
30 p≡q≡3(mod4)p \equiv q \equiv 3 \pmod 4p≡q≡3(mod4) 时开平方有简式：r=c(p+1)/4 mod pr = c^{(p+1)/4} \bmod pr=c(p+1)/4modp，s=c(q+1)/4 mod qs = c^{(q+1)/4} \bmod qs=c(q+1)/4modq，再用 a⋅p+b⋅q=1a\cdot p + b\cdot q = 1a⋅p+b⋅q=1 组合出 x=aps+bqrx = aps+bqrx=aps+bqr、y=aps−bqry = aps-bqry=aps−bqr，四根为 ±x,±y\pm x, \pm y±x,±y
31 Rabin 的效率：加密只需 1 次模平方（比 RSA 的 e=3e=3e=3 还少一次模乘）；解密与 RSA 同数量级
32 Rabin 的安全（被动攻击者）：SQROOT ⟺ 分解 nnn；归约证明——用 SQROOT 算法 RRR 对 x2x^2x2 求根，若返回 ≠±x\ne \pm x=±x 则 gcd⁡(x−y,n)\gcd(x-y,n)gcd(x−y,n) 分解成功，每次成功概率 1/2
33 Rabin 的主动攻击：攻击者用自己的 mmm 造 c=m2c=m^2c=m2，让解密机返回某个根 yyy；若 y≠±my \ne \pm my=±m 则拿到因子。冗余规则可挡住（含冗余 → 返回 mmm 本身；不含冗余 → 拒绝回答）
34 公钥加密的四条要求：① Dk(Ek(m))=mD_k(E_k(m))=mDk​(Ek​(m))=m ② Ek,DkE_k, D_kEk​,Dk​ 容易算 ③ 给定 kkk 易确定两函数 ④ 只知道 EkE_kEk​ 算不出 DkD_kDk​（对几乎所有 kkk）
35 认证与不可否认：对称密码里"认证容易、不可否认不成立"（双方能力对等）；公钥密码里两者都不自然成立，但可用 Ekb(Ska(m))=Ekb(Dka(m))E_{k_b}(S_{k_a}(m)) = E_{k_b}(D_{k_a}(m))Ekb​​(Ska​​(m))=Ekb​​(Dka​​(m)) 实现
36 陷门单向函数：单向函数 + 陷门信息；RSA 的陷门是 p,qp,qp,q、φ\varphiφ 或 ddd；单向函数的存在性至今未知（所以只能叫"候选函数"）
