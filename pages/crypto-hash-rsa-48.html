3.2.2 Pollard 的 p−1p-1p−1 算法（PPT 第 24–27 页）

基本思想（PPT 第 24 页）

PPT 原文：

Pollard 的 p−1p-1p−1 算法的基本思想如下。令 BBB 是一个平滑界。令 QQQ 是所有素数 ≤B\le B≤B 的幂 ≤n\le n≤n 的最小公倍数。如果 ql≤nq^l \le nql≤n，则 lln⁡q≤ln⁡nl \ln q \le \ln nllnq≤lnn，因此有 l≤⌊ln⁡n/ln⁡q⌋l \le \lfloor \ln n / \ln q \rfloorl≤⌊lnn/lnq⌋。这样

Q=∏q≤Bq⌊ln⁡n/ln⁡q⌋，Q = \prod_{q \le B} q^{\lfloor \ln n / \ln q \rfloor}，Q=q≤B∏​q⌊lnn/lnq⌋，
这里乘积实际包含了所有素数 q≤Bq \le Bq≤B。如果 ppp 是 nnn 的一个素数因子，满足 p−1p-1p−1 是 BBB-平滑的，则 p−1∣Qp-1 \mid Qp−1∣Q，并且对于任何 aaa 满足 (a,p)=1(a, p) = 1(a,p)=1，因为 Fermat 小定理而有 aQ≡1(modp)a^{Q} \equiv 1 \pmod paQ≡1(modp)。因此，如果 d=(aQ−1,n)d = (a^{Q} - 1, n)d=(aQ−1,n)，则 p∣dp \mid dp∣d。当然，也可能 d=nd = nd=n，这时候方法失败，但是如果 nnn 有至少两个不同大素数因子时，这种情况不太可能发生。

补先解释"平滑"这个核心概念：

BBB-平滑（BBB-smooth）：一个整数如果它的所有素因子都 ≤B\le B≤B，就称它是 BBB-平滑的。

例子：取 B=19B = 19B=19。

  • 5280=25×3×5×115280 = 2^5 \times 3 \times 5 \times 115280=25×3×5×11——每个素因子都 ≤19\le 19≤19，所以 528052805280 是 191919-平滑的 ✓
  • 3606=2×3×6013606 = 2 \times 3 \times 6013606=2×3×601——601>19601 > 19601>19，所以 360636063606 不是 191919-平滑的 ✗

补这个方法"利用了什么"？ 答案：p−1p-1p−1 的平滑性。

逐步理解这个算法的逻辑链：

①  假设 p 是 n 的一个素因子
        │
②  假设 p−1 是 B-平滑的
        │   （也就是 p−1 的所有素因子都 ≤ B）
        ↓
③  那么 p−1 整除 Q  =  ∏_{q≤B} q^⌊ln n / ln q⌋
        │   （因为 Q 把所有 ≤B 的素数都"用到了足够高的幂次"）
        ↓
④  对任意与 p 互素的 a，由费马小定理 a^{p−1} ≡ 1 (mod p)
        │
        ↓  而 p−1 | Q，所以
⑤  a^Q ≡ 1 (mod p)
        │
        ↓
⑥  也就是 p | (a^Q − 1)
        │
        ↓
⑦  所以 gcd(a^Q − 1, n) 必含因子 p     ← 分解成功！

补最关键的是③那一步：为什么 p−1∣Qp-1 \mid Qp−1∣Q？

因为 QQQ 的定义是**"所有 ≤B\le B≤B 的素数的足够高幂次的乘积"**：

Q=∏q≤Bq⌊ln⁡n/ln⁡q⌋Q = \prod_{q \le B} q^{\lfloor \ln n / \ln q \rfloor}Q=q≤B∏​q⌊lnn/lnq⌋

而 p−1p-1p−1 是 BBB-平滑的，也就是说

p−1=∏q≤Bqeq(某些 eq≥0)p - 1 = \prod_{q \le B} q^{e_q} \quad (\text{某些 } e_q \ge 0)p−1=q≤B∏​qeq​(某些 eq​≥0)

要证明 p−1∣Qp - 1 \mid Qp−1∣Q，只需要证明每个 eq≤⌊ln⁡n/ln⁡q⌋e_q \le \lfloor \ln n / \ln q \rflooreq​≤⌊lnn/lnq⌋。

为什么成立？ 因为 qeqq^{e_q}qeq​ 是 p−1p-1p−1 的因子，所以 qeq≤p−1<p≤nq^{e_q} \le p - 1 < p \le nqeq​≤p−1<p≤n，取对数得

eqln⁡q≤ln⁡n⟹eq≤ln⁡nln⁡qe_q \ln q \le \ln n \quad \Longrightarrow \quad e_q \le \frac{\ln n}{\ln q}eq​lnq≤lnn⟹eq​≤lnqlnn​

而 eqe_qeq​ 是整数，所以 eq≤⌊ln⁡nln⁡q⌋e_q \le \left\lfloor \frac{\ln n}{\ln q} \right\rflooreq​≤⌊lnqlnn​⌋。 ✓

补大白话：QQQ 里的每个 qqq 都取到了"≤n\le n≤n 范围内能让 qqq 出现的最高幂次"。而 p−1p-1p−1 里 qqq 的幂次不可能超过这个上限——所以 QQQ 一定"覆盖得住"p−1p-1p−1。

补这个方法"gcd⁡\gcdgcd 一算就出因子"的美妙之处，用一个类比说明：

想象 ppp 和 qqq 是两把锁，而 aQ−1a^Q - 1aQ−1 是一把钥匙：

  • 对因子 ppp：因为 p−1∣Qp-1 \mid Qp−1∣Q，所以 aQ≡1(modp)a^Q \equiv 1 \pmod paQ≡1(modp)，即 p∣(aQ−1)p \mid (a^Q - 1)p∣(aQ−1) → 钥匙打得开 ppp 这把锁；
  • 对另一个因子 qqq：如果 q−1q-1q−1 不是 BBB-平滑的，那么 aQ≢1(modq)a^Q \not\equiv 1 \pmod qaQ≡1(modq)，即 q∤(aQ−1)q \nmid (a^Q-1)q∤(aQ−1) → 钥匙打不开 qqq 这把锁。

于是 gcd⁡(aQ−1,n)=p\gcd(a^Q-1, n) = pgcd(aQ−1,n)=p——一个因子被打开、一个没被打开，gcd⁡\gcdgcd 就把它们分开了。

补这就解释了 PPT 那句"如果 d=nd = nd=n，这时候方法失败"：

如果 p−1p-1p−1 和 q−1q-1q−1 都是 BBB-平滑的，那么两把锁都被打开了：

aQ≡1(modp)且aQ≡1(modq)⟹aQ≡1(modn)a^Q \equiv 1 \pmod p \quad \text{且} \quad a^Q \equiv 1 \pmod q \quad \Longrightarrow \quad a^Q \equiv 1 \pmod naQ≡1(modp)且aQ≡1(modq)⟹aQ≡1(modn)

于是 gcd⁡(aQ−1,n)=n\gcd(a^Q - 1, n) = ngcd(aQ−1,n)=n，没能把它们分开——因为两个因子"一起出来了"。

PPT 补充说："但是如果 nnn 有至少两个不同大素数因子时，这种情况不太可能发生。"——因为两个随机大素数的 p−1p-1p−1 同时都平滑的概率很小。

补"平滑界 BBB 怎么选"是一个典型的工程权衡（PPT 第 26 页的评述会讲）：

BBB 的选择 计算量 成功概率
BBB 小 便宜（要算的素数少、QQQ 小） 低（很多 p−1p-1p−1 不是 BBB-平滑的）
BBB 大 昂贵（要算的素数多） 高

所以 BBB 要根据"目标 nnn 有多大"和"愿意花多少时间"来定——没有普适的最优值。

算法 5　Pollard 的 p−1p-1p−1 算法（PPT 第 25 页）

PPT 原文：

算法 5　Pollard 的 p−1p-1p−1 算法分解整数 输入：一个非单一素数乘幂的合数 nnn。 输出：nnn 的一个非平凡因子 ddd。 （1） 选择一个平滑界 BBB。 （2） 随机选择一个整数 aaa，2≤a≤n−12 \le a \le n-12≤a≤n−1，并计算 d=(a,n)d = (a, n)d=(a,n)。如果 d≥2d \ge 2d≥2，则 return(ddd)。 （3） 对于每个素数 q≤Bq \le Bq≤B 做如下操作。 　（3.1） 计算 l=⌊ln⁡nln⁡q⌋l = \left\lfloor \frac{\ln n}{\ln q} \right\rfloorl=⌊lnqlnn​⌋。 　（3.2） 计算 a←aql(modn)a \leftarrow a^{q^{l}} \pmod na←aql(modn)。 （4） 计算 d=(a−1,n)d = (a - 1, n)d=(a−1,n)。 （5） 如果 d=1d = 1d=1 或 d=nd = nd=n，则失败终止算法。否则，return(ddd)。

补逐步解释算法的每一步：

输入："一个非单一素数乘幂的合数 nnn"。这个限定条件很重要：

  • 如果 nnn 是纯素数幂（n=pkn = p^kn=pk），这个算法不适用（因为只有一个"因子"可提，gcd⁡\gcdgcd 会直接给出 nnn 或平凡值）；
  • 实际场景中 n=pqn = pqn=pq（两个不同素数），完全符合。

第（2）步：先"顺手"检查 gcd⁡(a,n)\gcd(a, n)gcd(a,n)。

这一步是个便宜的兜底：随机选的 aaa 万一恰好和 nnn 有公因子（比如 aaa 是 ppp 的倍数），那直接白得一个因子。概率很小，但算一次 gcd⁡\gcdgcd 几乎不要钱，所以顺手做掉。

补这种"先做一次廉价检查"的写法在算法设计里很常见，叫 "cheap pre-check"。它不改变最坏情况，但能在少数情况下"运气好省一大步"。

第（3）步：累积地把 QQQ 的所有因子"喂"进 aaa 的指数里。

注意这里有个巧妙的"折叠"：算法没有真的算出 QQQ（QQQ 是个天文数字），而是边算边把每个 qlq^{l}ql 的幂次乘进指数：

a ← a^{q₁^{l₁}}          （处理 q₁ = 2）
a ← (上面结果)^{q₂^{l₂}}  （处理 q₂ = 3）
a ← …^{q₃^{l₃}}          （处理 q₃ = 5）
   ⋮
最后 a = a₀^{q₁^{l₁} · q₂^{l₂} · … } = a₀^{Q}

因为幂运算满足 (ax)y=axy(a^{x})^{y} = a^{xy}(ax)y=axy，所以这个"逐次取幂"的效果和"一次取 QQQ 次幂"完全一样——但每次只需要算一个小指数 qlq^lql 的模幂。

补这里有一个很有意思的细节：qlq^lql 本身可能还是很大的数。

对 q=2, n≈21024:l=⌊1024ln⁡2ln⁡2⌋=1024,ql=21024\text{对 } q = 2,\ n \approx 2^{1024}: \quad l = \left\lfloor \frac{1024 \ln 2}{\ln 2} \right\rfloor = 1024, \quad q^l = 2^{1024}对 q=2, n≈21024:l=⌊ln21024ln2​⌋=1024,ql=21024

这个指数有 1024 比特——但用第 2.2 节的快速模幂（从左向右二进制算法），算 a21024 mod na^{2^{1024}} \bmod na21024modn 只需要约 1024 次模平方。所以这一步本身是可行的。

补为什么用 l=⌊ln⁡n/ln⁡q⌋l = \lfloor \ln n / \ln q \rfloorl=⌊lnn/lnq⌋ 而不是别的？

因为 qlq^lql 要能"覆盖"住 p−1p-1p−1 里 qqq 的幂次。而 p−1<np-1 < np−1<n，所以 p−1p-1p−1 里 qqq 的最高幂次不超过 ⌊ln⁡n/ln⁡q⌋\lfloor \ln n/\ln q\rfloor⌊lnn/lnq⌋。

如果取小了（比如只取 l=1l = 1l=1），那么 QQQ 里 qqq 的幂次不够，覆盖不住 p−1p-1p−1，算法失效。 如果取大了，计算量增加但不会有额外收益（因为超过的部分用不上）。

所以这个 lll 是"刚好够用"的精确值。

第（4）（5）步：gcd⁡\gcdgcd 一次定成败。

d=(a−1, n)d = (a - 1,\ n)d=(a−1, n)
  • d=1d = 1d=1：完全失败。说明连 ppp 都没被"打开"——可能 aaa 选得不好（比如 a≡1(modp)a \equiv 1 \pmod pa≡1(modp)），或者 p−1p-1p−1 不是 BBB-平滑的；
  • d=nd = nd=n："打得太开"——两个因子同时被打开了（p−1p-1p−1 和 q−1q-1q−1 都是 BBB-平滑的）；
  • 2≤d≤n−12 \le d \le n-12≤d≤n−1：成功，ddd 就是一个非平凡因子。

补注意第（2）步已经把 aaa 检查过一遍了，所以第（5）步里 d=1d=1d=1 的含义是：aQ≡1(modp)a^Q \equiv 1 \pmod paQ≡1(modp) 对任何因子 ppp 都不成立。这意味着 aaa 的选取（或 BBB 的选取）不合适。
