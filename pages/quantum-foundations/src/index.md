共 101 页 PPT）重讲了一遍。它不是课件的摘要，而是**按课件原有的节次顺序，把每一页的知识点用初学者能跟上的速度重写**，并把课件默认你已掌握、其实很多人没有掌握的前置知识补上。

### 这份讲义怎么用

1. **先看第 0 章（前置知识补课）**。它是整份讲义的地基：复向量空间、狄拉克记号、厄米/酉算子、概率与期望、张量积、经典比特与量子比特的差别。跳过它，后面会一直磕磕绊绊。
2. **对照课件看**。每节都标了 `（PPT 第 N 页）`，可以直接翻到对应 PPT 核对。课件的节次编号被完整保留（1 / 1.1 / 2 / 2.1 …），所以你能用课件的目录来定位。
3. **看到橙色「补」徽章要格外认真**。那是我补充的、课件里没写但初学必需的内容（术语定义、历史背景、类比、易错点）。看到橙色「勘误」徽章，说明课件该处有笔误或不严谨，已给出订正。
4. **公式不是装饰**。每个公式后面都有一句「翻译成人话」。遇到看不懂的推导，先看那句白话，再回头抠符号。
5. **每讲结尾有小结与自测题**，答案默认折叠，先自己做再看。
6. **附录不是装饰，复习时优先用**：附录 A 是术语中英对照表，附录 B 是关键公式速查（每条都写了「什么时候用」），附录 C 是常见疑问 FAQ，附录 D 是跨讲综合自测题。**考前只看 B + D 就能覆盖全部考点**。它们在右侧目录条最下方的「附录」一组里。

### 阅读建议（按你的基础选路线）

| 你的情况 | 建议路线 |
|---|---|
| 完全没学过线性代数/复变 | 第 0 章逐节精读 → 第一讲 → 第二讲逐节精读 |
| 学过线代，但没接触过量子的形式化 | 第 0 章快速扫一遍（重点 0.2 内积、0.3 谱分解）→ 第二讲精读 |
| 只想搞懂「为什么量子能算得快」 | 导言 + 1.1–1.4 + 第四讲（布洛赫球） |
| 要交期中大作业 | 第 0 章 → 2.6（非正交态不可区分）→ 2.9（贝尔态）→ 课程作业一节 |

### 关于正文里的这些约定

- `（PPT 第 N 页）`：该段落对应课件页码。
- 蓝色等宽代码块：用来放 **ASCII 结构图**（框图、流程、矩阵排布）。若你看到这些框线错位，是本机缺少覆盖 `⊕ ─ │ ┌ └` 的等宽字体，页面左下角会自己提示你安装 Consolas 或 DejaVu Sans Mono。
- 表格：`表格` 用于概念对比；灰色无表头的对齐表用于**纯数值排列表**（如矩阵）。
- 数学公式在构建时已离线渲染成矢量/HTML 混排，**断网也能正常显示**（不依赖任何 CDN）。
- 每节底部的「上一节 / 下一节」和右侧「大章节」目录条可以连续翻页；右侧目录可用「收起」按钮隐藏，状态会记住。

### 从课件到讲义的取舍

- 课件里的**思考题、课堂讨论、Q&A** 被保留在对应位置，并补上了「该怎么想」的提示。
- 课件口播性的重复表述被合并；同一知识点在多页反复出现的，合并到首次出现处以保持线索清晰。
- 课件中的**数字、矩阵、常数**若前后不自洽，我会用「勘误」标出，并提示「看流程、不纠结数字」。
