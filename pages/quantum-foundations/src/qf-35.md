### 使用说明

本附录是 P1 全书的**术语中英对照表**，按主题分组。用途有三个：①读英文教材/论文时对不上中文说法；②复习时用一句话把概念说清；③确认某个术语在本讲义哪一讲、哪一节出现过（正文关键处均标注讲次/小节编号）。

格式约定：**中文名 | 英文名 | 一句话解释**。「一句话解释」都尽量写成可以口头复述的形式，不引入新符号。带「★」的是最容易混淆、建议优先记住的条目。

【补】表中少数条目（如「不可克隆定理」「广义概率论」「量子认知」「上下文性」）课件只点名或未展开，是为便于衔接后续讲次补入的；第一次通读时可以先把它们跳过，不影响本讲的主线。

### A.1 数学基础

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 复数 | complex number | 由实部与虚部组成的数 $a+bi$，其中 $i^{2}=-1$。 |
| 共轭 | complex conjugate | 把虚部符号翻转：$(a+bi)^{*}=a-bi$。 |
| 模 ★ | modulus | 复平面上的长度，$\lvert z\rvert=\sqrt{zz^{*}}$；概率来自模的平方。 |
| 相位因子 | phase factor | 形如 $e^{i\theta}=\cos\theta+i\sin\theta$ 的单位复数，只改「角度」不改长度。 |
| 复向量空间 | complex vector space | 允许复数线性组合的向量空间，是「叠加」的容器。 |
| 希尔伯特空间 | Hilbert space | 定义了内积的复向量空间；有限维时就是 $\mathbb{C}^{n}$。 |
| 内积 ★ | inner product | 把两个向量变成一个复数，$\langle\phi\vert\psi\rangle$；用来算长度、夹角与概率。 |
| 外积 ★ | outer product | $\lvert\phi\rangle\langle\psi\rvert$，结果是一个矩阵（算子），不是数。 |
| 正交 | orthogonal | 内积为零，$\langle\phi\vert\psi\rangle=0$；在量子力学里意味着「可以完美区分」。 |
| 标准正交基 | orthonormal basis | 两两正交且各自归一的基；展开系数可以直接用内积读出。 |
| 归一化 | normalization | 让向量的长度等于 1，保证测量概率总和为 1。 |
| 狄拉克记号 | Dirac notation | 用尖括号区分 ket、bra、内积与外积的记号体系。 |
| ket | ket | 列向量 $\lvert\psi\rangle$。 |
| bra | bra | ket 的共轭转置（行向量），记作 $\langle\psi\rvert$。 |
| 共轭转置 | conjugate transpose (dagger) | 先转置再取共轭，记作 $\dagger$。 |
| 厄米算子 ★ | Hermitian operator | 满足 $A^{\dagger}=A$ 的算子；物理可观测量都必须是厄米的，其特征值为实数。 |
| 酉算子 ★ | unitary operator | 满足 $U^{\dagger}U=I$ 的算子；保内积，对应量子演化与换基。 |
| 特征值 / 特征向量 | eigenvalue / eigenvector | 满足 $A\lvert v\rangle=\lambda\lvert v\rangle$ 的 $\lambda$ 与 $\lvert v\rangle$；测量结果只可能是特征值。 |
| 谱分解 | spectral decomposition | 把厄米算子写成 $A=\sum_i\lambda_i\lvert i\rangle\langle i\rvert$，即「按测量结果拆开」。 |
| 投影算子 | projector | 满足 $P^{2}=P=P^{\dagger}$ 的算子；对应「问一个是非题」。 |
| 迹 ★ | trace | 矩阵对角元之和，也等于全部特征值之和；$\mathrm{tr}(AB)=\mathrm{tr}(BA)$。 |
| 半正定 | positive semidefinite | 对任意向量都有 $\langle v\vert A\vert v\rangle\ge0$；保证「概率不为负」。 |
| 张量积 ★ | tensor product | 把两个系统的空间拼成复合系统空间的运算，记作 $\otimes$。 |
| 克罗内克积 | Kronecker product | 张量积在选定基下的具体矩阵算法；两量子比特给出 $4\times4$ 矩阵。 |
| 期望值 | expectation value | 测量结果的平均值，$\langle M\rangle=\langle\psi\vert M\vert\psi\rangle$。 |
| 方差 | variance | 测量结果的离散程度，$\mathrm{Var}(M)=\langle M^{2}\rangle-\langle M\rangle^{2}$。 |
| 奇异值分解 | singular value decomposition (SVD) | 把任意矩阵写成「左酉 × 非负对角 × 右酉」，施密特分解的证明工具。 |
| 秩 | rank | 矩阵线性无关列的最大个数；也等于非零奇异值的个数。 |
| 凸组合 | convex combination | 形如 $\sum_i p_i x_i$（$p_i\ge0$、$\sum p_i=1$）的加权平均，几何上是「在凸包里取点」。 |
| 李群 / 李代数 | Lie group / Lie algebra | 连续对称性的群与它的「无穷小生成元」；量子演化 $e^{-iHt}$ 就是李群元素。 |
| 特殊正交群 | special orthogonal group SO(3) | 行列式为 $+1$ 的 $3\times3$ 正交矩阵构成的群；单量子比特演化的布洛赫球版本。 |

### A.2 量子力学形式化

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 量子态 | quantum state | 描述一个量子系统的全部可观测信息。 |
| 状态空间 | state space | 量子态所在的希尔伯特空间；维数决定系统「能装多少可区分状态」。 |
| 叠加态 ★ | superposition state | 同一基下多个基态的复系数线性组合，如 $a\lvert0\rangle+b\lvert1\rangle$。 |
| 计算基 | computational basis | 最常用的基 $\{\lvert0\rangle,\lvert1\rangle\}$。 |
| 表示基 | representation basis | 用来把抽象态写成具体系数的基；换基不改变状态本身。 |
| 概率幅 | probability amplitude | 展开系数本身，可正可负可复；只有它的模平方才是概率。 |
| 全局相 ★ | global phase | 整个态乘上 $e^{i\theta}$，不改变任何测量结果，因此不可观测。 |
| 测量算子 | measurement operator | 一般测量中与结果 $m$ 对应的算子 $M_m$，概率为 $\langle\psi\vert M_m^{\dagger}M_m\vert\psi\rangle$。 |
| 投影测量 | projective measurement | 用一组正交投影算子描述的测量，是一般测量的特例。 |
| 一般测量 / POVM | generalized measurement / POVM | 只要求 $\sum_m M_m^{\dagger}M_m=I$ 的测量；比投影测量更一般，可含「不确定结果」。 |
| 完备性关系 | completeness relation | $\sum_m M_m^{\dagger}M_m=I$，即「所有结果的概率加起来是 1」。 |
| 测量塌缩 ★ | measurement collapse / state reduction | 测量后状态跳到与结果对应的态上，如 $M_m\lvert\psi\rangle/\sqrt{p(m)}$。 |
| 后测量态 | post-measurement state | 测量之后系统所处的状态，与测量前一般不同。 |
| 可观测量 | observable | 用厄米算子表示的物理量，其谱就是可能的测量结果。 |
| 密度算子 ★ | density operator / density matrix | $\rho=\sum_i p_i\lvert\psi_i\rangle\langle\psi_i\rvert$，统一描述纯态、经典混合与子系统状态。 |
| 纯态 ★ | pure state | 可以用一个态向量写出的状态；判据 $\mathrm{tr}(\rho^{2})=1$。 |
| 混合态 ★ | mixed state | 不能用单个态向量描述的状态；$\mathrm{tr}(\rho^{2})<1$。 |
| 最大混合态 | maximally mixed state | $\rho=I_n/n$，测量结果对任何基都完全随机，代表「一无所知」。 |
| 纯度 | purity | $\mathrm{tr}(\rho^{2})$；等于 1 是纯态，越小越混。 |
| 偏迹 ★ | partial trace | 只对复合系统的一个子系统求迹、另一个不动的线性运算，记作 $\mathrm{tr}_B$。 |
| 约减密度算子 ★ | reduced density operator | 子系统自己的状态，$\rho^{A}=\mathrm{tr}_B(\rho^{AB})$。 |
| 局域状态 | local state | 在单个子系统上做测量所看到的状态；等于约减密度算子。 |
| 施密特分解 ★ | Schmidt decomposition | 把纯态换基写成 $\lvert\psi\rangle=\sum_i\lambda_i\lvert i_A\rangle\lvert i_B\rangle$，$\lambda_i\ge0$。 |
| 施密特系数 | Schmidt coefficients | 施密特分解中的系数 $\lambda_i$，满足 $\sum_i\lambda_i^{2}=1$。 |
| 施密特数 ★ | Schmidt number | 施密特系数中非零元素的个数；等于 1 等价于积状态。 |
| 部分转置 | partial transpose (PT) | 只对复合系统的一个子系统转置；$\mathrm{PT}(\rho)$ 半正定是纠缠的必要条件。 |
| 可分性 | separability | 状态能否写成积状态的凸组合；可以写成则是可分态（非纠缠态）。 |
| 布洛赫球 ★ | Bloch sphere | 单量子比特状态的几何表示：单位球，纯态在球面、混合态在球内。 |
| 布洛赫向量 ★ | Bloch vector | 三个 Pauli 期望值组成的三维实向量 $\psi_i=\mathrm{tr}(\sigma_i\rho)$。 |
| 互补测量 ★ | complementary measurement | 布洛赫向量正交的两个投影测量；不能同时进行，一个方向的结果对另一个方向不提供信息（$\Omega=\frac12$）。 |
| 兼容测量 ★ | compatible measurement | 布洛赫向量反平行（同一测量基）的两个投影测量；可被同一次测量给出。 |
| 双重覆盖 | double cover | $\mathrm{SU}(2)$ 到 $\mathrm{SO}(3)$ 的二对一映射：$U$ 与 $-U$ 给出同一个旋转。 |
| 退相干 | decoherence | 系统与环境纠缠后，局域状态的非对角项（相干性）消失的过程。 |
| 唯象模型 | phenomenological model | 数学形式明确、能预言实验但公理缺乏直观物理图像的理论（课件对量子力学的定位）。 |
| 公理化 | axiomatization | 用少数几条原则推出整套形式化的做法。 |

### A.3 量子信息与纠缠

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 量子比特 ★ | qubit | 二维量子系统，状态空间为 $\mathbb{C}^{2}$，布洛赫球是其几何图像。 |
| 量子信息 | quantum information | 以量子态为载体、以振幅与纠缠为资源的信息。 |
| 纠缠 ★ | entanglement | 复合系统状态无法写成两个子系统状态的张积的现象。 |
| 积状态 ★ | product state | 可以写成 $\lvert\alpha\rangle\otimes\lvert\beta\rangle$ 的状态；施密特数为 1。 |
| 贝尔态 ★ | Bell state | 两量子比特四个最大纠缠态 $\lvert\Phi^{\pm}\rangle$、$\lvert\Psi^{\pm}\rangle$ 的统称。 |
| 最大纠缠态 | maximally entangled state | 施密特系数全部相等的纠缠态（两量子比特时各为 $1/\sqrt2$）。 |
| 局域操作 | local operation | 只作用在单个子系统上的操作，如 $U_A\otimes I_B$；不改变另一端的局域状态。 |
| 非定域性 | nonlocality | 无法用局域隐变量模型解释的统计关联。 |
| 贝尔不等式 | Bell inequality | 局域实在论必须满足的不等式；量子力学可以违背它（实验已证实）。 |
| 隐变量 | hidden variable | 假设量子随机性背后存在未被观测的确定取值的变量。 |
| 上下文性 | contextuality | 测量结果的分布依赖于「与哪些其它观测量一起测量」这一语境。 |
| 非经典概率 | non-classical probability | 不满足柯尔莫哥洛夫公理（尤其分配律）的概率结构。 |
| 分配律 | distributivity | 命题格中 $A\wedge(B\vee C)=(A\wedge B)\vee(A\wedge C)$；量子事件格不满足它。 |
| 柯尔莫哥洛夫概率 | Kolmogorov probability | 经典概率论的公理化体系；量子概率不是它的一个实例。 |
| 量子密钥分发 | quantum key distribution (QKD) | 用非正交态不可区分性生成安全密钥，如 BB84 协议。 |
| 不可克隆定理 | no-cloning theorem | 任意未知量子态不能被精确复制，这是量子密码的基础之一。 |
| 局部可区分性 | local distinguishability | 只能做局域测量与经典通信时能区分哪些态；与纠缠密切相关。 |
| 纠缠熵 | entanglement entropy | 用 $\rho^{A}$ 的冯·诺依曼熵度量纠缠量；积状态时为 0。 |
| 密度算子的系综分解 | ensemble decomposition of a density operator | 同一个 $\rho$ 可以有无穷多种「概率混合哪些纯态」的写法。 |
| 操作主义 | operationalism | 用「能测出什么统计结果」来定义物理状态意义的方法论。 |

### A.4 量子计算与算法

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 量子门 | quantum gate | 作用在量子比特上的酉变换，是量子线路的基本元件。 |
| 单比特门 | single-qubit gate | 作用在单个量子比特上的 $2\times2$ 酉矩阵。 |
| 泡利门 | Pauli gates | $X$、$Y$、$Z$ 三个门，对应布洛赫球绕 $x$、$y$、$z$ 轴转 $\pi$。 |
| 哈达玛门 | Hadamard gate | $H=\frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$，把 $\lvert0\rangle$ 变成 $\lvert+\rangle$，制造叠加。 |
| 量子线路 | quantum circuit | 门的时序排列 + 测量，是量子算法的标准画法。 |
| 量子并行 | quantum parallelism | 一次酉变换同时作用在叠加态的所有分支上，是加速的直觉来源。 |
| 量子算法 | quantum algorithm | 利用叠加与纠缠完成计算任务的算法，如 Shor、Grover。 |
| 多项式加速 | polynomial speedup | 相对经典最好算法只有多项式级提升（如 Grover 的平方根加速）。 |
| 指数加速 | exponential speedup | 相对经典最好算法有指数级提升（如 Shor 因式分解）。 |
| 非确定图灵机 | non-deterministic Turing machine (NTM) | 可以「同时探索多条路径」的抽象计算模型，常被用来类比叠加性。 |
| 广义量子人工智能 | generalized quantum AI | 用量子力学作为 AI 与认知的数学模型的宽泛方向。 |
| 狭义量子人工智能 | narrow quantum AI | 在量子计算机上实现机器学习算法这一具体方向。 |
| 量子上下文相关资源 | contextual resource | 上下文性等非经典性在量子计算中可被当作「资源」使用。 |

### A.5 物理、实验与思想方法

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 双缝干涉 | double-slit interference | 单个粒子逐个发射仍出现条纹，是叠加性最直接的证据。 |
| 路径信息 | which-path information | 「知道粒子走了哪条缝」的信息；路径信息越完全，干涉条纹越弱。 |
| 量子擦除 | quantum eraser | 把路径信息「擦掉」之后干涉条纹重新出现。 |
| 互补性 | complementarity | 路径信息与干涉可视度不能同时达到最大。 |
| 不确定性原理 | uncertainty principle | 两个不兼容观测量（如位置与动量、$\sigma_x$ 与 $\sigma_z$）无法同时确定。 |
| 自旋 | spin | 粒子的内禀角动量，单量子比特最常实现为自旋 $1/2$。 |
| 手性 | chirality | 自旋在 $x$、$y$、$z$ 三个方向上的「取向」，不能同时确定。 |
| 实验装置的不完美 | experimental imperfection | 真实实验中的噪声与探测效率，是不等式检验必须处理的系统误差。 |
| 狭义相对性原理 | principle of special relativity | 「所有惯性系中物理规律相同」，是狭义相对论的直观前提之一。 |
| 光速不变原理 | constancy of the speed of light | 「真空光速对所有惯性系相同」，是狭义相对论的另一前提。 |
| 广义概率论 | generalized probabilistic theories (GPT) | 把「状态是凸集、测量是仿射映射」等结构抽象出来的理论框架，量子理论是其中一个成员。 |
| 信息因果原则 | information causality | 一条信息论原则，与其它几条一起可导出有限维量子理论。 |
| 解释之争 | interpretation debate | 关于量子态到底「描述知识」还是「描述实在」的争论，不影响计算预言。 |
| 科学实在论 | scientific realism | 「理论成功意味着它描述的对象真实存在」的哲学立场。 |
| 量子认知 | quantum cognition | 用非经典概率与非对易结构建模人类判断与决策的方向。 |

### A.6 最容易混淆的五组术语（建议对照背诵）

| 易混对 | 区别要点 |
|---|---|
| 内积 $\langle\phi\vert\psi\rangle$ vs 外积 $\lvert\phi\rangle\langle\psi\rvert$ | 内积是**数**（可算概率），外积是**矩阵**（可当算子）。 |
| 纯态 $\rho=\lvert\psi\rangle\langle\psi\rvert$ vs 混合态 $\rho=\sum_i p_i\lvert\psi_i\rangle\langle\psi_i\rvert$ | 判据是 $\mathrm{tr}(\rho^{2})=1$ 还是 $<1$；「看起来像混合」不等于混合。 |
| 施密特系数 $\lambda_i$ vs 混合概率 $p_i$ | 前者是**振幅**，平方才是概率，且只描述纯态；后者本身就是概率。 |
| 偏迹 $\mathrm{tr}_B$ vs 部分转置 $\mathrm{PT}$ | 偏迹是**求迹**（得子系统的状态），部分转置是**转置**（用于纠缠判据）。 |
| 互补测量 vs 兼容测量 | 布洛赫向量**正交**是互补（不能同时测），**反平行**是兼容（同一个基的两个结果）。 |
