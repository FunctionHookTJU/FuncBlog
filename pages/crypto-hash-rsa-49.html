3.2.2 Pollard 的 p−1p-1p−1 算法（PPT 第 24–27 页）（续 1）

评述（PPT 第 26 页）

PPT 原文：

评述. （1） 事实上，如果 d=nd = nd=n，我们并不是一无所获。这种情况下，我们得到了一个值 rrr 满足 ar≡1(modn)a^{r} \equiv 1 \pmod nar≡1(modn)。这给了我们一个机会使用指数分解方法分解 nnn。同时，我们还可以选择一个更小的平滑界 BBB 重新执行算法。 （2） 如果我们选择一个小的平滑界 BBB，则算法执行速度将会非常快但是成功的几率会非常低。如果我们选择一个非常大的 BBB，算法执行速度就会相当慢。对 BBB 的实际值常常需要根据具体情况来确定。

补第（1）条那句"并不是一无所获"很值得学——它体现了一种"失败也是信息"的思路。

为什么 d=nd = nd=n 时能拿到一个通用指数？

d=nd = nd=n 意味着 n∣(aQ−1)n \mid (a^Q - 1)n∣(aQ−1)，也就是

aQ≡1(modn)a^{Q} \equiv 1 \pmod naQ≡1(modn)

而 QQQ 是对所有 gcd⁡(a,n)=1\gcd(a,n)=1gcd(a,n)=1 的 aaa 都成立的通用指数（它只依赖于 nnn 和 BBB，与 aaa 无关）。

所以我们已经有了一个通用指数 r=Qr = Qr=Q——于是直接套第 3.2.1 节的"通用指数分解方法"（那个方法能把 50% 左右的成功率做到），问题就解决了。

补这是一个非常漂亮的"失败转化为成功"的例子：

Pollard p−1 直接跑 → d = n → "失败"

但是换个角度看：d = n 意味着我们掌握了 a^Q ≡ 1 (mod n)
                  ↓
      这正是"通用指数分解方法"需要的输入
                  ↓
          套用 3.2.1 节的方法 → 成功分解

所以 3.2.1 节和 3.2.2 节是"上下游关系"：3.2.2 负责"生产"通用指数，3.2.1 负责"消费"通用指数。 这也是 PPT 把 3.2.1 放在前面讲的原因。

补第（1）条还给了第二条退路：换一个更小的 BBB 重跑。

为什么更小的 BBB 能避免 d=nd=nd=n？

d=nd = nd=n 的原因是"两个因子同时被打开"，也就是 p−1p-1p−1 和 q−1q-1q−1 都是 BBB-平滑的。

减小 BBB 之后，"平滑"的条件变严了——可能就变成"p−1p-1p−1 平滑、q−1q-1q−1 不平滑"，于是只有一个因子被打开，gcd⁡\gcdgcd 就成功了。

补这两条退路合起来说明：这个算法即使"失败"也不算废，因为它总能把问题转化成另一个视角下的问题。"把失败当作新信息"是密码分析里非常重要的思维方式。

补第（2）条是纯粹的工程权衡，用一张表说清：

BBB 需要算的素数个数 计算量 成功概率
小（如 100） 25 个 小 低——只有 p−1p-1p−1 的素因子都很小才行
中（如 10510^5105） 9592 个 中 中
大（如 10610^6106） 78498 个 大 高

补这个算法在现实中还有用吗？ 有，但用途很明确：

它就是"为什么第 4.2 节要推荐强素数"的那个理由之一。 如果 RSA 的 ppp 满足"p−1p-1p−1 是 BBB-平滑的"（BBB 不太大），那么只需选个小的 BBB，这个算法几秒钟就能分解 nnn。

防御方式：让 p−1p-1p−1 含有一个大素数因子（这就是第 4.2 节"强素数"的第一个条件）。这样 p−1p-1p−1 就不是 BBB-平滑的了，Pollard p−1p-1p−1 就失效了。

补这就是"一个被打开、一个没被打开"的完美局面：

对因子 p = 5281：
   p−1 = 5280 是 19-平滑的

   3607−1 = 3606 不是 19-平滑的（含 601 这个大于 19 的素因子）

补这个例子的"教学要点"，三条：

# 要点
1 lll 的计算是"够用就好"：⌊ln⁡n/ln⁡q⌋\lfloor \ln n/\ln q\rfloor⌊lnn/lnq⌋ 是能取的最大幂次，一个不多一个不少
2 成功的条件是"恰好一个因子平滑"：p−1p-1p−1 平滑而 q−1q-1q−1 不平滑 → 完美；两个都平滑 → d=nd=nd=n 失败；两个都不平滑 → d=1d=1d=1 失败
3 BBB 的选择决定了成败：这个例子里 B=19B=19B=19 刚好把 p−1p-1p−1 的素因子（最大 11）盖住，同时没盖住 q−1q-1q−1 的 601。如果 B=601B = 601B=601 或更大，两个因子都会被打开，ddd 就变成 nnn 了

补第 3 点特别值得琢磨：它说明 Pollard p−1p-1p−1 的成功不是"越努力越好"，而是"刚好卡在中间"。

这也正是第 4.2 节"强素数"的第一个条件（"p−1p-1p−1 有大的素数因子"）能有效防御它的原因：如果 p−1p-1p−1 含有一个很大的素因子（比如接近 ppp 本身量级），那么要让 BBB 盖住它，BBB 就得大到不可行——攻击者被"卡"在了"太小不成功、太大跑不动"的位置上，无解。
