1　有限域 GF(pn)GF(p^{n})GF(pn) 的知识

对应 PPT 第 8–12 页。这一节是纯数学，但请你耐心——它没有看起来那么难，只是名词陌生。

1.1 先建立直觉：什么是"域"，什么叫"有限域"

补**域（Field）**是一个"四则运算封闭"的集合。通俗地说：一个集合里能自由地做加、减、乘、除（除数非零），结果永远还在这个集合里。

  • 有理数集合是一个域（无限域）：任意两个有理数加减乘除，结果还是有理数。
  • 整数集合不是域：因为 1÷2=0.51 \div 2 = 0.51÷2=0.5 跑出了整数范围。

补有限域（Finite Field / Galois Field，记作 GF）：元素个数有限的域。元素个数有限，就意味着"能穷举"，这正是计算机最喜欢的性质。

为什么密码学需要有限域？ 因为有限域里的运算既封闭又不会溢出：加、减、乘、除的结果永远落在同一个集合里，而且每一个非零元都有逆元（可以除以它）。这正是设计加密算法所需要的——既要能把数据"搅乱"，又要保证能精确地"还原回来"。

PPT 第 8 页的结论（这是本节的总纲，务必记住）：

对于一个素数 p，恰好有一个有限域的元的个数为 pnp^{n}pn。但是整数模 pnp^{n}pn 不能形成这个有限域，原因是同余方程 p⋅x≡1(modpn)p\cdot x \equiv 1 (mod p^{n})p⋅x≡1(modpn) 无解。

补逐句理解：

  • "恰好有一个"：元素个数是 pnp^{n}pn 的有限域在同构意义下唯一（不论你怎么构造，结构都一样）。所以你可以放心地"就是它"。
  • "整数模 pnp^{n}pn 不能形成"：注意 p 是素数，所以 模 p（记作 ZpZ_pZp​）是一个域（因为每个非零元都和 p 互素，所以都有逆元）。但 模 pⁿ（n≥2n \ge 2n≥2）就不是域了——比如 p=2,n=2p=2, n=2p=2,n=2，即模 4：想找 2 的逆元，就是解 2x ≡ 1 (mod 4)。左边永远是偶数，右边是奇数，永远无解。
  • 原因就是 PPT 说的：p⋅x≡1(modpn)p\cdot x \equiv 1 (mod p^{n})p⋅x≡1(modpn) 无解。因为 p⋅xp\cdot xp⋅x 总是 p 的倍数，而 1 不是 p 的倍数。

那怎么办？ 模 pⁿ 走不通，就换一条路：用"以 p 为系数的多项式"来构造。这就是下一节。

1.2 例 1：亲手建立 GF(22)GF(2^{2})GF(22)（PPT 第 9 页）

这是全书最值得亲手做一遍的例子。建议拿张纸跟着算。

例 1　建立 GF(22)GF(2^{2})GF(22)。

解：令 Z2[X]Z_2[X]Z2​[X] 是系数为整数模 2 的多项式的集合，例如 X6+X+1X^{6}+X+1X6+X+1、X。常量多项式 0 和 1 也在 Z2[X]Z_2[X]Z2​[X] 之中。

我们可以在多项式上做加减乘，只要系数模 2 即可，例如：

(X³ + X + 1)(X + 1) = X⁴ + X³ + X² + 1

我们也可以如同整数一样做除余。 例如，我们用 X2+X+1X^{2} + X + 1X2+X+1 除 X4+X3+1X^{4} + X^{3} + 1X4+X3+1，得到：

X⁴ + X³ + 1 = (X² + 1)(X² + X + 1) + X

我们也可以写做 X4+X3+1≡X(modX2+X+1)X^{4} + X^{3} + 1 \equiv X (mod X^{2} + X + 1)X4+X3+1≡X(modX2+X+1)。

因此，我们可以定义 Z2[X](modX2+X+1)Z_2[X] (mod X^{2} + X + 1)Z2​[X](modX2+X+1) 为集合

{ 0, 1, X, X + 1 }

这里多项式的度最多为 1。对于模 X2+X+1X^{2} + X + 1X2+X+1 下的加法和乘法，实际构成了 4 个元的有限域。

补逐条拆解，把每一步的门道说清楚：

① 系数模 2 是什么意思？

多项式的系数只有 0 和 1，而加减乘的时候系数都要 mod 2。于是：

(X³ + X + 1)(X + 1)
= X³·X + X³·1 + X·X + X·1 + 1·X + 1·1
= X⁴ + X³ + X² + X + X + 1
= X⁴ + X³ + X² + (X ⊕ X) + 1        ← 因为 mod 2 下 X+X = 0
= X⁴ + X³ + X² + 1                    ✓ 与 PPT 一致

记住这条：在 GF(2) 上，"加"就是异或，"减"和"加"是同一件事（因为 1+1=01 + 1 = 01+1=0，所以 −1=1-1 = 1−1=1）。这就是为什么后面所有运算都能写成异或。

② 除余是什么意思？

和整数的带余除法完全一样：

   X⁴ + X³ + 1  ÷  X² + X + 1
  • 先看最高次项：X4÷X2=X2X^{4} \div X^{2} = X^{2}X4÷X2=X2，所以商的第一项是 X2X^{2}X2。
  • X2⋅(X2+X+1)=X4+X3+X2X^{2}\cdot (X^{2}+X+1) = X^{4} + X^{3} + X^{2}X2⋅(X2+X+1)=X4+X3+X2，用它去减被除数（在 GF(2) 上减就是异或）：
    (X⁴ + X³ + 0X² + 1) ⊕ (X⁴ + X³ + X² + 0) = X² + 1
  • 再看 X2÷X2=1X^{2} \div X^{2} = 1X2÷X2=1，商的第二项是 1。
  • 1⋅(X2+X+1)=X2+X+11\cdot (X^{2}+X+1) = X^{2} + X + 11⋅(X2+X+1)=X2+X+1，再减：
    (X² + 0X + 1) ⊕ (X² + X + 1) = X
  • X 的次数（1）已经低于除数 X2+X+1X^{2}+X+1X2+X+1 的次数（2），停止。

所以：商 = X2+1X^{2}+1X2+1，余数 = X，写成 X4+X3+1=(X2+1)(X2+X+1)+XX^{4}+X^{3}+1 = (X^{2}+1)(X^{2}+X+1) + XX4+X3+1=(X2+1)(X2+X+1)+X ✓ 与 PPT 一致。

③ 为什么集合是 0,1,X,X+1{0, 1, X, X+1}0,1,X,X+1？

因为凡是次数 ≥ 2 的多项式，都可以"除余"降次，最终变成一个次数 ≤ 1 的多项式。而次数 ≤ 1 的多项式，系数各取 0 或 1，一共有 2×2=42 \times 2 = 42×2=4 种：

0·X + 0 = 0
0·X + 1 = 1
1·X + 0 = X
1·X + 1 = X + 1

所以这个域正好有 4=224 = 2^{2}4=22 个元素 ✓ 这就是"元素个数为 pnp^{n}pn"的来历——n 就是"度不超过 n−1 的多项式"的系数自由度数，也就是 n 个系数各取 p 种可能 → 共 pnp^{n}pn 个元素。

④ 这几个元素的名字怎么写？

多项式 当成 2 比特看 十进制
0 00 0
1 01 1
X 10 2
X+1X+1X+1 11 3

补看出门道了吗？ GF(22)GF(2^{2})GF(22) 的 4 个元素，正好就是"2 比特能表示的全部 4 种状态"。 推广一下：GF(28)GF(2^{8})GF(28) 的 256 个元素，正好就是"1 个字节能表示的全部 256 种状态"。 这就是为什么 AES 要把字节和 GF(28)GF(2^{8})GF(28) 的元一一对应——计算机天生会做这种运算，不需要额外的表示。

⑤ 为什么必须用"既约多项式"？

X2+X+1X^{2}+X+1X2+X+1 在 GF(2) 上不能分解（把 X=0X=0X=0 和 X=1X=1X=1 代进去：0+0+1=1≠00+0+1=1\ne 00+0+1=1=0，1+1+1=1≠01+1+1=1\ne 01+1+1=1=0 —— 都没有根，所以不可约）。这就是【既约多项式 / 不可约多项式】。

补类比：构造 ZpZ_pZp​（模素数）时，要求 p 是素数，因为"合数会导致有零因子、除不了"；构造 GF(pn)GF(p^{n})GF(pn) 时，"素数"这个角色由既约多项式来扮演。如果一个多项式可以分解，用它做模就会出问题（会出现两个非零元相乘得 0，那样就没有逆元了）。

1.3 建立 GF(pn)GF(p^{n})GF(pn) 的一般过程（PPT 第 10 页）

PPT 给了标准三步，这三步要背下来：

（1）Zp[X]Z_p[X]Zp​[X] 是系数为模 p 的多项式集合。 （2）选择一个系数为模 p、度为 n 的既约多项式 P(X)。 （3）令 GF(pn)GF(p^{n})GF(pn) 为 Zp[X](modP(X))Z_p[X] (mod P(X))Zp​[X](modP(X))，则 GF(pn)GF(p^{n})GF(pn) 是有 pnp^{n}pn 个元的有限域。

PPT 的注释（第 10 页）：

# 如果我们选择两个不同的模 p、度为 n 的既约多项式来建立有限域 GF(pn)GF(p^{n})GF(pn) 会怎样？答案是它们在计算意义上都是相同的。

补这句话在说什么？ 意思是：选用哪一个既约多项式，得到的域"结构上"是同一个（数学上叫"同构"）。但是——注意这里有坑——"同构"是抽象意义上的；如果你把元素表示成字节（例如把 X7+X6+X3+X+1X^{7}+X^{6}+X^{3}+X+1X7+X6+X3+X+1 记作 11001011），那么不同的既约多项式会导致同一串比特对应不同的数值，具体的加法乘法表就不一样了。

所以 Rijndael 必须明确指定用哪一个，这就是它选定 X8+X4+X3+X+1X^{8}+X^{4}+X^{3}+X+1X8+X4+X3+X+1 的原因（见 1.4 节）。AES 标准里，这个多项式是硬性规定的一部分。

1.4 GF(28)GF(2^{8})GF(28)：AES 真正用的域（PPT 第 12 页）

PPT 原文：

以 GF(28)=Z2[X](modX8+X4+X3+X+1)GF(2^{8}) = Z_2[X] (mod X^{8} + X^{4} + X^{3} + X + 1)GF(28)=Z2​[X](modX8+X4+X3+X+1) 为例。每个有限域的元能够唯一表示为多项式

b₇X⁷ + b₆X⁶ + b₅X⁵ + b₄X⁴ + b₃X³ + b₂X² + b₁X + b₀

这里 bib_{i}bi​ 为 0 或 1。8 比特 b7b6b5b4b3b2b1b0b_{7}b_{6}b_{5}b_{4}b_{3}b_{2}b_{1}b_{0}b7​b6​b5​b4​b3​b2​b1​b0​ 可以表示为一个字节。 例如，X7+X6+X3+X+1X^{7} + X^{6} + X^{3} + X + 1X7+X6+X3+X+1 就是 11001011。

补这是全讲最重要的对应关系，请刻进脑子：

多项式 X⁷ + X⁶ + X³ + X + 1
   ↓  系数依次写下来（有 X^k 项写 1，没有写 0）
字节   1 1 0 0 1 0 1 1
        ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
       X⁷X⁶X⁵X⁴X³X²X¹X⁰

一句话：GF(28)GF(2^{8})GF(28) 的元 = 一个字节；多项式的系数 = 这个字节的各个比特。 从此以后看到"字节"，就想到"GF(28)GF(2^{8})GF(28) 的元"。

加法：按比特异或

PPT 原文：

加法是按比特异或或 XOR：

(X⁷ + X⁶ + X³ + X + 1) + (X⁴ + X³ + 1)
→ 11001011 ⊕ 00011001
= 11010010
→ X⁷ + X⁶ + X⁴ + X

验算：

  1100 1011     ← X⁷+X⁶+X³+X+1
⊕ 0001 1001     ← X⁴+X³+1
───────────
  1101 0010

11010010 → X7+X6+X4+XX^{7} + X^{6} + X^{4} + XX7+X6+X4+X ✓

补为什么加法就是异或？ 因为系数 mod 2：逐位相加时 1+1=01+1=01+1=0（不进位），1+0=11+0=11+0=1，0+0=00+0=00+0=0——这正好就是异或的真值表。所以 GF(28)GF(2^{8})GF(28) 的加法是完全免费的，一个 XOR 门就够。

乘法：左移 + 条件归约

PPT 原文（这段是精华）：

乘法是

(X⁷ + X⁶ + X³ + X + 1)(X)
→ 11001011（左移）→ 110010110（加 0）
→ 110010110 ⊕ 100011011（如果首位为 1，减 X⁸ + X⁴ + X³ + X + 1）
= 010001101

我们可以看到在有限域 GF(28)GF(2^{8})GF(28) 上的计算是有效的。

补把这段拆成三个动作：

动作① 乘以 X = 左移一位（右边补 0）

11001011 × X  →  110010110

因为乘 X 就是把每一项的次数加 1，也就是整体左移一位。

动作② 如果结果跑出了 8 位（首位是 1），就要"归约"

110010110 是 9 位，最高位是 X8X^{8}X8——但 GF(28)GF(2^{8})GF(28) 里不允许出现 X8X^{8}X8 项（所有元素次数 ≤ 7）。怎么办？用归约：因为模多项式给出了

X⁸ + X⁴ + X³ + X + 1 ≡ 0    ⟹    X⁸ ≡ X⁴ + X³ + X + 1

也就是说，凡是出现 X8X^{8}X8 的地方，就把它替换成 X4+X3+X+1X^{4}+X^{3}+X+1X4+X3+X+1。在比特层面，这等价于异或上 100011011（X4+X3+X+1X^{4}+X^{3}+X+1X4+X3+X+1 的比特表示，前面补一个 1 对应 X8X^{8}X8）。

动作③ 做异或，去掉最高位

  110010110
⊕ 100011011
───────────
  010001101

那么"什么时候左移、什么时候异或"？ 这是 GF(28)GF(2^{8})GF(28) 乘法的一般算法（不是乘以 X，而是乘以任意元）：

乘法算法（GF(2⁸) 上的 a × b）：
result = 0
for i = 0 to 7:
    如果 b 的最低位是 1:  result = result ⊕ a
    b = b 右移一位
    a = a 左移一位
    如果 a 跑出 8 位（原 a 的最高位是 1）:  a = a ⊕ (X⁸+X⁴+X³+X+1)

记忆口诀：「乘 X = 左移；跑出去就异或 1B」。

为什么叫 1B？因为 X8+X4+X3+X+1X^{8}+X^{4}+X^{3}+X+1X8+X4+X3+X+1 写成十六进制就是 0x11B（1 0001 1011）。工程实现里都写 0x1B。这个常数要记住。

为什么"计算是有效的"？

PPT 最后那句"我们可以看到在有限域 GF(28)GF(2^{8})GF(28) 上的计算是有效的"，说的是：这套加法（异或）和乘法（移位 + 条件异或）都能用最基础的位运算实现，速度极快，硬件代价极低。 这正是 AES 选它作为运算地基的原因。

1.5 关于除法：扩展 Euclidean 算法（PPT 第 11 页）

问题：既然域里要有除法，那就要能算"逆元"。怎么在 GF(28)GF(2^{8})GF(28) 上求逆元？

PPT 例 2：

例 2　考虑 GF(28)=Z2[X](modX8+X4+X3+X+1)GF(2^{8}) = Z_2[X] (mod X^{8} + X^{4} + X^{3} + X + 1)GF(28)=Z2​[X](modX8+X4+X3+X+1)，找到 X7+X6+X3+X+1X^{7} + X^{6} + X^{3} + X + 1X7+X6+X3+X+1 的逆元。

解：如同整数一样求最大公约数（X7+X6+X3+X+1X^{7}+X^{6}+X^{3}+X+1X7+X6+X3+X+1, X8+X4+X3+X+1X^{8}+X^{4}+X^{3}+X+1X8+X4+X3+X+1）（剩余 → 除数 → 被除数 → 忽略）

X⁸+X⁴+X³+X+1 = (X+1)(X⁷+X⁶+X³+X+1) + (X⁶+X²+X)
X⁷+X⁶+X³+X+1 = (X+1)(X⁶+X²+X) + 1

因此，

1 = (X²)(X⁷+X⁶+X³+X+1) + (X+1)(X⁸+X⁴+X³+X+1)

两边取模 X8+X4+X3+X+1X^{8}+X^{4}+X^{3}+X+1X8+X4+X3+X+1，我们得到：

(X²)(X⁷+X⁶+X³+X+1) ≡ 1 (mod X⁸+X⁴+X³+X+1)

补这段是"扩展欧几里得算法"（Extended Euclidean Algorithm）。把它的套路讲清楚：

第 1 步：辗转相除（求最大公因式）

和整数求最大公约数完全一样，反复"用余数除上一个除数"：

①  A ÷ B ：X⁸+X⁴+X³+X+1 ÷ (X⁷+X⁶+X³+X+1)
     商 = X+1，余 = X⁶+X²+X
②  再看 B ÷ 余： (X⁷+X⁶+X³+X+1) ÷ (X⁶+X²+X)
     商 = X+1，余 = 1        ← 余数变成 1 了！

"剩余 → 除数 → 被除数 → 忽略" 这八个字说的是表格里的轮换方式：这一轮的余数，成为下一轮的除数；这一轮的除数，成为下一轮的被除数；而这一轮的被除数就被"忽略"了（用不上了）。这是手工算辗转相除时的标准排版技巧。

验算一下（一定要自己动手，不然公式悬在空中）：

  • (X+1)(X7+X6+X3+X+1)(X+1)(X^{7}+X^{6}+X^{3}+X+1)(X+1)(X7+X6+X3+X+1) = X8+X7+X4+X2+X+X7+X6+X3+X+1X^{8}+X^{7}+X^{4}+X^{2}+X + X^{7}+X^{6}+X^{3}+X+1X8+X7+X4+X2+X+X7+X6+X3+X+1 = X8+X6+X4+X3+X2+1X^{8}+X^{6}+X^{4}+X^{3}+X^{2}+1X8+X6+X4+X3+X2+1
  • A ⊕ 它 = (X8+X4+X3+X+1)⊕(X8+X6+X4+X3+X2+1)(X^{8}+X^{4}+X^{3}+X+1) \oplus (X^{8}+X^{6}+X^{4}+X^{3}+X^{2}+1)(X8+X4+X3+X+1)⊕(X8+X6+X4+X3+X2+1) = X6+X2+XX^{6}+X^{2}+XX6+X2+X ✓
  • (X+1)(X6+X2+X)(X+1)(X^{6}+X^{2}+X)(X+1)(X6+X2+X) = X7+X3+X2+X6+X2+XX^{7}+X^{3}+X^{2} + X^{6}+X^{2}+XX7+X3+X2+X6+X2+X = X7+X6+X3+XX^{7}+X^{6}+X^{3}+XX7+X6+X3+X；B ⊕ 它 = (X7+X6+X3+X+1)⊕(X7+X6+X3+X)(X^{7}+X^{6}+X^{3}+X+1) \oplus (X^{7}+X^{6}+X^{3}+X)(X7+X6+X3+X+1)⊕(X7+X6+X3+X) = 1 ✓

第 2 步：回代（把余数 1 表示成 A 和 B 的组合）

由 ②：1 = B ⊕ (X+1)·(余数1)
由 ①：余数1 = A ⊕ (X+1)·B
代入：1 = B ⊕ (X+1)·[A ⊕ (X+1)·B]
      = B ⊕ (X+1)A ⊕ (X+1)²B
      = [(X+1)² ⊕ 1]·B ⊕ (X+1)·A
因为 (X+1)² = X²+1，(X²+1) ⊕ 1 = X²
所以 1 = X²·B ⊕ (X+1)·A
即   1 = X²·(X⁷+X⁶+X³+X+1) ⊕ (X+1)·(X⁸+X⁴+X³+X+1)   ✓ 与 PPT 一致

第 3 步：两边取模，得到逆元

在模 X8+X4+X3+X+1X^{8}+X^{4}+X^{3}+X+1X8+X4+X3+X+1 意义下，右边的第二项等于 0（因为它是模多项式的倍数），所以：

X²·(X⁷+X⁶+X³+X+1) ≡ 1 (mod X⁸+X⁴+X³+X+1)

结论：X7+X6+X3+X+1X^{7}+X^{6}+X^{3}+X+1X7+X6+X3+X+1 的逆元就是 X2X^{2}X2，也就是字节 00000100。

补这个结果马上就会用到——第 3.8 节的例 3 和这个例子是同一道题！那里问"字节 11001011 的乘法逆是多少"，答案是 00000100，就是这里算出来的 X2X^{2}X2。

补如果不想手算，有两个偷懒办法：

  1. 查表：AES 标准里直接给出了 256 个元素的逆元（S-盒就是用它造出来的），实际实现都是查表（第 6 节讲的"查表法"）。
  2. 用"平方累乘"：因为在 GF(28)GF(2^{8})GF(28) 中 a255=1a^{255} = 1a255=1，所以 a−1=a254a^{-1} = a^{254}a−1=a254。可以用反复平方快速算幂，硬件实现常用这招。
