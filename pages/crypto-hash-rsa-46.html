3.2 关于整数分解（PPT 第 19–30 页）

3.2.0 两种最简单的分解法（PPT 第 19 页）

PPT 原文：

简单的分解整数 nnn 的办法是用所有素数 p≤np \le \sqrt{n}p≤n​ 去除 nnn，但是在大多数情况下这种方法显然太慢。另一种方法称做 Fermat 分解方法，在大多数的情况下速度也很慢。这种方法的思路是将 nnn 写成两个平方之差：

n=x2−y2。n = x^2 - y^2。n=x2−y2。
这样 n=(x+y)(x−y)n = (x+y)(x-y)n=(x+y)(x−y) 就能给出 nnn 的分解。也就是计算 n+12n + 1^2n+12，n+22n + 2^2n+22，⋯\cdots⋯，直到发现平方为止。 Fermat 分解方法在 nnn 的两个素数非常接近的情况下会非常有效。如果 n=p⋅qn = p \cdot qn=p⋅q，则需要计算 ∣p−q∣/2|p-q|/2∣p−q∣/2 步可以发现分解。因此，在 RSA 组成模 nnn 的两个素数选取上通常需要有些许的尺寸差别。

（勘误：PPT 原文"也就是计算 n+12n + 1^2n+12，n+22n + 2^2n+22，…"应理解为"计算 n+12n + 1^2n+12、n+22n + 2^2n+22、n+32n + 3^2n+32、…（即 n+k2n + k^2n+k2）"，直到某个 n+k2n + k^2n+k2 是完全平方数为止。这是原课件表述上的省略。）

补方法一：试除法（Trial Division）

做法：拿所有 ≤n\le \sqrt{n}≤n​ 的素数去试除 nnn。

为什么只要试到 n\sqrt{n}n​？ 因为如果 n=p⋅qn = p \cdot qn=p⋅q 且 p≤qp \le qp≤q，那么 p≤np \le \sqrt{n}p≤n​——较小的那个因子一定在 n\sqrt{n}n​ 以内。

为什么"太慢"？ 素数密度大约是 1ln⁡n\frac{1}{\ln n}lnn1​，所以 ≤n\le \sqrt{n}≤n​ 范围内的素数个数约是：

nln⁡n≈2nln⁡n\frac{\sqrt{n}}{\ln \sqrt{n}} \approx \frac{2\sqrt{n}}{\ln n}lnn​n​​≈lnn2n​​

对 1024 比特的 nnn：n≈2512\sqrt{n} \approx 2^{512}n​≈2512。要试的素数个数是天文数字——完全不可行。

补方法二：Fermat 分解法

思路：把 nnn 写成平方差形式。

n=x2−y2=(x+y)(x−y)n = x^2 - y^2 = (x+y)(x-y)n=x2−y2=(x+y)(x−y)

只要能写成平方差，因子就立刻到手：p=x−yp = x - yp=x−y、q=x+yq = x + yq=x+y。

怎么找这样的 x,yx, yx,y？ 从 x=⌈n⌉x = \lceil \sqrt{n} \rceilx=⌈n​⌉ 开始，逐个令

x=⌈n⌉, ⌈n⌉+1, ⌈n⌉+2, …x = \lceil \sqrt{n} \rceil,\ \lceil \sqrt{n} \rceil + 1,\ \lceil \sqrt{n} \rceil + 2,\ \ldotsx=⌈n​⌉, ⌈n​⌉+1, ⌈n​⌉+2, …

每取一个 xxx，检查 x2−nx^2 - nx2−n 是不是完全平方数。如果是，那么 y=x2−ny = \sqrt{x^2 - n}y=x2−n​，分解完成。

补手算一个成功的例子：分解 n=200819n = 200819n=200819。

√200819 ≈ 448.13  →  从 x = 449 开始

x = 449:  449² = 201601,  201601 − 200819 = 782     不是平方数
x = 450:  202500 − 200819 = 1681 = 41²  ✓ 找到了！

所以 y = 41,  x = 450
p = x − y = 450 − 41 = 409
q = x + y = 450 + 41 = 491

验证：409 × 491 = 409×500 − 409×9 = 204500 − 3681 = 200819  ✓

只用了 2 步就分解完成。

补为什么"ppp 和 qqq 很接近"时这个方法特别快？

推导一下需要的步数。设 n=pqn = pqn=pq，p≤qp \le qp≤q。要求的 x,yx, yx,y 满足：

x=p+q2,y=q−p2x = \frac{p+q}{2}, \qquad y = \frac{q-p}{2}x=2p+q​,y=2q−p​

注意 ppp 和 qqq 是奇素数（其实无论奇偶，p+qp+qp+q 和 q−pq-pq−p 都是偶数），所以 xxx 和 yyy 都是整数。

从 ⌈n⌉\lceil\sqrt{n}\rceil⌈n​⌉ 开始，要走多少步才能到 p+q2\frac{p+q}{2}2p+q​？

p+q2−n=p+q2−pq=(q−p)22\frac{p+q}{2} - \sqrt{n} = \frac{p+q}{2} - \sqrt{pq} = \frac{(\sqrt{q} - \sqrt{p})^2}{2}2p+q​−n​=2p+q​−pq​=2(q​−p​)2​

化简一下（上下同乘 (q+p)2(\sqrt{q}+\sqrt{p})^2(q​+p​)2）：

=(q−p)22(q+p)2≈(q−p)28pq=(q−p)28n= \frac{(q-p)^2}{2(\sqrt{q}+\sqrt{p})^2} \approx \frac{(q-p)^2}{8\sqrt{pq}} = \frac{(q-p)^2}{8\sqrt{n}}=2(q​+p​)2(q−p)2​≈8pq​(q−p)2​=8n​(q−p)2​

而我们要找的是"x2−nx^2 - nx2−n 是平方数"的那一步——实际上需要的步数大约是 ∣p−q∣2\frac{|p-q|}{2}2∣p−q∣​（这是 PPT 给的结论）。

补关键的结论是：

需要的步数≈∣p−q∣2\text{需要的步数} \approx \frac{|p-q|}{2}需要的步数≈2∣p−q∣​
  • 如果 ppp 和 qqq 非常接近（∣p−q∣|p-q|∣p−q∣ 很小），步数就很少 → 分解极快；
  • 如果 ppp 和 qqq 相差很远（∣p−q∣|p-q|∣p−q∣ 很大），步数就很多 → 分解很慢。

对 1024 比特的 nnn，如果 ppp 和 qqq 都是 512 比特、随机选，那么 ∣p−q∣|p-q|∣p−q∣ 大约是 25112^{511}2511 量级——需要 25102^{510}2510 步，完全不可行。

补这解释了算法 1 里"两个素数的长度基本相等"这条要求：

p 和 q 长度基本相等   →   |p−q| 不会太小，也不会太大
                          ↓
              ┌───────────┴───────────┐
              ↓                       ↓
       试除法失效                  Fermat 法失效
   （p 不会是极小素数）        （p、q 相距足够远）

两种简单攻击被"夹在中间"同时封堵——这就是"长度基本相等"这条看似平淡的要求的深意。

补反过来，这条要求也告诉攻击者一个信号：如果某个 RSA 实现的 ppp 和 qqq 偶然选得太接近（比如有人图省事用"ppp 附近的素数"当 qqq），那么 Fermat 分解法几秒钟就能破。第 3.7 节的"部分密钥泄露攻击"就是利用了这类"生成方式的规律性"。
