Math Tool

行列式计算器

输入数字或代数表达式，直接得到精确结果或展开后的公式。支持 2–6 阶矩阵、分数精确运算、 变量代入求值，以及可复制的 LaTeX 科学公式。

矩阵输入

2–6 阶 · 留空按 0
阶数 n = 3
示例

单元格支持数字、分数、小数、科学计数法、变量（a、x、θ…）、 函数（sin、cos、ln、sqrt…）以及 + − × ÷ ^ 运算与括号。

输入语法

写法含义
1/3、0.25、1e-3分数、小数、科学计数法（数值模式保持精确）
a、x、x1、θ、alpha变量，代入数值后可求值
2x、3(a+b)、(a+b)(a-b)隐式乘法，与 2*x 等价
x^2、2^-3乘方（指数需为常数）
sin(x)、cos(x)、ln(x)、sqrt(x)、abs(x)三角函数、对数、开方、绝对值
pi、e圆周率、自然常数（数值结果按近似值给出）
  • 全为有理数的矩阵使用分数精确运算，结果给出约分后的分数、小数与科学计数法。
  • 含变量时按余子式展开并合并同类项，结果为完全展开的多项式；展开项数过多时会保留紧凑形式。
  • 含函数的结果不做三角恒等式化简（例如 sin²x + cos²x 不会自动合并为 1）。
  • e 是自然常数（≈ 2.718），不能作为变量名；需要变量时请用其它字母。
  • 行列式最多支持 6 阶：再大时计算量增长很快，建议先做行列变换化简。
