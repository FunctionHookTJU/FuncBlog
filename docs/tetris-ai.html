俄罗斯方块 AI：算法、权重与文献

站内那个能自己玩的 AI，用的是最经典的路线：枚举当前方块的所有旋转与落点， 对每个候选局面算一组特征，用一篇 2011 年论文里的权重打分，选分最高的摆放。 这里记录实现细节、三套公开权重的来历，以及可以直接读的论文与开源代码。

去玩（点「AI 自动玩」） 返回新产品

为什么用启发式，而不是「精确求解」

俄罗斯方块的离线最优规划是NP-完全的：给定整串方块序列，想最大化消行数、 最大化四行全消次数、最小化最大堆高，都是 NP-完全问题，而且前两者还不可近似 （Demaine、Hohenberger、Liben-Nowell，2003）。所以实时对局几乎没人做全局最优， 主流做法是「看一步、打分、贪心」——也就是 1-ply 搜索加线性评价函数。

一个反直觉的事实：这套只看一步的线性打分，在 10×20 标准场地上能连消上千万行 （El-Tetris 论文报告平均 16,047,595 行/局）。真正的瓶颈不是搜索深度，而是特征选得对不对。

算法流程

for 每个新方块:
  候选 = []
  for 每个去重后的旋转形态 r:            # I/O 2 个，S/Z 2 个，T/J/L 4 个
    for 每个合法列 x:                    # 水平平移
      y = 一直下落到底的落点             # 撞到已堆方块或底部为止
      if 落点越界或悬空: continue        # 视为不可行，直接丢弃
      新棋盘 = 锁定方块 + 消除满行
      候选.append( (r, x, 新棋盘, 特征) )
  选 特征加权得分最高 的候选，执行「旋转 → 平移 → 瞬降」

一次决策最多几十个候选，每个候选算 6 个特征，纯 O(行×列)。当前实现里 2-ply（再看一个预览块）单次决策约 5ms，浏览器里完全没有压力。

六个特征与权重（El-Tetris，本站默认）

Islam El-Ashi 在 2011 年改进了 Pierre Dellacherie 的经典算法，用粒子群优化（PSO） 重新调了权重，并开源了实现。它的评价函数就是六个特征各乘一个权重再求和：

特征含义权重
Landing Height 落点高度（列高 + 方块高 / 2） −4.500158825082766
Rows eliminated 本步消除的行数 +3.4181268101392694
Row Transitions 行内相邻格「填充↔空」的变换次数 −3.2178882868487753
Column Transitions 列内相邻格「填充↔空」的变换次数 −9.348695305445199
Holes 同列上方存在填充格的空格数 −7.899265427351652
Well Sums 「井」的累计深度，长度为 n 的井按 1+2+…+n 计 −3.3855972247263626

容易踩的坑：El-Tetris 把 Dellacherie 原版的正向特征 eroded piece cells （本步被消掉的、属于刚落下方块的格子数）换成了简单的「消行数」。 两套权重不能混用——特征变了，权重就得跟着变。

边界处理也必须严格照搬，否则性能会从千万行掉到几百行：行转换把左右两堵墙视为填充； 列转换把「天花板上方」视为填充、地板以下开放不计；井的判定在首末列把棋盘外当作墙。

另外两套公开权重

Pierre Dellacherie（2003，手工试错）

最早的经典：同样六个特征，但正向特征是 eroded piece cells。 他本人没有发表论文，权重是反复试错调出来的，学界普遍按 Fahey（2003）的转述引用， 常见整数版本为：落地高度 −1、侵蚀格数 +1、行转换 −1、列转换 −1、洞 −4、井 −1。

Yiyuan Lee（2013，遗传算法）

只有四个特征，代码短到几十行，很适合直接读：总堆高、消行数、洞数、地表起伏（相邻列高差之和）。 遗传算法调出的权重为 −0.510066、+0.760666、−0.35663、−0.184483（符号「负正负负」）。

本站实现把三套权重都放进去了（weights 可选 eltetris / dellacherie / lee）。自对弈 3000 块的三组随机种子下， 三套都能存活不爆顶，平均消行都在 1190 行左右，差别不大；真实对局里差异更多来自随机序列与场地规则。

AI 的速度与游戏的重力，是两回事

AI 的操作速度是恒定的：每步动作间隔固定 55ms，一路旋转、平移、瞬降， 实测约 3.5 块/秒，从 1 级到几百级都一样。它不随等级变快，也不受「简单模式」影响。

与此同时，游戏本身的等级加速照常生效：等级越高，方块自然下落的间隔越短 （1 级 800ms → 12 级起封顶 80ms）。AI 只是在这个越来越快的场地里保持自己的手速， 该顶死的时候一样会顶死。

等级重力下落间隔AI 操作速度（实测）
1800 ms≈ 3.6 块/秒
3660 ms≈ 4.0 块/秒
5520 ms≈ 3.5 块/秒
8310 ms≈ 3.5 块/秒
10170 ms≈ 3.8 块/秒
12 及以后80 ms（下限）≈ 3.5 块/秒

AI 速度的上下浮动（3.45–4.0 块/秒）来自每块需要旋转/平移的步数不同，不是等级造成的。 开启「简单模式」后，重力恒定 800ms 不再加速，而 AI 依旧是 3.5 块/秒左右。 这两条断言（AI 速度恒定 ≤1.3 倍浮动、重力随等级下降）固化在 tools/verify_tetris_ai_pace.mjs 里，可随时复跑。

本站的实现

引擎在 scripts/tetrisAI.js （零依赖，浏览器与 Node 都能跑），游戏页在 俄罗斯方块。 页面上的「AI 自动玩」按钮打开后，AI 会接管当前方块：旋转到目标朝向 → 平移到目标列 → 瞬降锁定， 玩家随时可以按方向键把控制权抢回来。AI 的操作速度恒定，游戏重力的等级加速独立生效。 

// 浏览器
const best = TetrisAI.bestPlacement(grid, pieceMatrix, {
  weights: TetrisAI.WEIGHTS.eltetris,   // 或 dellacherie / lee
  lookahead: true,                       // 用下一个预览块做 2-ply
  nextMatrix: nextPieceMatrix
});
// best = { rot, x, y, matrix, cleared, score, features, gridAfter }

想自己调权重，改 WEIGHTS 里对应的数字即可；每个特征的取值都会随 best.features 一起返回，方便观察某一手到底被哪一项惩罚了。

论文

  • Erik D. Demaine, Susan Hohenberger, David Liben-Nowell. Tetris is Hard, Even to Approximate. COCOON 2003；IJCGA 2005。离线最优规划 NP-完全且不可近似的标准引文。 复杂性
  • Islam El-Ashi. El-Tetris – An Improvement on Pierre Dellacherie's Algorithm. 2011（作者博客，一手来源）。本站默认权重的出处，含特征定义与 PSO 调参说明。 启发式
  • István Szita, András Lőrincz. Learning Tetris Using the Noisy Cross-Entropy Method. Neural Computation 18(12), 2006。加噪声防早收敛的交叉熵方法。 学习型
  • Christophe Thiery, Bruno Scherrer. Building Controllers for Tetris. ICGA Journal 32(1), 2009。系统梳理了 Tetris 特征清单，并提醒实现细节会让分数差很多。 综述
  • Victor Gabillon, Mohammad Ghavamzadeh, Bruno Scherrer. Approximate Dynamic Programming Finally Performs Well in the Game of Tetris. NIPS 2013。策略空间近似动态规划，样本量约为交叉熵方法的 1/10。 ADP
  • Yiyuan Lee. Tetris AI – The (Near) Perfect Bot. 2013（博客；若打不开可看对应 GitHub 仓库源码）。四特征与遗传算法调参过程。 博客

开源实现

  • LeeYiyuan/tetrisai JavaScript，MIT。四特征 + 遗传算法，浏览器内直接可跑，最适合拿来对照阅读。 JS
  • ielashi/eltetris JavaScript，GPL。El-Tetris 作者的参考实现，位运算写法，注意协议是 GPL，只宜阅读不宜直接搬进 MIT 项目。 JS
  • nuno-faria/tetris-ai Python（Keras/JAX），DQN 深度强化学习，含预训练模型，是「换条技术路线」的首选参照。 DQN
  • GregoryCannon/StackRabbit C++，NES Tetris 的搜索 + 估值表方案，用价值迭代学局面价值，思路很值得借鉴。 搜索
  • hinesboy/ai_tetris C++，Dellacherie 启发式的完整实现，中文注释详细，适合逐行对照六特征算法。 启发式
