## 3. Markdown 写法（硬性规定）

### 3.1 标题层级

- **禁止 `#` 和 `##`**：页面标题由构建器注入。
- 小节内用 `###`，更细一层用 `####`。
- 每节至少 2 个 `###`。

### 3.2 数学公式

- 行内：`$...$`；独立成行的公式：`$$...$$`（前后各留空行）。
- **禁止硬写 Unicode 上下标**（`²³ⁿ⁺⁻₀ᵢ` 这类）。全部写成真正的 LaTeX：`10^{277}`、`|\psi_i\rangle`、`\langle\phi|\psi\rangle`。
- 常用记号：`|\psi\rangle`、`\langle\psi|`、`\otimes`、`\dagger`、`\rho`、`\sigma_1`、`\mathrm{tr}`、`\frac{}{}`、`\tfrac{}{}`、`\sum_i`、`\sqrt{2}`、`\mathrm{tr}_B`、`\mathbb{C}`。
- 公式合法性会被逐条离线校验：**渲染失败的公式会让整个构建失败**，所以别写半截公式。
- 每个公式后面跟一句「翻译成人话」。

### 3.3 讲义专用标记

| 你写 | 渲染为 | 用途 |
|---|---|---|
| `【补】` | 橙色「补」徽章 | 课件没讲但初学者必需的内容（术语定义、历史背景、类比、易错点、补充数据） |
| `【勘误】` | 橙色「勘误」徽章 | 指出课件的笔误/不严谨之处 |

用法示例：

```markdown
【补】**为什么必须用复数？** 实数域上无法同时满足「酉演化」和「测量概率」的两条要求……
【勘误】原课件此处把 $\sigma_2$ 写成了 $\sigma_3$，按上下文应为 $\sigma_2$。
```

### 3.3.1 【勘误】的使用红线（独立核查后补充的硬规则）

**`【勘误】` 只能用于「课件确实写错」的地方**：数字、符号、下标、求和上下限、公式里的加减号、术语误用等。

以下情况**一律用 `【补】`，不得标 `【勘误】`**（否则读者会以为课件出错，而实际是讲义自己的加工）：

- 讲义自己的观点、判断、润色（例如「这两种视角其实是同一个结论」）；
- 对课件留下的问句/思考题给出答案；
- 把课件的历史叫法讲清楚；
- 把课件没写全的前提条件补上。

判断标准：**如果课件原文并没有说出被批评的那句话，就不构成【勘误】。**「先把课件的话加强，再批评这个加强版」是最典型的误判。

### 3.4 表格与结构图

- 普通表格：标准 Markdown 表格（**必须有 `|---|---|` 分隔行**）。
- **纯数值的排列 / 矩阵 / 表头全空的表**：一律写成裸 HTML（Markdown 的 tables 扩展处理不了），记得前后留空行：

```html
<table class="grid"><tr><td>a</td><td>b</td></tr><tr><td>c</td><td>d</td></tr></table>
```

- **ASCII 结构图（框图、流程图）**：放进 ``` 代码块，用 `┌ ─ │ └ ⊕` 等制表符画。**不要**改成 KaTeX 矩阵，也不要替换 `⊕`。
- 含中文的公式块保持「等宽纯文本代码块」，不要把中文塞进 `\text{}`。

### 3.5 行文要求

- 跟着课件原编号走，**课件每个知识点都要有对应段落**，可标 `（PPT 第 N 页）`。
- 面向「基础薄弱的学生」：**禁用「显然」「易得」「同理可证」**；每步数学都要能给出手算例子。
- 术语首次出现给中英对照，例如「测量塌缩（measurement collapse）」。
- 主动指出课件的不严谨之处，用 `【勘误】`。
- 关键对比做表格（状态向量 vs 密度算子、投影测量 vs 一般测量、LHV vs 量子力学……）。
- 讲末节（标题含「小结」的）必须含：`### 小结`（含一句「一句话串起本讲」）+ `### 核心结论清单` + `### 自测题`（4–8 题）。
- **自测题答案就地折叠**（不要另建答案页），用原生 HTML 的 `<details>`，前后留空行：

```html
<details><summary>答案</summary>

由 $|a|^2+|b|^2=1$ 得 $|b|^2=1/2$，故 $b=\pm\tfrac{1}{\sqrt2}$（相位可自由选取）。

</details>
```

（`<details>` 里的公式同样支持 `$...$`。）
- 篇幅：**每节 4500–12000 字符（不含空白）**。宁可写透一个知识点，也不要罗列名词。

## 6. 质量标杆（示例片段）

```markdown
### 2.1 公理 1：状态空间与量子态

量子力学的第一条公理只做一件事：**规定「量子态」住在什么样的数学对象里**。

> **公理 1**　物理系统的状态空间是一个定义了内积运算的复向量空间（Hilbert 空间）。系统的状态（量子态）由该空间中的一个**单位列向量**完全描述。（PPT 第 28 页）

把这句话拆成三块：

1. **复向量空间**：态可以相加、可以乘复数——这就是「叠加」的数学源头。
2. **内积**：有了内积才能谈「长度」和「夹角」，才能把概率算出来。
3. **单位向量**：长度必须是 1。这不是审美要求，而是概率归一化的直接后果：

$$\langle\psi|\psi\rangle = 1 .$$

**翻译成人话**：量子态就是一个「长度为 1 的箭头」，它的方向编码了全部可观测信息。

【补】**为什么必须归一化？** 设 $|\psi\rangle=a|0\rangle+b|1\rangle$，测量得到 $|0\rangle$ 的概率是 $|a|^2$、得到 $|1\rangle$ 的概率是 $|b|^2$。两者之和必须等于 1（测量必有结果），于是 $|a|^2+|b|^2=\langle\psi|\psi\rangle=1$。反过来，任何长度为 1 的复向量都是一个合法的量子比特态。

**手算一个例子**：检验 $|\psi\rangle=\tfrac{1}{\sqrt2}|0\rangle+\tfrac{i}{\sqrt2}|1\rangle$ 是否合法：

$$\langle\psi|\psi\rangle=\left|\tfrac{1}{\sqrt2}\right|^2+\left|\tfrac{i}{\sqrt2}\right|^2=\tfrac12+\tfrac12=1 .$$

合法。注意 $\left|i/\sqrt2\right|^2=1/2$，**模平方会把 $i$ 消掉**——相位不进入概率，这是后面「全局相不可观测」的伏笔。
```
